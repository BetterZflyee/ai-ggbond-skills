# OpenClaw 知识库资料

## 基本信息
- **名称**: OpenClaw（昵称"小龙虾"）
- **发布时间**: 2025年11月
- **作者**: 奥地利程序员 Peter Steinberger
- **GitHub地位**: 2026年1月底爆火，星标数量超过 Linux，成为 GitHub 上获星最多的软件项目

## 核心定位
OpenClaw 是一款开源、本地优先的 AI Agent 框架，将大型语言模型转变为能够执行跨平台复杂任务的助手。

## 核心能力
- 清理邮件
- 管理日历
- 执行代码
- 自己给自己写新技能
- 跨平台任务执行

## 关键案例：傅盛的14天实验
- **Agent名称**: 三万
- **实验时长**: 14天
- **对话量**: 1157条消息，22万字
- **成果**: 
  - 8个Agent组成的团队
  - 7×24小时自动运转
  - 40多个Skill积累
  - 公众号从年更十几篇变成日更
  - 一条推文100万+阅读（凌晨自主发布）
  - 24小时搭建 sanwan.ai 网站（59个页面，7070行代码）

## 技术特点
- 向量化记忆系统
- Multi-Agent协作架构
- Skill机制（可复用、可传递）
- 定时自动化

## 使用门槛
- 需要命令行部署
- 需要自己配置API key
- 需要处理安全漏洞
- 对非技术用户门槛较高

## 竞品/相关产品
- **EasyClaw**: 猎豹移动推出的易用版本，3分钟上手
- **WorkBuddy**: 腾讯推出的全场景AI智能体，兼容OpenClaw
- **元气AI Bot**: EasyClaw国产版

## 行业意义
验证了AI可以不只回答问题，而是替人完成任务——这是工具的AGI时刻。

## 核心洞察
Agent的真正壁垒不在模型有多聪明，而在Skill的积累。模型的智力是起点，让整个系统真正变强的是行动中沉淀下来的经验。
