# 导演分身 Director Mind

## 任务目标
本 Skill 用于：
- 将用户的创意需求转化为专业的影视创作方案
- 优化 AI 视频生成的提示词，提升画面表现力和镜头语言
- 提供专业的拍摄手法和视听语言建议
- 指导剧本编写，确保故事结构完整、节奏合理

核心能力包含：
- 提示词优化与专业化转换
- 视听语言分析和建议
- 拍摄手法和镜头设计
- 剧本结构梳理和完善

触发条件：
- 用户提到"文生图"、"图生视频"、"视频生成"、"画面制作"、"影视拍摄"
- 需要优化或编写提示词
- 询问拍摄手法、镜头语言、剧本编写相关内容

## 操作步骤

### 1. 需求分析与理解
- 明确用户的创作目标：是 AI 视频生成、实拍指导，还是剧本创作？
- 识别核心场景和视觉元素
- 确定作品风格定位（文艺片、商业片、纪录片等）

### 2. 方案设计与建议
根据用户需求，提供以下指导：

**对于 AI 文生图提示词优化：**
- 调用 `references/image-prompt-guide.md` 中的优化方法论
- 将用户描述性语言转换为专业术语
- 添加构图、光影、色彩、风格等要素
- 确保提示词结构完整（主体+细节+环境+风格+技术参数）

**对于 AI 图生视频提示词优化：**
- 调用 `references/video-prompt-guide.md` 中的优化方法论
- 在静态图像基础上添加动态要素（运镜、动作、节奏）
- 设计镜头运动方案（推拉摇移、环绕、跟拍等）
- 添加动态光影和时间变化描述

**对于 AI 视频生成提示词优化：**
- 调用 `references/prompt-optimization-guide.md` 中的优化方法论
- 将用户描述性语言转换为专业术语
- 添加镜头语言、光影效果、色彩方案等专业要素
- 确保提示词结构完整（主体+动作+环境+风格+技术参数）

**对于拍摄手法建议：**
- 调用 `references/shooting-techniques.md` 获取拍摄手法参考
- 根据场景特点推荐合适的运镜方式
- 提供机位设置、构图方案
- 说明节奏把控要点

**对于剧本编写：**
- 调用 `references/screenplay-templates.md` 中的格式规范
- 确保故事结构完整（起承转合）
- 梳理人物关系和冲突
- 优化对白和场景描述

### 3. 提示词优化执行

#### 3.1 AI 文生图提示词优化

**分析原始提示词：**
- 提取核心视觉元素和主体
- 识别模糊或缺失的细节描述
- 评估构图、光影、色彩要素的完整性

**专业化转换：**
- 将通俗描述转换为专业术语（例如："漂亮的风景" → "壮丽的雪山倒映在碧蓝湖水中，黄金时刻光线"）
- 补充构图细节（例如："人物在中间" → "人物位于画面右侧三分之一处，遵循三分法"）
- 添加光影描述（例如："有光" → "侧逆光营造轮廓，暖橙色暖色调"）
- 明确风格定位（例如："好看" → "电影感，8K分辨率，照片级真实"）

**结构化输出：**
提供优化后的提示词，包含以下模块：
```
[主体描述] 人物、物体、核心元素
[场景细节] 动作、表情、材质、纹理
[环境设定] 场景类型、背景、道具
[构图光影] 构图法则、光源类型、色调方案
[风格参数] 艺术风格、渲染质量、技术参数
```

#### 3.2 AI 图生视频提示词优化

**分析源图像：**
- 识别画面中的静态元素（主体、背景、环境）
- 分析现有光影和构图
- 确定可以转化为动态的要素

**设计动态方案：**
- 选择运镜方式（推拉摇移、环绕、跟拍、手持等）
- 定义主体动作（移动、变形、表情变化等）
- 设计环境变化（光影变化、云层流动、水波荡漾等）
- 规划节奏控制（缓慢、中等、快速）

**专业化转换：**
- 添加镜头运动描述（例如："镜头缓慢推进，聚焦于人物眼睛"）
- 补充动态细节（例如："头发随风轻摆，眼神追随着远方的飞鸟"）
- 说明时间变化（例如："从黄昏渐入夜幕，天空色彩从橙红转为深蓝"）
- 增加技术参数（例如："24fps，运动模糊，光线追踪"）

**结构化输出：**
提供优化后的提示词，包含以下模块：
```
[基础图像] 描述源图像的静态要素
[镜头运动] 运镜方式、速度、轨迹
[动态设计] 主体动作、环境变化、时间推移
[光影变化] 光源移动、色调演变
[技术参数] 帧率、时长、渲染风格
```

#### 3.3 AI 视频生成提示词优化

**分析原始提示词：**
- 提取核心视觉元素和动作
- 识别模糊或缺失的专业信息
- 评估技术参数的完整性

**专业化转换：**
- 将通俗描述转换为专业术语（例如："慢慢靠近" → "缓慢推镜头，中景转近景"）
- 补充光影细节（例如："光照" → "侧逆光营造轮廓，暖色调氛围"）
- 添加镜头运动描述（推拉摇移、跟拍、航拍等）
- 明确景别变化（远全中近特）

**结构化输出：**
提供优化后的提示词，包含以下模块：
```
[场景描述] 主体、动作、环境
[镜头语言] 运镜方式、景别、构图
[光影色彩] 光源类型、色温、色调方案
[情绪氛围] 情感基调、节奏把控
[技术参数] 分辨率、帧率、风格强度（适用于 AI 生成）
```

### 4. 视听语言深化

## 使用示例

### 示例 1：AI 文生图提示词优化
**用户需求**：生成一个日落时分海边的唯美画面

**优化后的提示词**：
```
[主体描述] 年轻女子，穿着白色连衣裙，长发微卷，赤脚站在沙滩上
[场景细节] 海风轻拂，头发随风飘动，眼神温柔地望着远方海面
[环境设定] 金色沙滩，蔚蓝大海，远处有帆船剪影，海鸥掠过天空
[构图光影] 低角度拍摄，人物位于画面右侧三分之一处，遵循三分法；逆光营造轮廓光，暖橙色暖色调，黄金时刻光线
[风格参数] 电影感，照片级真实，8K分辨率，高细节，柔和光线
```

### 示例 2：AI 图生视频提示词优化
**源图像**：一个人物站在湖边的静态照片

**优化后的提示词**：
```
[基础图像] 30岁男子，深色休闲装，站在湖边，背景是雪山和蓝天
[镜头运动] 缓慢推进，从中景拉近至特写，焦点从背景转移到人物面部
[动态设计] 微风拂过，头发和衣角轻柔摆动；眼神追望着远方的水面；湖面波光粼粼，云层缓慢移动
[光影变化] 阳光穿过云层，产生微妙的光线变化；人物面部受光面随之改变
[技术参数] 24fps，5秒时长，运动模糊，光线追踪，4K分辨率
```

### 示例 3：AI 视频提示词优化
**用户需求**：生成一个日落时分海边的唯美动态画面

**优化后的提示词**：
```
[场景描述] 金色夕阳西下，海浪轻拍礁石，海鸥掠过海面，远方帆船剪影
[镜头语言] 缓慢横移，中景拉开至远景，低角度拍摄增强宏伟感
[光影色彩] 逆光营造剪影效果，暖橙色色调，黄金时刻光线
[情绪氛围] 宁静致远，略带诗意，节奏舒缓
[技术参数] 电影感滤镜，光线追踪增强，4K分辨率，24fps
```

### 示例 4：拍摄手法建议
**用户需求**：表现主角内心的冲突和焦虑

**建议方案**：
- 使用手持摄影增加不安感
- 镜头快速切换，配合人物微表情特写
- 色调偏向冷灰，对比度降低
- 环境音渐入，营造压抑氛围

### 示例 5：剧本编写指导
**用户需求**：优化一场离别戏

**建议要点**：
- 对白克制，多用动作和表情传达情感
- 环境描写烘托离别氛围（雨、黄昏、站台等）
- 镜头从中景拉开至远景，强化孤独感
- 控制节奏，留白给观众情感共鸣空间
