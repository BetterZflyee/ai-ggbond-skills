# 数据源地图

## 一条极易被搞反的规律

政策有三个层级，但**钱的位置和新闻的位置是反的**：

| 层级 | 作用 | 媒体曝光 | 对普通人直接价值 |
|---|---|---|---|
| **国家级** | 定方向、定框架（口号层） | 极高 | 极低 |
| **省级** | 定标准、定配套资金（规则层） | 中 | 中 |
| **市/区县级** | 定执行口径、发真金白银（执行层） | **几乎为零** | **最高** |

**结论：真正该天天盯的，是你所在区的人社局、住建局、医保局、教育局官网"通知公告"栏——它们几乎不上新闻。**

同一份材料，A 区认、B 区不认，换个窗口口径就变。**政策知识是极端分散的**（哈耶克意义上的分散知识），这就是信息差存在的原因。

## 检索路径

### 市级政策原文
- 市政府门户 → "政务公开 / 政策文件" → 按发文机关筛选
- 市自然资源和规划局 → "规划公示 / 控制性详细规划"
- 市发改委 → "项目核准 / 轨道交通建设规划"
- 检索语法：`site:gov.cn 关键词 2026`、`"办法" filetype:pdf 城市名`

### 区县级（价值最高）
- 区人民政府门户 → "政务公开 → 通知公告"
- 区人社局 → "就业创业补贴 / 社保补贴 / 技能培训"
- 区住建局 → "保障性住房 / 购房资格 / 老旧小区改造"
- 区教育局 → "招生政策 / 学区划分 / 随迁子女"
- 区医保局 → "报销政策 / 异地就医 / 集采"
- **电话核实**：12345 转对应部门（最准，但记得问"依据哪份文件第几条"）

### 政策生命周期
- 征求意见稿：地方政府"立法征求意见"栏目、部委官网"征求意见"
- 已发布未生效：看"自 X 年 X 月 X 日起施行"
- 失效/修订：看"废止文件目录"

## Layer B 硬指标出处

| 指标 | 算法 | 出处 |
|---|---|---|
| 土地财政依赖度 | 国有土地使用权出让收入 ÷ 一般公共预算收入 | 市财政局年度预算执行报告、财政部地方财政决算 |
| 城投债利差 | 本地城投债到期收益率 − 同期限国债 | 中债估值、Wind、企业预警通 |
| 常住人口 / 小学生入学人数 | 直接取数 | 市统计年鉴、国民经济和社会发展统计公报、教育局事业统计 |
| 写字楼空置率与租金 | 直接取数 | 戴德梁行/仲量联行/世邦魏理仕季度报告 |
| 招聘岗位数 / 薪资带 | 按行业×城市检索岗位量 | 招聘平台公开检索（BOSS/猎聘/智联），取趋势不取绝对值 |
| 园区入驻率 | 直接取数 | 园区官网招商页、管委会年度报告 |
| 上市公司数量与融资额 | 直接取数 | 交易所、证监会派出机构、地方金融局 |

## 城市空间与规划（Layer B1 辅助）

- 国务院/省级**批复文件**（几百字，定性最硬：城市性质、人口上限、开发边界）
- **轨道交通建设规划（发改委批复）**——唯一把具体站点写进合同的规划，普通人价值最高
- **年度国有建设用地供应计划**——只管 1–2 年，但是政府用真金白银投票处
- 市级国土空间总体规划（2021–2035）
- 区级分区规划、控规调整公示（最早信号，噪声也最大）

**刚性 vs 预期性**：生态红线、永久基本农田、城镇开发边界是**刚性**（几十年不动）；人口目标、GDP 目标是**预期性**（可以随口许诺）。
**用排除法划掉不毛之地，比用追逐法找暴击地块靠谱十倍。**

## 信源可信度

| 级 | 来源 | 用法 |
|---|---|---|
| A | 国务院/部委批复、发改委核准 | 直接采信 |
| B | 省市级政策原文 | 采信，核对执行细则 |
| C | 区县通知、官方新闻、窗口答复 | 采信但标注"以窗口为准" |
| D | 自媒体、中介传单 | 只作线索，绝不进结论 |
