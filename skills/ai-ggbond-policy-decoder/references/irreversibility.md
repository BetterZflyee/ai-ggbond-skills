# 不可逆性检查

## 铁律

> 普通人真正的风险不是收益率低，是**掉进一个出不来的坑**。

塔勒布的杠铃原则在这里成立得很硬：**如果你承受不起一次归零，那么任何期望收益都是幻觉。**

**不可逆清单为空，拒绝输出结论。**

---

## 五类不可逆 / 半不可逆决策

| 类型 | 不可逆在哪 | 真实代价 |
|---|---|---|
| **买房** | 首付 + 税费 + 限售期 + 挂牌周期 | 3–6 个月现金流 + 20–30% 交易摩擦 + 数年锁死 |
| **迁户口** | 迁出容易迁回难，社保年限可能重置 | 回迁资格丧失，购房/学区资格重新计算 |
| **辞职转行** | 技能折旧 + 年龄门槛 + 收入断档 | 12–24 个月收入恢复期，35 岁后难度陡增 |
| **生育** | 时间不可逆，育儿支出刚性 | 18 年刚性支出 + 一方职业减速 |
| **担保 / 长期负债** | 连带责任，信用记录 | 一旦触发，家庭资产负债表直接归零 |

---

## 决策三分级 → 下注比例

| 分级 | 定义 | 允许的下注上限 |
|---|---|---|
| **可逆** | 错了能退回原状，成本 < 5% 净资产 | 可以试，可以快 |
| **半可逆** | 能退，但要付显著代价（10–30%） | 只在基准情景成立时做，不做杠杆 |
| **不可逆** | 退出成本 > 30%，或根本退不出 | **只在基准情景成立 + 保留逃生资金 + 有明确退出条件时做** |

**判断标准只有一个**：
> 如果三年后我发现错了，我能退回来吗？退回来要花多少钱？

---

## 逃生资金规则

做任何不可逆决策之前，必须确认：

1. **现金缓冲 ≥ 6 个月家庭总支出**（有房贷 ≥ 12 个月）
2. **月供 ÷ 月收入 ≤ 50%**（含所有负债，不只是房贷）
3. **不动用应急资金凑首付**
4. **单项不可逆投入 ≤ 家庭净资产的 70%**

四条缺一条，**结论一律降级为"等"**。

```
   → ___

   → ___
```

## 中间态设计（抵抗不可逆的最好工具）

大多数不可逆决策，都可以拆出一个**低成本的中间态**：

- 想买房 → 先在同区域租住 6 个月，验证通勤/配套/噪音
- 想换城 → 先接一次 3 个月的远程或短期项目
- 想转行 → 先做 2 个真实付费项目，再辞职
- 想生孩子前换工作 → 先确认新公司产假与稳定性

**先付小钱试错，再付大钱下注。**

---

## 反向判据：什么时候"不行动"才是错的

不可逆性不能变成永久拖延的借口。以下情况应主动行动：

- 窗口期明确且在关闭（征求意见稿已将截止）
- 不行动本身会造成不可逆损失（如资格失效、年龄门槛临近）
- 决策可逆但机会成本极高

**"等"是一种决策，不是不决策。** 等也要给条件：等到什么信号就动。
