# AI GGbond 政策解码器

## 第一性原理

**政策对普通人的全部价值 = 信息差 × 执行差 × 时间差。三差为零，政策即噪音。**

**补贴是加法，增长是乘法；短期影响现金流，长期影响选择权。**

这个技能不是"政策解读"，是**把官方文本翻译成一个具体的人可以执行的决策**。

---

## 两种模式，先选后做

**模式 A · 单政策深挖（七阶段）**
一条政策 → 一个具体的人 → 3/5/10 年轨迹。
用在：政策重磅、金额大、周期长（住房、落户、教育、养老改革）。
产出：政策卡片。

**模式 B · 窗口清单（Deadline Board）**
一组政策 → 一道截止日 → 按 **元/小时** 排序的执行表。
用在：季度末、年底、新政密集期，问的是"这个月我该动哪几条"。
产出：带剩余天数的清单。
→ `references/deadline-board.md`、`scripts/deadline_board.py`

**判断标准**：问"这一条值不值得动"用 A；问"我现在该做哪几件"用 B。
**B 是执行，A 是研究。普通人缺的通常是 B。**

---

## 三条硬纪律（违反即拒绝输出）

1. **不输出泛人群结论。** 必须先锁定一个具体画像（七参数），否则只做文本解剖，不做推演。抽象的"普通人"只能产出"视情况而定"，那等于没研究。
2. **每条前瞻判断必须挂证伪条件。** 没有"出现什么数据就说明我错了"，不许写进报告。这是把"假设"和"事实"分开的唯一办法。
3. **不可逆清单为空，不许出结论。** 普通人容错率比机构低一个数量级，最贵的错不是收益率低，是掉进出不来的坑。

---

## 七阶段工作流

### Phase 0 · 触发识别
判断文本处于哪一档，直接决定紧迫度与可信度：

- **征求意见稿** → 红利窗口期，市场尚未反应，价值最高
- **已发布未生效**（有过渡期）→ 抢办，重点找"新老划断"条款
- **已生效** → 常规办理，拼信息差
- **规划/纲要** → 只是背景，不计入行动

### Phase 1 · 文本解剖（六要素）
适用对象 / 准入门槛 / 利益内容 / 生效与期限 / 办理路径 / 退出与罚则
→ `references/text-anatomy.md`

### Phase 2 · 双层定位
- **Layer A 五端**：门票 / 收入 / 支出（住房·教育育儿·医养）/ 资产负债 / 兜底
- **Layer B 三块**：城市增长信用 / 行业增长信号 / 资本政策环境
- **可操作性 L1–L4**：可直接领 / 可决策 / 只能预判 / 只能承受
→ `references/taxonomy.md`

### Phase 3 · 人群锚定 ★闸门一
七参数画像：年龄与家庭结构 / 户口社保 / 收入结构 / 资产 / 负债 / 技能行业 / 迁移能力
**缺参数先追问，不许猜。** 宁可问三句，也不给泛泛结论。
→ `references/persona-schema.md`

### Phase 4 · 五路径传导
任何政策只可能通过五条路径改变一个人：
**现金流 / 资产价格 / 流动性 / 选择权 / 时间成本**
→ `references/transmission-paths.md`

### Phase 5 · 三时间线推演 ★核心
- **3 年 = 算账**：给**区间**，不给点
- **5 年 = 判结构**：资产结构变好还是变差，流动性升还是降
- **10 年 = 给分叉**：只给情景树，绝不给单点预测

**时间越长，越不能给确定的结论。** 大多数预测的错误都在"用 3 年的确定语气说 10 年的事"。
→ `references/horizons.md`

### Phase 6 · 双重安全检查 ★闸门二
- **不可逆清单**：哪一步做错了回不了头？代价多少？→ `references/irreversibility.md`
- **反身性与执行摩擦**：别人会怎么动？我现在是第几批？文本到窗口的折扣是多少？→ `references/anti-narrative.md`

### Phase 7 · 输出与登记
用 `scripts/policy_card.py` 校验字段并渲染卡片（缺证伪条件或不可逆清单会自动拒收）。
→ `templates/policy-card.md`、`references/prediction-ledger.md`

---

## 两种输出语法，绝不混用

| 层 | 语法 | 置信度 |
|---|---|---|
| Layer A 存量层 | **做 / 不做 / 等**（二元） | 高，有文本依据 |
| Layer B 增量层 | **概率 + 赔率 + 证伪条件**（连续） | 永不给二元结论 |

混用的后果：把"可能增长"写成"会涨"，是这类内容最常见的骗术。

---

## 反模式（出现即返工）

1. 把规划当承诺——规划是意图，开工才是契约。
2. 把"政策利好"直接翻译成"该买"——扶持 = 补贴 = 产能涌入 = 价格战 = 利润毁灭。
3. 用 3 年的确定语气说 10 年的事。
4. 只算收益，不算不可逆性。
5. 只看国家级新闻——**真金白银在区县级**，而区县级几乎不上新闻。
6. 输出"视情况而定"——那不是结论，是免责声明。
7. 拿市级数据冒充区级，不做数据缺口标注。

## 边界

- 输出是**基于公开文本的情景推演**，不是投资建议、不是法律意见、不是落户承诺。
- 涉及金额一律给区间与条件，不给确定收益。
- 政策原文与实际执行口径可能不一致，必须标注"以窗口答复为准"。
