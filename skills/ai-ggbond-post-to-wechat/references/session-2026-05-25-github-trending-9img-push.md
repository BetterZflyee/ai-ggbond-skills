## 关键教训

### 1. 推送耗时公式

每张图片：压缩（3MB→1MB）+ HTTP 上传 = **60-90 秒**
9 张正文图 + 1 张封面 = **12-15 分钟**
这期间 stdout 被缓冲，`process log` 返回空。

**每次重试都从零上传所有图片**（微信素材库不跨请求缓存）。

### 2. 不杀进程铁律

- v1: 成功（10 分钟，exit_code=0）
- v2: 成功（15 分钟，exit_code=0，顺利推送）
- v3 attempt 1: 被杀（exit_code=143，上传完 9 张正文图后在封面上传阶段被杀）
- v3 attempt 2: 被杀（同上）
- v3 attempt 3: 成功（15 分钟，exit_code=0）

每次被杀后重跑都重新上传 9 张图，每次 12+ 分钟。如果不杀 v3 attempt 2，它可能已经推送成功了。
