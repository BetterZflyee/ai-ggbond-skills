# 信息图语义质量门禁

## 为什么只查文字不够

信息图可能中文无乱码、标题完整、配色漂亮，但读者仍然“不明所以”。常见原因是画面只有气氛，没有把文章判断画成可追踪的关系。

典型失败：用发布会、人物背影、深渊、闪电等电影海报元素表达“演示到生产的落差”。画面很酷，却没有说明演示为什么能跑、生产为什么不敢用。

## 生成前：先写逻辑骨架

每张图在写视觉提示词前，先写：

```text
条件/输入 → 变化/机制 → 结果 → 结论
```

例如：

```text
演示环境：数据完整 + 路径固定 + 人工兜底
→ 上线以后
→ 生产环境：数据残缺 + 规则冲突 + 系统割裂 + 责任不清
→ 企业不敢放权
```

无法写出逻辑链时，先不要生图。

## 视觉选择

优先：对比栏、流程图、桥梁、漏斗、矩阵、路线图、因果箭头、明确阅读顺序。

高风险：舞台、观众、人物背影、抽象裂缝、闪电、宇宙、城市剪影。它们只能辅助，不能承担逻辑。若删掉文字只剩“科技气氛”，图大概率不合格。

## 生成后：双重门禁

### 文字门禁
- 逐字核对标题、标签、署名
- 检查乱码、漏字、错字、重复项
- 检查图标内部偷偷出现的英文、软件标志和伪文字

### 3秒语义测试
让一个没读文章的人回答：
1. 图在比较或解释什么？
2. 箭头从哪里到哪里？
3. 为什么产生这个结果？
4. 最终判断是什么？

任何一题需要猜，判定不通过。不得因为美观而放宽。

## 批量顺序

1. 先生成一张代表图。
2. 同时通过文字门禁与3秒语义测试。
3. 再批量生成其余图片。
4. 批量完成后逐张检查；失败图单独重做。

## 图标文字陷阱

模型常在表格、文档、手机、软件图标里自动添加 `X`、`PDF`、假字母或伪文字。提示词应明确：

> 所有图标内部不得出现字母、数字、文字或软件标志；只使用纯图形化图标。

## 重做原则

语义失败时不要微调形容词，应改信息架构：
- “舞台 vs 深渊” → “演示条件 vs 生产问题”
- 抽象转折 → 带文字的因果箭头
- 气氛金句 → 条件、机制、结果、结论四层结构

语义问题靠重构版式解决，不靠增加视觉特效解决。
