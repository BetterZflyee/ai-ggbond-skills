# 微信公众号 2.35:1 封面安全构图与质检

## 核心教训

微信公众号封面是低高度超宽横幅。将 16:9 信息图机械居中裁成 2.35:1，常导致：

- 顶部标题只剩下半截；
- 底部支点、人物或图标贴边/被截；
- 左中右元素平均铺开，缩略图没有视觉中心；
- 明明有大块留白，关键信息却处在裁切框外。

因此，封面必须在最终画布上原生构图，或把已有素材重新排版到最终画布，而不是只做 crop。

## 推荐尺寸

- 严格比例：`1645 × 700`，宽高比精确为 `2.35`
- 兼容常用尺寸：`900 × 383`，宽高比约为 `2.3499`
- 用户明确强调比例时，优先 `1645 × 700`

## 安全构图

1. 标题必须完整位于最终画布内，上下安全边距至少为画布高度的 8%。
2. 核心视觉尽量压成横向结构，避免高耸主体。
3. 底部文案、杠杆支点、人物脚部等不得贴边。
4. 公众号信息流缩略图下，仍应一眼读出标题和单一冲突点。
5. 石墨极简文章配图对应封面：暖白底、石墨黑灰、少量低饱和冷蓝、细线图标、高留白；不要回到霓虹深色科技风。

## 发布前双重质检

### 确定性尺寸检查

```python
from PIL import Image
im = Image.open('cover.png')
w, h = im.size
assert abs(w / h - 2.35) < 1e-9
print(w, h, w / h)
```

### 视觉检查

逐项确认：

- 标题是否完整、无错字和乱码；
- 上下是否有裁切；
- 核心元素是否聚焦；
- 缩小后标题仍清晰；
- 色彩是否与正文排版主题一致。

注意：视觉模型可能根据显示缩放估算出近似像素，真实比例以文件像素读取为准；视觉工具负责构图和文字检查，不替代确定性尺寸检查。
