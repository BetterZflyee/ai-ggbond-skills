# 技能展示类文章的两种模式

日期：2026-05-29
来源：飞哥写 remove-ai-marks 开源文章时的两次纠偏

## 核心区分

技能展示类文章不只有"调查实验型"一种写法。飞哥根据文章目的不同，会选择不同模式：

| 维度 | 模式A：调查实验型 | 模式B：歸藏模式 |
|------|------------------|----------------|
| 一句话 | "我替你做了这个实验" | "我做了个东西，给你看看" |
| 叙事弧 | 发现问题→困惑→实验→踩坑→解法→卧槽 | 故事引入→产物体验→能做什么→怎么用→效果→开源 |
| 文章主角 | 人（的探索过程） | 产物（但用分享欲驱动） |
| 语气 | 侦探、探索、好奇 | 朋友分享好东西、忍不住推荐 |
| 技术深度 | 技术作为"顺手掏出"的补充 | 功能介绍为主，不讲设计决策 |
| 适用场景 | 有真实踩坑经历、探索过程有戏剧性 | 产物已经成熟、直接展示价值 |
| 配图风格 | 调查手记风（软木板、终端截图、手绘笔记） | 按产物特性选（手绘/信息图/截图混搭） |
| 典型案例 | remove-ai-marks v2（被吐槽后重写成功） | 歸藏PPT Skill、花叔达尔文.skill |

## 模式B：歸藏模式详细结构

参考文章：
- https://mp.weixin.qq.com/s/GXjjlxpIJ604HVCCZJkUBA（歸藏 PPT Skill）
- https://mp.weixin.qq.com/s/4ICQJGwa2MD616_oFmJb4w（花叔 达尔文.skill）

### 结构模板

1. **开头故事**（~400字）
   - 一个具体场景：被朋友问到、线下活动后被追问、自己踩了某个坑
   - 自然引出"索性就开源了"
   - 不要讲"为什么做这个"的设计动机，故事本身就在回答这个问题

2. **它长什么样**（~500字）
   - 给读者一个直观感受：装好之后用起来是什么体验
   - 一个 before/after 或第一眼印象
   - 让读者30秒内知道这个东西"大概是什么级别"

3. **它能做什么**（~1200字）
   - 功能清单，白话讲
   - 不堆术语，不列参数表
   - 用"你可能会遇到的场景"来组织，不是用"功能模块"来组织

4. **怎么用**（~1500字）
   - 最常见的2-3个场景，每个场景给完整命令/步骤
   - 复制即用，不要让读者自己猜
   - 包含"踩坑提醒"但不做深度分析

5. **用着怎么样**（~1000字，可选）
   - 真实使用体验、效果对比
   - 或者：设计上的一些巧思（轻描淡写，不是技术分析）

6. **写在最后**（~400字）
   - 开源链接 + 安装方式
   - 一句话升华（不是总结）
   - 金句收尾

### 飞哥的关键约束

- **不要"为什么做成这样"**：设计决策分析会让文章变成产品文档。读者不需要知道你为什么选了A而不是B，他们只需要知道A好用。
- **不要行业科普**：不要单独开一节"AI水印这件事你该知道的"。如果需要背景信息，穿插在功能介绍里自然带出。
- **分享欲驱动**：全文的底层情绪是"我发现了一个好东西，忍不住要分享给你"，不是"我来给你系统讲解这个领域"。
- **总字数控制**：5000-8000字足够，不注水。歸藏原文约3000字，花叔原文约5000字。

## 模式选择决策树

拿到技能展示类选题后，先问自己：

```
这个技能/工具，我有没有一段真实的"探索→踩坑→发现"的经历？
├── 有，而且经历本身有故事性 → 模式A（调查实验型）
└── 没有，或者经历不重要，产物本身才是重点 → 模式B（歸藏模式）
```

或者直接问飞哥："这个你想写成'我替你做了实验'还是'我做了个东西给你看看'？"

## 常见错误

1. **把模式B写成模式A**：飛哥要"分享好东西"，你写成"侦探拆解"——框架对不上
2. **把模式B写成产品手册**：归藏模式≠技术文档。"它能做什么"用场景组织，不用功能模块组织
3. **在模式B里加"设计决策"章节**：飞哥明确拒绝——"不用讲为什么做"
4. **在模式B里加行业科普**：飞哥明确拒绝——"不是科普专家"
5. **字数失控**：模式B的舒适区是5000-8000字，超过8000大概率在注水
6. **在 Hermes Skill 文章里展示 CLI 命令**（2026-05-29 飞哥纠偏）：用户看到 `python3 scripts/clean.py xxx` 会直接退场。改用自然语言——「帮我清除这张图的AI水印」「帮我看看这张图有没有AI标记」。Skill 的价值就是"说中文就能用"，文章必须体现这一点。
