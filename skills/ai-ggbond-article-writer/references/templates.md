# 内容创作模板

## 概览

本文件提供公众号内容创作中常用的模板，包括选题讨论、协作文档、长文转X等场景的标准化格式。

## 选题讨论模板

### 强制规则

- **必须提供 3-5 个不同的选题方向供用户选择**
- **禁止直接生成文章**，必须等待用户选择选题后才能继续
- 用户未选择前，不得进入后续写作步骤

### 标准格式

当需要讨论选题时，提供3-5个选题方向，每个包含以下要素：

```markdown
---

## 选题一: 《[主标题]:[副标题]》

**核心角度**: <一句话说明这个选题的核心观点/切入点>

**工作量**: ⭐/⭐⭐/⭐⭐⭐（1-3星，5星最复杂）(<理由>)

**写作大纲**:
1. <一级标题>
2. <一级标题>
3. <一级标题>
...
（3-7个大标题）

**优劣势分析**:
- ✅ 优势: <为什么这个选题好>
- ❌ 劣势: <可能的挑战或不足>

**是否需要真实测试**: <是/否> (<理由>)

---

## 选题二: 《[主标题]:[副标题]》
...

---

## 选题三: 《[主标题]:[副标题]》
...

---

## 选题四: 《[主标题]:[副标题]》（可选）
...

---

**请告诉我您想选择哪个选题？或者如果您有其他想法，请告诉我。**

⚠️ 注意：在您选择之前，我不会开始撰写文章。
```

### 配图流程

```
1. 分析文章，确定配图需求
   - 识别关键概念、产品界面、数据图表、流程图等
   - 确定每个位置需要的图片类型

2. 创建图片文件夹
   - 在文章目录下创建 `images/` 文件夹
   - 按顺序命名：`01-cover.png`, `02-infographic.png`, `03-xxx.png`...

3. 获取/生成图片（优先级从高到低）：
   ① 公共领域图片：Unsplash、Pexels等免费图库
   ② AI生成图片：使用Nana API或其他AI绘图工具
   ③ 免费图库搜索：根据关键词搜索相关图片
   ④ 截图：产品界面、数据图表等

4. 在Markdown插入图片
   - 格式：`![图片说明](images/xx.png)`
   - 在需要配图的位置标注 [图片]

5. 验证图片显示
   - 确保图片路径正确
   - 确保图片能正常加载
```

## 自然段落结构文章示例

### 完整文章示例（推荐格式）

```markdown
# 《别被"超级个体"忽悠了：未来5年，普通人到底该怎么走？》

📊 约 3000 字 · 建议阅读 10 分钟
#超级个体 #职业发展 #AI时代

> 来源摘要：本文基于对"超级个体"概念的深度调研、行业观察以及作者的个人思考

## 什么是"超级个体"

说起来，"超级个体"这个概念最近火得不行。打开手机，到处都是"一个人抵一个团队"、"AI让你成为超级个体"的说法。

听起来很诱人，对吧？

上周在星巴克和几个朋友聊天，大家都在讨论这个话题。有人说要学AI，有人说要搞副业，有人说要做自媒体。好像不成为"超级个体"，就要被时代抛弃了一样。

但说实话，我对这个概念有点不一样的看法。

## 为什么我说这是个坑

先别急着反驳我，听我说完。

我折腾AI折腾了大半年，踩了不少坑。最开始也是被"超级个体"这个概念吸引的，觉得有了AI工具，一个人就能干翻一个团队。

结果呢？

学了一堆工具，买了无数课程，最后发现自己什么都没做成。精力分散在太多方向上，反而把原本擅长的事情给荒废了。

这让我想起上周和圈子里一个大佬的聊天。他说了一句话让我印象很深："所谓的超级个体，本质上是把多个岗位的工作量叠加到一个人身上。你以为是在赋能，其实是在透支。"

这个观点，让我开始重新思考这个问题。

## 普通人到底该怎么走

那问题来了，普通人该怎么办？

我觉得核心就一句话：**找到自己的不可替代性，然后用AI放大它，而不是用AI替代它。**

具体来说，可以分三步走：

**第一步，搞清楚自己到底擅长什么。** 不是AI能帮你做什么，而是你本身有什么独特价值。可能是行业经验，可能是人脉资源，可能是某种思维方式。这个是AI替代不了的。

**第二步，把AI当作杠杆，而不是替代品。** 比如你擅长写作，AI可以帮你提高效率，但不能替代你的观点和洞察。你擅长沟通，AI可以帮你整理资料，但不能替代你的情商和判断。

**第三步，专注一个方向，做到极致。** 不要什么都想学，什么都想做。与其成为"万金油"，不如在一个细分领域做到不可替代。

## 写在最后

折腾了大半年，我最大的感悟是：工具再好，也只是工具。

真正的"超级个体"，不是学会了多少AI工具，而是清楚自己要什么、能做什么、该放弃什么。

如果你也在迷茫，不妨停下来想想：你真正想成为的，到底是什么样的个体？

希望对你有点启发。
```

### 格式要点总结

**小标题设计**：
- ❌ 避免：`## 01. 什么是超级个体`
- ✅ 推荐：`## 什么是"超级个体"`
- 标题是完整句子或短语，带有情感或观点

**段落过渡**：
- 用问题过渡：「那问题来了，普通人该怎么办？」
- 用转折过渡：「但说实话，我对这个概念有点不一样的看法。」
- 用故事过渡：「这让我想起上周和圈子里一个大佬的聊天...」

**段落长度**：
- 每段3-5行
- 段落之间空一行
- 避免大段文字墙

**自然对话感**：
- 使用口语化表达：「说起来...」「说实话...」「折腾了大半年...」
- 适当使用短句：「听起来很诱人，对吧？」「结果呢？」
- 加入个人经历和故事

## 个人IP融入模板

### 踩坑经历型

```markdown
我在折腾这个项目的时候，踩过一个坑。当时我以为是这样，结果发现完全不是那么回事...

具体来说，我遇到的问题是...。折腾了大半天，最后发现原来是因为...
```

### 工作流分享型

```markdown
我自己平时用这套工作流处理类似的需求。说实话，一开始我也觉得麻烦，但养成习惯后发现效率提升很明显...

这套工作流的核心是...，具体步骤是...
```

### 圈内交流型

```markdown
上周和圈子里一个大佬聊到这个问题，他说了一句让我印象很深的话："..."

我觉得这个观点挺有意思，因为...
```

### 个人偏好型

```markdown
我自己更喜欢用A而不是B，不是因为A功能更多，而是它的某个细节设计特别符合我的工作习惯...

具体来说，A在...方面做得更好...
```

### 成长反思型

```markdown
关于这个问题，我的认知其实经历过几次迭代。最早我是这样想的，后来经过几次实践，现在我的看法是...

这个认知转变的关键节点是...
```

## 使用建议

1. **选题讨论**：不要跳过，先讨论再创作
2. **协作文档**：测试任务复杂时创建，简单任务可省略
3. **长文转X**：X版本要精炼，抓住核心观点
4. **文件命名**：严格按照规范，方便管理和检索
5. **定期整理**：知识库要定期更新和清理
