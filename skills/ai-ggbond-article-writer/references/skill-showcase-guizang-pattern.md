## 核心结构（歸藏模式）

歸藏那篇的结构拆解：

1. **开头故事**（~200字）：一个具体场景引入（私享会后被问"PPT什么做的"→决定开源）
2. **它长什么样**（~300字）：给读者直观感受——第一眼看到产物是什么感觉
3. **它能做什么**（~800字）：功能介绍，白话讲，不堆术语
4. **怎么用**（~800字）：最常用的场景，用自然语言描述
5. **为什么做成这样**（~800字）：设计决策背后的思考（可选，飛哥说可以不要）
6. **写在最后**（~300字）：开源链接 + 金句收束

花叔那篇的结构略有不同（更偏方法论科普），但核心一样：**故事引入 → 正面介绍 → 开源**。

## 与「调查实验型」的关键区别

| 维度 | 调查实验型（v1→v2模式） | 歸藏模式 |
|------|----------------------|---------|
| 叙事弧 | 发现问题→困惑→实验→踩坑→卧槽结果 | 故事引入→长什么样→能做什么→怎么用→开源 |
| 适用场景 | 自己做的工具、有真实踩坑经历 | Skill/工具开源，重点在推广 |
| 文章重心 | 人的实验和发现 | 工具本身的介绍和使用 |
| 知识输出 | 聊着聊着顺手掏出来 | 正面介绍，白话讲 |
| 飞哥典型需求 | "写一篇关于XX技能的文章" | "开源我的XX Skill" |

**选择标准**：
- 飞哥说"开源""介绍一下这个Skill" → 歸藏模式
- 飞哥说"写写我怎么发现的""踩坑经历" → 调查实验型
- 不确定时，先问飞哥

## 五条铁律（本次踩坑总结）

### 1. 用法必须是自然语言，不是代码块

❌ 错误：
```bash
python3 scripts/clean.py input.png -o clean.png
```

✅ 正确：
> 帮我清除这张图的AI水印：images/cover.png

飞哥原话："用户看到 python3 scripts/clean.py 就会退场了。应该告诉用户一些中文指令。"

**规则**：Skill 文章的"怎么用"部分，所有用法都用引用块展示自然语言指令。代码块只在开发者文档中使用，不出现在公众号文章里。

### 2. 绝不暴露上游依赖

❌ 错误："折腾了一圈，最后找到了 wiltodelta/remove-ai-watermarks 这个开源库"

✅ 正确："折腾了一圈，我决定自己写一个专门干这件事的 Skill"

飞哥原话："这句话暴露了技能不是我原创的。"

**规则**：文章中不提及底层库/框架/第三方项目名称。只说"我写了一个Skill"、"我自己研究了一套方法"。技术实现细节留给 GitHub README，不在公众号文章里交代。

### 3. 结尾必须锚定用户痛点，不是通用哲学

❌ 错误：
> 知不知道，和用不用，是两件事。
> 但你至少应该知道。

✅ 正确：
> 平台把溯源信息变成了降权信号，塞进推荐算法里，从来没告诉过创作者。
> 用AI提效就被降权，不用AI跟不上节奏。
> 这个 Skill 做的事，就是把选择权还给你。

飞哥原话："这结尾讲的什么狗屁啊，我最终的目的是推广我的技能。"

**规则**：结尾的逻辑链必须是：
1. 揭示用户不知道的真相（平台在偷偷降权）
2. 指出用户的困惑（你以为是自己的问题）
3. 点明两难困境（用AI被降权，不用AI跟不上）
4. Skill 作为解法（把选择权还给你）

### 4. 站在普通人分享欲上，不是科普专家

飛哥纠偏："你要站在普通人的分享欲上面，而不是一个科普专家，不用讲为什么做。"

**规则**：
- 去掉"为什么做成这样"的设计决策分析段落
- 去掉"AI水印你该知道的"科普段落
- 保持"我发现了好东西，给你看看"的调性
- 不是"我来给你分析为什么这样设计"

### 5. 标题前缀可带"开源我的XX Skill"

飛哥给的标题公式：`开源我的[技能名]：[故事性副标题]`

示例：
- 开源我的去AI水印Skill：我把AI生图的"身份证"撕了
- 开源我的XX Skill：[好奇心/反差/利益驱动的副标题]

## 完整流程（歸藏模式）

```
步骤1: 确认飞哥要的是"歸藏模式"还是"调查实验型"
步骤2: 确认标题（前缀"开源我的XX" + 副标题）
步骤3: 写故事开头（具体场景引入，不要"在AI快速发展的今天"）
步骤4: 写"它长什么样"（直观感受，before/after）
步骤5: 写"它能做什么"（白话讲功能，不堆术语）
步骤6: 写"怎么用"（自然语言指令，引用块展示，零代码块）
步骤7: 写结尾（锚定用户痛点，揭示平台真相，Skill作为解法）
步骤8: 洁净度自检（去AI味、活人感、无代码块、无上游依赖暴露）
步骤9: 配图（调查手记风或归藏风格，按文章内容选）
```
