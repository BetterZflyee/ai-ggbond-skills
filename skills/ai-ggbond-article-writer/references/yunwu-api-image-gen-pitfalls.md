# 云雾 API 生图踩坑记录

## gpt-image-2 渠道极不稳定

通过 yunwu.ai 调用 gpt-image-2 时，频繁出现以下问题：

| 错误 | 含义 | 解法 |
|------|------|------|
| 429 `model_not_found` | 当前分组不支持该模型或渠道耗尽 | 等待恢复，无预判方法 |
| 429 `上游负载已饱和` | 限流 | 等 60-120 秒重试 |
| ReadTimeout (180s+) | 模型生成太慢，连接超时 | 重试或换时间段 |
| 401 `无效的令牌` | API Key 问题 | 检查 Key 是否正确加载 |

- 2026-05-15 约 15:27-15:35 期间短暂可用（仅生成1张 cover）

### 降级策略

当 gpt-image-2 不可用时，按优先级：

1. 等待重试 — 每 30 分钟自动检测一次
2. 用户手动生成 — 去 ChatGPT 官网 (chat.openai.com) 用 GPT-4o 生图，提示词由 Agent 准备好
3. 换模型 — gpt-image-1 可用但质量差，不推荐
