# 微信公众号 HTML 排版铁律（2026-05-25 飞哥纠偏）

## 触发场景
飞哥说"排版差透了""你没有完全按技能要求来"时，说明 HTML 排版没有遵循这些铁律。飞哥参考模板：https://mp.weixin.qq.com/s/3vW27TzgJiayb6SP7meD6g

## 四条死线（违反任一条 = 重做）

### 1. 正文内绝对不出现标题和副标题
- 标题放在微信公众号草稿箱标题栏
- 副标题/摘要放在草稿箱摘要栏
- HTML `<body>` 直接从正文第一句开始
- 禁止：`<h1>`、居中大字标题、副标题行

### 2. 必须大量加粗关键概念
- **每个项目名**：codegraph、agentmemory、superpowers 等全部加粗
- **每个核心判断**："建心智地图""长期记忆才是资产""别乱来"全部加粗
- **每段至少 1-2 处加粗**，不能让读者扫过去全是普通字
- 用 `<strong>` 而非 `<b>`

### 3. 章节标题简洁清晰
- `<h2>` 就够了，不要叠分隔线、徽章、色块
- 字体 18px，黑色加粗
- 参考文章格式：`## 一、核心事件` → `<h2>一、核心事件</h2>`

### 4. 引用用 blockquote 蓝底左边框
- 德鲁克、芒格、布鲁克斯等人的名言
- 样式：`border-left:3px solid #3366CC; background:#EEF3FB; padding:12px 16px`
- 引用原文加粗

## CSS 令牌参考
```
正文色: #2B2B2B
引用蓝: #3366CC
引用底: #EEF3FB
正文: 15px, line-height 1.9, text-align justify
h2: 18px, font-weight 700
blockquote padding: 12px 16px, margin 20px 0
a: color #3366CC
```

## 常见错误对照

| 错误 | 正确 |
|---|---|
| 正文有 H1 标题 | 标题只放草稿箱 |
| 正文有副标题行 | 副标题放摘要栏 |
| 章节前加分隔线装饰 | 干净的 h2 即可 |
| 图片加阴影 box-shadow | 简洁 border-radius:8px |
| 项目名没加粗 | 全部 `<strong>` |
| 引用用暖色底 | 用蓝底 #EEF3FB |
| 正文用科技蓝配色 | 白底黑字为主，少量蓝点缀 |
