# 飞哥个人品牌故事写作模式

> 2026-05-26 从"影响力半径"文章实战中沉淀的模式与教训。

## 核心约束（铁律）

1. **禁止行业标签**：不能写"物业行业数字化""制造业AI方案""政企数据分析"等。任何把飞哥锁进一个行业的表述都是错的。飞哥明确说："不要突出物业行业，要突出复杂系统，因为行业会存在鄙视链。"
2. **禁止能力标签**：不能写"项目经理""数据分析师""AI架构师"等。能力标签和行业标签一样，把人装进格子里。
3. **必须写成长路径**：不是"我做了什么"，是"我是怎么一步步变成今天这个样子的"。

## 成长隐喻驱动（最重要）

品牌故事的核心是找到一个**成长隐喻**——一个贯穿全文的具象概念，用来标记成长阶段。

**成功案例（本次）**：
- 隐喻：「影响力半径」——从1米 → 一层楼 → 一座城 → 一个行业 → 无限大
- 效果：每一段经历都变成这个隐喻的一个刻度，读者能直观感受"成长"

**失败案例（被飞哥否决）**：
- 「让自己变得没用」——角度太悲观
- 「翻译官」——太像能力标签
- 「复杂系统操盘手」——太像行业标签
- 「反直觉专业户」——太轻浮

**隐喻选择的教训**：
- 必须**正向**——传播、扩散、生长，不是退出、消失、不重要
- 必须**可度量**——读者能直观看到变化，不是抽象的"我成长了"
- 必须**脱离行业和能力**——半径和行业无关，任何人都能投射自己

## 选题流程（品牌故事专用）

1. 飞哥给主题后，先判断是不是品牌故事
2. 不要用常规的"3-5个选题"框架——品牌故事的核心是**找到隐喻**，不是找角度
3. 提供3-5个**不同隐喻**的选题方向
4. 每个选题标注情感基调（正向/积极/向上），避免悲观隐喻
5. 飞哥选隐喻后，再展开大纲

## 引经据典规范

飞哥明确要求品牌故事必须**引经据典**。

**引用块格式**：
```
> *「原文」*
>
> ——《出处》第X章
>
> *白话释义*
```

**引用分布要求**：
- 引言区：1个点题引用（如《道德经》"道生一"）
- 每个成长阶段：至少1个引用的经典匹配
- "驱动力"章节：1-2个引用 + 1-2个科学理论
- 结尾：1个升华引用

**本次实战引用清单（11处）**：
- 引言：《道德经》第四十二章
- 半径1米：《周易·系辞下》"穷则变"
- 半径一层楼：麦克卢汉《理解媒介》
- 半径一座城：王阳明《传习录》
- 半径一个行业：《孙子兵法·势篇》+ 维纳控制论
- 半径无限大：《道德经》第八十一章 + 梅特卡夫定律
- 驱动半径：《庄子·养生主》+ 考夫曼相邻可能
- 下一个十年：梅多斯《系统之美》+ 《道德经》第四十八章
- 结尾：《道德经》第七章

## 科学理论贯穿规范

飞哥要求善用数理理论、心理学、博弈论、控制论等辅助表达。

**理论植入技巧**：
- 每个理论只出现一次，服务于当前论点
- 先讲故事，再讲理论——"这里有一个XX领域的概念叫'XXX'"
- 理论必须和飞哥亲身经历挂钩
- 引用原文 + 白话转译

**本次使用的理论**：最后一公里问题（系统工程）、反馈回路（控制论/维纳）、梅特卡夫定律、相邻可能（考夫曼）、边际效用递增

## Markdown 高级排版规范

- 章节标题：`## 半径1米 · 一台电脑，一个项目`（`·` 分隔）
- 引用块：三行格式（原文 → 出处 → 白话释义）
- 分隔线：章节间使用 `---`
- 表格：用于总结对比
- 加粗分布：每200字至少一处加粗核心判断

## 写作禁忌

- ❌ 不要写成简历
- ❌ 不要写成方法论
- ❌ 不要突出行业标签
- ❌ 不要悲观隐喻
- ✅ 要找成长隐喻
- ✅ 要正向积极
- ✅ 要引经据典
- ✅ 要科学理论
- ✅ 要高级 Markdown 排版
