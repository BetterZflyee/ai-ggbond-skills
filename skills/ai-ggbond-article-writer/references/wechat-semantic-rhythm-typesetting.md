# 微信公众号长文语义节奏排版规则（飞哥纠偏记录）

适用场景：给飞哥的公众号长文做 Markdown/HTML 精排，尤其是 AI 行业观察、方法论、产品拆解类长文。

## 核心原则

**分段不是按句号切，也不是为了视觉短段而切；一段应承载一个完整的语义动作。**

飞哥的原话要点：
- “你要等你的逻辑说完，这样一定会长短句相结合。”
- 分段的逻辑由上下文决定：转折、逻辑结束、表达动作完成，才断。
- 不要机械“一句话一段”；也不要为了避免碎而合成大段文字墙。

## 正确分段判断

### 应该放在同一段

1. **总起句 + 展开句**
   - 错误：
     ```text
     下半场，问题变了。

     它能不能接入我的文件？能不能调用工具？……
     ```
   - 正确：
     ```text
     下半场，问题变了。它能不能接入我的文件？能不能调用工具？能不能在安全环境里执行？能不能把设计、代码、浏览器、数据库放进同一个上下文？能不能留下日志，方便我接管？能不能部署在企业自己的环境里？
     ```
   - 理由：第一句只是引子，后面的连续追问才把意思说完。

2. **判断句 + 解释句**
   ```text
   这不是“又多了几个 AI 工具”。这是 AI 工具进入下半场的信号。
   ```

3. **同一组排比、连续追问、连续例证**
   ```text
   你让它写方案，它写了。你还要复制到 Word 里改格式。你让它分析竞品，它给了框架。你还要自己打开网页、截图、整理表格。
   ```

4. **体验递进属于同一个表达动作**
   ```text
   刚开始很震撼。后来开始麻木。再后来会发现，AI 好像什么都能说，但很多事还是要自己做。
   ```

### 应该断段

1. 观察结束，进入判断。
2. 一个判断完成，进入下一层结论。
3. 发生转折、对比、场景切换。
4. 论证完成后落到金句。
5. 章节、小节或情绪段落切换。

## 金句断点规则

“金句断点”是编辑策略，不是正文标题。**绝对不要把“金句断点”几个字写进正文。**

飞哥偏好：
- A 为主：正文自然加粗短句。
- B 极少量：独立金句卡片，默认不超过 3 个；如果引用卡片超过 2 个，独立金句卡片最多 1 个。
- C 少量：引用卡片点缀。

金句应该是前面逻辑推导后的落点，不是额外贴上去的装饰。

示例：
```text
真正的变化不是聊天窗口变聪明了。真正的变化是，AI 正在从一个“回答问题的东西”，变成一个“进入现场的系统”。

**工具负责回答，系统负责交付。**
```

## 引用规则

- 引用卡片样式可以保留：左侧蓝色竖线 + 浅灰背景。
- 所有引用原文必须加粗。
- 引用解释句不必全部加粗，避免整块过重。
- 最后的洞察句可再次加粗。
- **引用卡片和独立金句卡片不要连续出现**：同一个语义落点只能选择一种视觉强调。若一个原创判断后面紧跟名人引用，默认把原创判断留在正文里自然加粗，不要做成独立金句卡片。

错误示例：
```text
[独立金句卡片]
真正改变行业的工具，往往不是一开始最完美的那个，而是第一个把旧流程压缩掉的那个。

[引用卡片]
《创新者的窘境》作者克莱顿·克里斯坦森提醒我们：破坏性创新往往从“不够完美”的边缘开始。
```

正确处理：
```text
真正改变行业的工具，往往不是一开始最完美的那个，而是第一个把旧流程压缩掉的那个。

[引用卡片]
**《创新者的窘境》作者克莱顿·克里斯坦森提醒我们：破坏性创新往往从“不够完美”的边缘开始。**
```

示例：
```text
**《孙子兵法》孙武说：“胜兵先胜而后求战，败兵先战而后求胜。”**

放到今天，就是：真正会用 AI 的人，不是临时打开工具求救，而是在开战前就把工作流准备好了。

**AI 时代的“先胜”，就是任务到来之前，工作流已经在场。**
```

## 图片与元信息洁净度规则

- **不要插入阅读元信息行**：禁止在正文标题下生成 `📊 约 xxxx 字 · 建议阅读 x 分钟 · 点击右上角🎧可听阅`。
- **不要显示图片图注**：图片下方不要出现 `全文核心信息图：...`、`配图：...`、`图片说明：...` 等可见文字。
- **alt 文本只用于图片可访问性/上传识别，不得渲染为正文可见 figcaption**。
- 图片是视觉断点，不是二次标题。章节标题已经承担导航作用，图注再出现会造成噪音。

## 发布前洁净度自检

发布前必须全文搜索并删除以下可见文本：
- `建议阅读`
- `点击右上角`
- `全文核心信息图`
- `配图：`
- `图片说明`
- `<figcaption`

视觉重组件密度自检：任意两个重组件之间至少间隔 2 个自然段。重组件包括：图片、引用卡片、独立金句卡片、CTA 卡片。若页面显得不干净，优先删除装饰，保留正文。

## 推荐工作流

1. 先拿 800-1000 字做“语义节奏样稿”。
2. 让飞哥确认节奏后，再处理全文。
3. 生成 HTML 精排预览版，不直接推送公众号。
4. 预览确认后，再用 `ai-ggbond-post-to-wechat` 发布到草稿箱。

## 与发布技能的边界

`ai-ggbond-post-to-wechat` 主要负责 Markdown/HTML 转换、图片上传、封面上传、草稿创建；它不是精细排版设计器。若飞哥明确说“HTML 精排版”，应在 article-writer 阶段先生成可预览 HTML，再交给 post-to-wechat 推送。
