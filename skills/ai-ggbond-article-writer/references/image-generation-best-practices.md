# 图片生成最佳实践指南

## 概述

本文档总结了在使用AI生成微信公众号文章配图时的最佳实践，特别是针对中文内容生成的优化方案。

---

## 常见问题与解决方案

### 问题1：图片内容全是英文

#### 症状
- 生成的图片标题、标签、说明文字都是英文
- 即使提示词用中文描述，模型仍输出英文内容

#### 根本原因
1. 部分图像模型（如Gemini系列）对中文的支持不够稳定
2. 复杂提示词结构下，模型倾向于使用英文输出
3. 提示词中没有**强制要求**必须使用中文

#### 解决方案

**1. 使用中文友好的模型（推荐）**
```python
model="gpt-image-2"
```

**2. 在提示词中强制要求中文**
```
【强制要求】
- 所有文字必须使用简体中文，绝对禁止出现英文
- 标题："中文标题"
- 标签："中文标签"
- 任何文字都必须是中文
```

**3. 使用引号明确标注中文内容**
```
标题必须显示为："从AI工具到AI团队的进化"
副标题必须显示为："多Agent协作网络"
```

**4. 添加负面约束**
```
【禁止事项】
- 绝对禁止出现英文文字
- 绝对禁止出现乱码或无法识别的字符
- 绝对禁止出现拼音代替中文
```

---

### 问题2：图片结构与章节内容无关

#### 症状
- 生成的图片虽然美观，但与文章具体内容的契合度不够
- 图片展示的是通用概念，而非文章中的具体观点、案例或流程
- 读者无法从图片中获得文章的核心信息

#### 根本原因
1. 提示词过于**通用和模板化**，没有紧密结合文章的具体内容
2. 提示词设计时更多关注了视觉风格，而忽略了内容的准确性
3. 没有从文章中提取**核心观点、关键案例、具体流程**来指导图片生成

#### 解决方案

**1. 从文章提取具体内容生成提示词**
```python
# 1. 读取文章并提取关键信息
with open("文章.md", 'r', encoding='utf-8') as f:
    content = f.read()

# 2. 提取章节标题和核心要点
sections = extract_sections(content)  # 提取章节结构
key_points = extract_key_points(content)  # 提取核心观点

# 3. 基于具体内容构建提示词
prompt = f"""
创建章节配图，主题是：{section_title}

【必须展示的具体内容】
- 核心观点1：{key_points[0]}
- 核心观点2：{key_points[1]}
- 案例：{case_example}
- 数据：{specific_data}

【视觉元素要求】
- 必须包含：{specific_visual_elements}
- 必须展示：{article_specific_content}
"""
```

**2. 提示词结构模板（内容导向）**
```
创建一张微信公众号章节配图，16:9横版。

【文章章节主题】
{章节标题}

【必须展示的核心内容】（基于文章实际内容）
1. {核心观点1 - 直接引用文章}
2. {核心观点2 - 直接引用文章}
3. {具体案例 - 文章中的实例}
4. {关键数据 - 文章中的数字}

【视觉元素要求】
- 必须包含的视觉元素：{与内容相关的具体元素}
- 必须展示的场景：{文章描述的具体场景}
- 必须体现的关系：{文章中的逻辑关系}

【文字要求】
- 标题："{章节标题}"
- 要点标签："{要点1}"、"{要点2}"、"{要点3}"
- 所有文字必须是简体中文
```

**3. 内容关联性检查清单**
- [ ] 图片标题是否与章节标题一致？
- [ ] 图片是否展示了章节的核心观点？
- [ ] 图片是否包含文章中的具体案例/数据？
- [ ] 图片中的文字是否与文章内容一致？
- [ ] 图片视觉元素是否与文章主题相关？

### 问题3：中文文字乱码或无法识别

#### 症状
- 图片中的中文文字显示为乱码
- 文字模糊不清，无法阅读
- 出现"天书"般的字符

#### 解决方案

**1. 使用中文优化模型**
```python
model="gpt-image-2"
```

**2. 在提示词中明确要求**
```
【文字质量要求】
- 所有中文文字必须清晰可辨
- 字体必须标准规范
- 绝对禁止乱码、模糊、变形
- 每个字都必须准确无误
```

**3. 生成后验证**
- 生成图片后立即查看文字清晰度
- 如发现乱码，立即重新生成
- 可使用OCR工具验证文字准确性
