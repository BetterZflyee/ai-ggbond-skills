# 微信公众号贴图写作模式

贴图是独立的短内容（500字内），不是长文的推荐文案。写法和长文完全不同。

## 核心定位：普通人分享新奇东西

**不是**分析师评论、不是行业报告、不是深度思考。
**是**你刷到一个东西觉得有意思，转头分享给朋友。

## 反面案例（AI味/分析师味）

```
❌ "我想了半天，这事挺有意思。"        → 分析师腔
❌ "这个行业的特点是..."               → 行业报告
❌ "有人问：保险销售会失业吗？说实话，不知道。" → 理中客
❌ "一句话总结：AI把买保险变简单了，才是"  → 金句总结腔
❌ "我觉得有意思的不是'AI抢饭碗'"       → 观点输出
```

## 正面案例（普通人分享味）

```
✅ "刚刷到一个东西，真的惊到我了。"      → 发现新事物的反应
✅ "你没看错。"                        → 跟朋友确认
✅ "我第一反应是：扯呢吧？"              → 真实心理
✅ "你可能觉得，这不就是个高级客服？还真不是。" → 对话感
```

## 开头模式：荒诞事实

直接抛出一个让人"？？？"的事实，制造好奇心。

```
有个事情挺魔幻的。
一个 AI，前两天卖出去了一份保险。

刚刷到一个东西，真的惊到我了。
有个 AI，自己把保险卖出去了。
```

**禁止**：
- "在当今AI快速发展的时代..."
- "最近有个新闻引起了我的注意..."
- "今天给大家分享一个..."

## 升番节奏（三层递进）

### 第一层：事实（what）
抛出核心事实，制造惊讶。

### 第二层：反差（so what）
打破读者的预设判断。

```
你可能觉得，这不就是个高级客服？
还真不是。
它能根据你的情况出方案，能回答各种刁钻问题...
```

### 第三层：认知跃迁（now what）
把读者带到一个新视角。

```
所以这事有意思的地方，不是"AI抢饭碗"。
而是买保险这事，可能真要变简单了。
主动权跑你手里了。
```

## 弱者思维

- 用"我"的视角，承认自己的局限
- "我第一反应是：扯呢吧？"
- "我一开始也觉得..."
- "后来想了想，简单的确实能。"
- 不替读者下判断，留白让读者自己想

## 结尾模式

简洁收尾，不做金句总结。给信息来源即可。

```
Kinro AI 官网 kinro.com，感兴趣的可以看看。
来源是 Y Combinator 推特，昨天刚发的。
```

**禁止**：
- "一句话总结：..."
- "所以你看，..."
- "这说明了什么？"

## 格式规范

- 短句为主，一句一段
- 分隔线 `---` 区分语义段
- 500字以内
- 不用标题格式（# ## ###）
- 不用加粗强调（已经够短了，加粗反而显得刻意）

## 与长文的区别

| 维度 | 长文 | 贴图 |
|------|------|------|
| 定位 | 深度分析/认知框架 | 分享新奇事物 |
| 角度 | 陌生化+科学骨架 | 反差+好奇心 |
| 开头 | 叙事/荒诞/热点 | 荒诞事实 |
| 节奏 | 升番+800字一次认知升级 | 三层递进（事实→反差→跃迁） |
| 结尾 | 引用/哲思/行动呼吁 | 简洁信息来源 |
| 字数 | 8000-12000 | 500以内 |
| 加粗 | 核心判断句必须加粗 | 不用加粗 |
