# 选题策划阶段踩坑记录

## 1. 热点事件选题"围着事件转"而非"借事件说事"（2026-05-18）

**症状**：用户说"围绕XX热点写文章"，你给出的选题全部以热点事件为核心（事件还原、技术拆解、影响分析），没有一个选题跳出事件本身。

**根因**：把"切入点"理解成了"主题"。用户说"切入点"意味着事件是门，文章是房间——门只是让你进去，房间里的东西才是重点。

**修复**：选题策划时强制区分两个维度：
- **叙事锚点**（热点事件）：用于吸引点击、建立话题感
- **认知落点**（深层理解框架）：读者读完后获得的认知升级

每个选题可以用同一个事件做叙事锚点，但认知落点必须各不相同。

**验证方法**：去掉热点事件的名字，文章标题是否仍然能独立成立？如果不能，说明认知落点太浅。

**实战案例**：
- ❌ 错误：围绕Figure AI直播写了5个选题，每个都是"从直播看XX"
- ✅ 正确：5个选题都用Figure AI直播做引子，但认知落点分别是——具身智能本质认知、技术路线之争、工程vs技术、形态之争、认知框架建立

## 2. 选题迭代只修不重构（2026-05-18）

**症状**：用户拒绝了第一轮选题并给出方向反馈，你在第二轮只是在原选题基础上"加了点深度"，没有从根本上改变认知落点。

**根因**：没有真正理解用户的纠正信号。用户说"要更深度"通常不是"加字数"，而是"改方向"。

**修复**：
- 第二轮选题必须基于用户反馈**彻底重构**选题框架，不能在原选题上打补丁
- 分析用户纠正语言中的**关键词**——如用户说"更深刻的去谈整个具身智能的认知以及理解"，核心词是"认知"和"理解"，不是"Figure AI"

**实战案例**：
- 第一轮：5个选题全部以Figure AI为核心→被拒（"应该更深刻去谈整个具身智能的认知"）
- 第二轮：5个选题以具身智能认知为核心，Figure AI降为引子→被选中
- 关键转变：从"Figure AI怎么样"→"通过Figure AI我们该怎么理解具身智能"

## 3. "由浅入深"不等于"从短到长"（2026-05-18）

**症状**：用户要求"由浅入深"，你理解为"先写简单内容再写复杂内容"，文章前半段像科普、后半段像论文。

**根因**：把"由浅入深"理解成了"由易到难"，而不是"由现象到本质"。

**修复**："由浅入深"的正确含义是认知层次的递进：
1. 浅 = 现象层（发生了什么、看到了什么）
2. 中 = 概念层（是什么、不是什么、常见误解）
3. 深 = 本质层（底层逻辑、为什么是这样）
4. 最深 = 规律层（产业逻辑、演进趋势、预判）

每一层都要有独立的价值，不是"前面是后面的铺垫"，而是"每一层都让读者的认知升级一格"。
