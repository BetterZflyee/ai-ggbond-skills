# 配图风格混合策略（2026-06-07 补充）

## 问题背景

飞哥在《睡觉时公司自己变好了》文章中发现：章节配图用手绘风格太"软"，缺乏科技感。要求章节图换成高密度信息大图的科技蓝图风格。

## 铁律：封面/信息图 vs 章节图可以不同风格

| 配图类型 | 推荐风格 | 原因 |
|---------|---------|------|
| 封面图 | 手绘信息图 / 暖色科技风 | 吸引点击，有"人味" |
| 信息图（五层模型等） | 手绘信息图 | 展示框架，温暖亲切 |
| 章节配图 | **科技蓝图**（深蓝底+亮蓝线条） | 专业感、技术感、高密度 |

## 科技蓝图风格 prompt 模板

```
高密度信息大图风格，科技蓝图配色（深蓝背景#0a1628，亮蓝线条#00d4ff，白色文字）。
[具体内容描述]
像论文Figure一样的专业技术示意图。中文标注。无水印。
```

## 使用场景

- 技术架构图、流程图、对比图 → 科技蓝图
- 方法论框架、概念图 → 手绘信息图
- 数据图表、增长曲线 → 科技蓝图
- 个人故事、观点类 → 手绘信息图

## 关键：先确认风格再生成

配图前必须和用户确认：
1. 封面图风格（手绘/科技/暖色）
2. 信息图风格
3. 章节图风格（可以和封面不同）
