# Taste-Skill 视觉品味方法论吸收记录（文章配图专用）

**来源**：[Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill)
**吸收日期**：2026-05-29
**用途**：提升文章配图的视觉品味，打破AI图片默认模式

## 核心问题

AI生成的信息图/配图会塌缩成重复的默认模式——紫色渐变、居中hero、漂浮气泡、弱字体层级。taste-skill 通过"旋钮系统"和"反默认纪律"主动打破这些。

## 配图生成前必做：设计解读

在生成任何配图之前，先输出一行设计解读：

```
解读为：为[目标受众]做的[内容类型]，采用[视觉语言]风格，倾向[具体方案]。
```

示例：
- "解读为：为AI爱好者做的技术拆解信息图，采用学术高密度风格，倾向白底黑字+技术标注。"
- "解读为：为普通读者做的行业观察配图，采用手绘信息图风格，倾向暖色调+高留白。"

## AI配图10大默认陷阱（必须打破）

| 默认陷阱 | 为什么是陷阱 | 打破方式 |
|----------|-------------|----------|
| 居中深色hero | 所有AI图都长这样 | 改用左下角、右上角、全出血背景 |
| 紫色/蓝色AI辉光 | 千篇一律的"科技感" | 根据内容选配色 |
| 漂浮的无意义气泡/圆点 | 装饰性但无信息量 | 用具体图标、数据、场景替代 |
| 通用卡片堆叠 | 信息密度高但无层次 | 突出1-2个核心，其余弱化 |
| 弱字体层级 | 标题和正文差不多大 | 标题必须是正文的2-3倍 |
| 克隆式章节 | 每个模块长得一模一样 | 每个模块有独特构图 |
| "奢华"= 米色衬线体 | 假高级感 | 真奢华靠留白和克制 |
| "创意"= 实际上乱 | 不可读的混乱 | 创意必须可读 |
| 文字太多图太少 | 信息过载 | 图:文 ≥ 6:4 |
| 太密没有呼吸 | 压迫感 | 留白 ≥ 20%（高密度学术图除外） |

## 构图多样性规则（不要默认左文右图）

| 构图方式 | 适用场景 | 说明 |
| -------- | -------- | ---- |
| 居中覆盖背景图 | 品牌感、冲击力 | 文字叠在大图上 |
| 左下角定位 | 编辑感、不对称 | 文字在左下，视觉在右上 |
| 右下角定位 | 高端感、留白 | 文字在右下，左侧大面积视觉 |
| 堆叠居中 | 简洁、聚焦 | 标题在上，图在下，居中对称 |
| 画布式 | 艺术感、沉浸 | 整张图就是视觉，文字最小化 |
| 网格编辑 | 信息密度、对比 | 多模块网格布局 |
| 右文左图（反转经典） | 打破惯性 | 把图放左边，文字放右边 |
| 极简迷你 | 克制、高端 | 只有一个小焦点+大面积留白 |

## 三旋钮量化系统

| 旋钮 | 含义 | 范围 | 文章配图默认 |
|------|------|------|-------------|
| 设计变化度 | 1=完美对称, 10=艺术混乱 | 1-10 | 7 |
| 视觉密度 | 1=美术馆/透气, 10=驾驶舱/密集 | 1-10 | 按风格选（见下表） |
| 动效强度 | 1=静态, 10=电影级 | 1-10 | N/A（静态图） |

**密度按风格选**：

| 配图风格 | 视觉密度 |
|----------|----------|
| 手绘信息图 | 3-4（透气） |
| 科技蓝图 | 5-6（中等） |
| 学术高密度 | 7-8（密集） |
| 莫兰迪手帐 | 4-5（中低） |
| 复古波普 | 5-6（中等） |

## 应用到文章配图流程

在步骤 10（生成文章配图）中增加以下检查点：

1. **生成前**：输出设计解读 + 旋钮设置
2. **提示词中**：指定构图方式（不要默认左文右图）
3. **提示词中**：明确避免哪些默认陷阱
4. **生成后**：检查是否掉入默认陷阱
