# 图片生成陷阱与解决方案

## ⚠️ 超时问题（2026-05-18验证）

**问题**：在单个 Python 脚本中生成 3+ 张图片时，总耗时超过 300 秒默认超时，脚本被强制终止。

**根因**：每张 gpt-image-2 图片生成耗时约 90-130 秒，3 张 = 270-390 秒，容易超过 300 秒限制。

**解决方案**：
- **每次最多生成 2 张图片**，分多轮执行
- 封面图（2.35:1）单独一轮生成
- 信息图（16:9）单独一轮生成
- 章节配图每轮生成 1-2 张
- 每轮之间间隔 20 秒（实测 15s 不够，429 后需更长冷却）

**生成顺序建议**：
```
第1轮：cover.png（约 120 秒）
第2轮：01-infographic.png（约 120 秒）
第3轮：02-xxx.png（约 120 秒）
...依此类推，每张单独一轮最安全
```

## ⚠️ 429 限流实战（2026-05-27 验证）

**问题严重性**：云雾 API (yunwu.ai) 在高峰时段（北京时间 11:00-14:00）频繁返回 429。

**典型错误信息**：
```
HTTP 429: {"error":{"message":"当前分组上游负载已饱和，请稍后再试"}}
```

**有效的重试策略**：
- 第 1 次 429：等 15-20 秒
- 第 2 次 429：等 30 秒
- 第 3 次 429：等 90 秒后再试
- 3 次仍失败 → **立即暂停，通知用户**，不继续重试

**多人共用的 API Key 更容易遇到 429**，因为上游按分组限流。如果持续 429，告诉用户考虑：
1. 等 10-30 分钟非高峰时段重试
2. 更换 API Key / 分组
3. 切换备用节点

## 节点切换实际问题

脚本文档标注了 3 个节点自动切换，但实际情况：

| 节点 | 状态（2026-05-27） | 问题 |
|------|-------------------|------|
| yunwu.ai | ✅ 主站 | 高峰 429 频繁 |
| api3.wai.vip | ❌ SSL 错误 | `UNEXPECTED_EOF_WHILE_READING` — SSL 证书问题，不可用 |
| api.apiplus.org | 未实测 | - |

**结论**：不要假设备用节点一定可用。api3 的 SSL 问题可能是临时故障也可能是长期问题。遇到 429 时先等待重试，而不是盲目切节点（铁律三：不擅自换端点）。

## ⚠️ 飞书 DM 发送的 chat_id 格式

**问题**：用 `feishu:ou_xxx` 格式发送文件报 `invalid receive_id`。

**正确格式**：使用 `send_message action=list` 获取可用 targets，DM 的格式是 `feishu:oc_xxx`，不是 `feishu:ou_xxx`。

## 封面图尺寸

- 2.35:1 比例使用 `2304x1024`（不是 2350x1000，API 不支持该分辨率）
- 16:9 比例使用 `1792x1024`

## 中文文字质量

- `gpt-image-2` 中文渲染效果最佳，是默认推荐模型
- 提示词中必须包含"所有文字必须使用简体中文，确保中文文字清晰无乱码无变形"
- 生成后检查文字清晰度，如有乱码立即重新生成

## Anthropic 暖色信息图风格（2026-05-27 飞哥确认）

适用于行业观察 / 深度分析类文章：

```
配色：暖米白/羊皮纸底色(#FAF9F6)、深炭黑文字(#1a1a1a)
点缀：陶土橙(#C27A4A)、赭石棕(#8B5E3C)、鼠尾草绿(#7A9A7E)
特征：高留白、克制、学术感、可信感、flat-vector
适用：深度行业观察、趋势分析、组织/战略类文章
```

不是所有文章都适合——方法论/教程类仍可用科技蓝，个人故事类可用手绘。选风格时先判断文章气质，再给飞哥确认。

## 本地代理直连回退方案（2026-05-27 验证）

当云雾 API 所有节点不可用（yunwu.ai 429、api3 SSL 错误、apiplus 403）时，**Hermes 本机到本地代理 `127.0.0.1:8317` 的直连往往仍然可用**。

**关键发现**：同一 API Key 到 yunwu.ai 返回 429，但到 `http://127.0.0.1:8317/v1/images/generations` 正常响应。本地代理可能是不同的上游分组，不受 yunwu.ai 限流影响。

**使用方式**：
```python
req = urllib.request.Request(
    "http://127.0.0.1:8317/v1/images/generations",
    data=json.dumps({"model": "gpt-image-2", "prompt": prompt, "n": 1, "size": "1792x1024"}).encode(),
    headers={"Authorization": f"Bearer {api_key}", "Content-Type": "application/json"}
)
```

**注意事项**：
- 本地代理的尺寸校验更严格：最小尺寸限制高于 yunwu.ai，`512x512` 会被拒（`Invalid size — below minimum pixel budget`），使用 `1792x1024` 或 `1536x1024`
- 本地代理返回 `b64_json` 而非 URL，需 base64 解码保存
- 这个回退方案不需要修改 Hermes 配置，直接在 Python 中调用即可
