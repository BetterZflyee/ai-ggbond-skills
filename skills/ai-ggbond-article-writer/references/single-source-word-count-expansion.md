# 单源文章字数扩充策略

## 场景
从单篇外部文章/视频改写公众号长文时，初稿通常只有目标字数的 30-40%（如目标 8000 字，初稿仅 4500 字）。

## 扩充方向（按效果排序）

### 1. 增加引言/钩子（+300-500 字）
在文章开头加一段引人入胜的引言，提出核心问题或制造悬念。

示例：
```
你有没有想过一个问题：为什么有些公司，老板不在就乱套？
而有些公司，老板休假一个月，回来发现公司比他在的时候还好？
```

### 2. 每层/每点增加具体例子（+500-1000 字）
框架性内容（如五层模型、三个步骤）需要为每一层/每一步补充：
- 具体场景描述
- 对比（传统 vs AI Native）
- 实际操作示例

### 3. 增加跨领域类比（+300-500 字）
用控制论、信息论、博弈论等科学理论辅助表达。

示例：
- 递归循环 → 控制论的"负反馈回路"
- 上下文 vs 软件 → 信息论的"信噪比"
- 副驾驶思维 → 必要多样性定律

### 4. 增加数据推演（+300-500 字）
用具体数字推演趋势，增强说服力。

示例：
```
假设客服团队 10 人处理 1000 工单 → 引入 AI 循环后 → 18 个月人效比 5 倍
```

### 5. 增加 Token 经济学分析（+400-600 字）
对比人力成本 vs AI Token 成本，用具体数字说明。

### 6. 增加冷思考/边界分析（+500-800 字）
为模式/方法论补充 3-5 个边界条件，增强可信度。

### 7. 增加具体行动建议（+500-800 字）
抽象建议需要具体化：
- "记录一切" → "3-3-3 记录法"（每天 3 个决策、3 个收获、3 个问题）
- "找到第一个循环" → "客户邮件自动分类"最小可行版本

## 扩充节奏
- 第一轮：骨架 + 核心内容（~4000-5000 字）
- 第二轮：补充例子、类比、数据（~6000-7000 字）
- 第三轮：补充行动建议、冷思考、引言（~8000+ 字）

## 自检清单
- [ ] 每个框架点是否有具体例子？
- [ ] 是否有跨领域类比（至少 2 个）？
- [ ] 是否有数据推演？
- [ ] 行动建议是否具体可操作？
- [ ] 冷思考是否在行动建议之前？
