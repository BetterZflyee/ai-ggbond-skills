# 让动作承担解释任务

先按[创意导演](creative-direction.md)确定场景目的，再选择下面的机制。配方是实现材料，按主题重新组合。

## 1. 时间、状态和输入共用一条更新路径

将场景分成`enter / beats / hold / exit`，将连续参数和离散状态集中管理。
每帧由环境时间、节拍目标的过渡进度和用户输入计算画面；默认由用户推进节拍，同一参数不要同时由导演轨迹与拖动直接写入。
需要任意跳转、重放的场景优先使用时间的确定函数；有物理状态的场景提供初始化与预热。
把一次性音效和事件放在阈值越过检测中，倒放、跳转和预览时按策略静音。

```js
function updateScene(ctx) {
  const t = ctx.localTime;
  const input = ctx.pointer;
  if (input.justPressed && hitHandle(input)) state.owner = "user";
  if (state.owner === "user" && input.down) {
    state.value = pointerToValue(input);
  } else if (state.owner === "demo") {
    state.value = authoredCurve(t);
  }
  if (input.justReleased) {
    state.owner = "settle";
    state.releasedAt = ctx.now;
  }
  updateReleasePolicy(state, ctx);
  applyValueToGeometry(state.value);
  renderEvidenceAndLabels(state, ctx);
}
```

## 2. 打字、删除与选择框

适用于表现改写、识别、承诺变化、问题重构。先确定文字变化带来的含义，再安排输入速度。
按字素簇拆分字符串，使用`floor((t-start)*rate)`确定已显示数量；删除从末尾反向裁切。
光标跟随实际排版后的行尾，中文、换行和字体加载完成后重新测量。
选框由目标对象的当前包围盒生成，位置与宽高插值，出现时可以使用轻微回弹。
选框跟随移动对象时每帧重算；最终全选时把目标框插值到舞台边界。
用短暂停顿区分“选中、删除、空白、输入、读完”，不要让最后一个字刚出现就转场。

## 3. 从字形得到可运动的材料

先用Canvas画字，再取得alpha mask；按需要生成字形纹理、采样点或有符号距离场。
普通排版优先使用DOM、Canvas或字形图集；距离场用于轮廓变形、挤出、液态法线等专属效果。
距离场挤出可通过Raymarch形成三维字；高度场可用有限差分求法线，驱动高光与环境反射。
字形采样点可作为实例几何的目标位置，随机起点插值到目标形成聚字，再用另一状态释放。
字体与中文字形必须先就绪，纹理尺寸按显示规模选择；近景重要文字单独提高分辨率。

## 4. 大量对象用实例与解析函数

同形对象使用`InstancedMesh`或实例化BufferGeometry，将位置、种子、阶段和颜色作为实例属性。
重复动作由`time + seed`直接求出，避免每个对象持有一套独立计时器。
增长过程可用移动前沿控制显现：比较对象距离与`frontRadius`，以平滑阈值点亮。
镜头拉远时切换密度、简化几何或聚合表达，使可见数量与当前解释尺度匹配。
需要超大尺度时使用对数距离、局部坐标与浮动原点，维持镜头附近数值精度。

## 5. 选择几何编排还是物理模拟

讲固定倍率级联时，可按`size(i)=base*ratio^i`生成对象，按时间决定当前对象和倾角。
利用接触几何反推前序倾角，再为相机、抖动、尘埃和声音编排响应，能得到稳定可回放的骨牌效果。
这种做法记录为几何级联；不要把视觉接触称为刚体求解。
需要绳索松紧、断裂和回弹时，使用当前位置与前一位置的Verlet式积分，再迭代修正相邻段长。
对子步设置不同介质阻尼与重力；断口跳过对应约束，回弹通过旧位置或速度施加冲量。
船体贴水可采样前后左右水高求高度、俯仰和横摇；完整浮力或刚体碰撞需求应另选求解方案。
固定时间步、最大子步数、重置和预热必须一并实现，避免低帧率时运动失控。

## 6. 局部同物体交接

先由内容决定相邻场景的关系；这一配方仅用于确有传递、追踪或形态转化理由的边界，片段之外保留各场需要的主体与机位。

建立共享对象或`handoff`数据：几何定义、数值映射、材质纹理、锚点和最终姿态。
二维图表接入三维纸面时，两端复用同一绘图函数与坐标映射，避免曲线在接缝处跳位。
先把三维相机对准平面，按FOV与画幅求贴屏距离；再逐渐偏离正面，揭示空间。
相邻场景均渲染到离屏纹理后，可由统一合成器处理遮挡、透明度和颜色空间。
需要切换渲染方式时，在两种输出几乎重合的时刻完成交接。

同一物体贯穿多个空间时，详细实现见[镜头与对象交接](camera-and-handoff.md)：在对象局部坐标中统一前后相机，连续混合光线与雾，并保留各场自身的接触阴影和遮挡。

## 7. 用投影四角实现空间转场

选取新场景中承接旧画面的平面，将四角投影到标准化屏幕坐标。
求二维单应矩阵，将旧画面纹理映射到这四角；新相机运动时持续更新投影。
旧纹理逐渐退出，露出新场景真实材质；退出场景时可反向使用。
保持角点顺序、纹理Y方向、画幅裁切和线性色彩混合一致，并处理近平面与退化四边形。
如果场景关系适合直接切换，使用明确的切点；空间转场用于延续对象关系。

## 8. 比较分界线必须真正交还控制

两种状态先分别渲染，再以`split`与像素位置比较，生成分屏合成。
拖动改变`split`，手柄扩大命中范围但保持视觉轻巧；指针按下后捕获，支持触摸和越界拖动。
用户开始拖动时暂停自动摆动，松手保留结果或按清晰规则延迟恢复。
允许复位、键盘调节和两端状态快捷查看，使展示和自主探索都能完成。
如果比较带有数据含义，标签与数值同时跟随分界或被选状态更新。

## 9. 镜头与几何形变分开设计

镜头用位置、目标点、FOV与roll关键帧，采用Hermite或样条插值并保留阅读停点。
缩放跨越数量级时插值对数值；旋转用四元数插值，避免欧拉角绕远和翻转。Hermite轨道使用原始段进度与共享切线，只有明确停点归零；把轨道或进度选作单一缓动层，用户偏移的阻尼独立管理。
日历、地形、网格等连续变形使用参数化曲面或LUT映射，按形变后的切线重算法线。
日期、格线和标注可以保留源UV，让结构随曲面变形；突出区域增加网格细分。
片元Shader的擦换与阴影可以表达纸面更新；独立翻页、卷曲或布料行为需要相应几何或模拟。

## 10. 让镜头、文字与声音落在同一发现点

运动先建立条件，关键变化出现，再给出名称或数字，最后保留理解时间。
音效由动作状态变化触发：选中、接触、释放、穿越、完成；持续声由速度、张力等参数调制。
在用户手势后初始化或恢复AudioContext，提供明显的静音控制，并保证静音下仍能理解。
使用少量层次：短促定位、材质反馈、持续环境、低频尺度感；根据场景需要选择。
声音越过阈值只触发一次，跳场和重新进入时重置门控。

## 11. 性能按体验收敛

先完成完整状态链，再测最复杂场景；观察实际帧耗、交互延迟、显存和切场停顿。
重负载效果优先降低离屏分辨率、采样次数、实例密度、阴影尺寸和后处理层数。
保持主文字与手柄清晰，按设备像素比上限或质量档位缩放昂贵效果。
进入前预建字形、纹理与Shader；退出后释放RenderTarget、几何、材质、监听器和音频节点。
后台暂停渲染，恢复时处理时间跨度；低动态模式保留关键状态与真实交互，缩短镜头运动。
离线交付将必要资源本地化或内嵌，资源路径在最终文件位置复验。

## 12. 逐项验证动作是否成立

在真实浏览器中验证：完整推进、倒退、跳场、重复进入、缩放、调整窗口、触摸或鼠标操作。
拖动到两端并释放，检查导演轨迹是否抢回状态；选用音频时再检查静音观看。
观察每个交接对象是否跳位、翻转、闪白或突然改变清晰度。
检查空白输入状态、最后一个字、最后一块实例和结束停留，不只截取中间好看的画面。
通过动作时间、状态断言和实际操作验证功能，再用截图核对构图；验收结果写入交付记录。
