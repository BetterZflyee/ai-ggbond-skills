# 方法来源与适用范围

本技能来自对《The Last Boring Slide》中文本地版的叙事与源码研究，提炼的是创作与实现方法。参考作品采用内容递进的多场景结构、实时空间、讲述节拍、参数动画、少量直接操控、按关系设计的转场，以及可定位的运行检查。

本包独立提供原创 WebGL 程序世界、鼠标镜头、直接光源操作、材质化过渡与状态声景的交互起点，同时保留显式 cinematic 音画实验与 flat 轻量分支。未包含参考作品的完整源码、字体、图像或音频。创作时根据主题重新确定内容、隐喻、视觉语言和规模。

首版的二维示范经用户反馈仍像 H5 PPT；2.0据此把默认起点改为素材、光照、声音与渲染，并将运行检查、画面审看、实际听审分开。首版安装包与样例保留为历史。

2.1按用户进一步澄清，把默认产品交回可探索的完整HTML：用户推进节拍、鼠标控制镜头、内容对象直接操作，环境独立运动。当时将精简播放器一并解释为移除声音，后续V4.3纠正；现行默认声音要求见[主技能](../SKILL.md)。首屏与最终成品入口也纳入验收，避免源码模板中的资源占位被误当成成品。

关键工程经验：

- 输入改变目标状态，帧循环将各动画参数追向目标；返回可以撤回后续拍进度，同时保持环境时间前进。
- 内容先形成因果链，各场按解释任务改变主体、空间和尺度；动作、数据、方向或问题都可承接下一场。
- 局部复用图表、物体或纸面并匹配投影，可以建立空间接缝；这项图形连续性需与内容语义和多场视觉节奏分别验收。
- 直接操控与演讲轨迹通过权重混合；用户松手可以保留位置，推进到下一拍再平滑收回控制。
- 根据运动任务选择确定性几何、约束模拟或着色器，不必为所有物件采用同一种模拟方式。
- 作品有指定状态定位和事件验收接口时，复杂动作更容易重放、检查与修正。

本轮镜头与交接复核补入[镜头与对象交接](camera-and-handoff.md)：原作本地HTML的`_a/Q3/oy`（4368行）提供带停点的Hermite轨道；`Fv/qA`（4978行）使用球面机位与对数距离；`A3/Et`（4341行）让双场同时推进并传递enter/exit；`portal.in/out`（4490、5722行）与船的`anchor`（4666行）、fold（5738行）通过实际投影衔接。此处提炼方法并附原创Three.js对象局部坐标交接示例，按当次内容选择，不把顺丰包裹、七场或固定特效作为通用结构。

同物体交接作为局部配方保留，不能把持续围绕同一物体换背景当作完整叙事。每场的新认识、进入下一场的理由及多场景视觉节奏，现已纳入导演卡与验收。

声音补验进一步区分能力与界面：精简控件不应删除已要求的音画匹配。原作本地版的`G3`（4341行）按scene/beat更新声床，`param`驱动持续层，`V3`按转场时长编排并清理旧过渡；画布pointerdown和键盘操作解锁声音。`R3`同一行以M键静音并短暂toast，初始DOM仅有画布和ui容器（28–29行），没有常驻圆形声音按钮。提炼时保留状态驱动与实际输出核验，不把含糊的圆形图描述当作确定UI要求，也不把固定音轨或播放器作为声音的前提。

2.3.0把顺丰V3.2→V4.3的实际迭代收敛为[制作与验收标准](production-and-acceptance.md)：先有场景内容因果，再选择主体尺度、独立机位和交接；将程序素材、镜头光影、直接操作及状态声音一起完成。默认starter同时具备视觉与声音的可编辑起点，构建成内联单文件；起点展示接口，正式作品按主题重新创作。
