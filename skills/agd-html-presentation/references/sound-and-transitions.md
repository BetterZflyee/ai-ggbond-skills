# 声景与材质化过渡

配合[技能入口](../SKILL.md)和[程序视觉素材](procedural-materials.md)使用。默认交互作品同时设计声景、动作与转场声音；第2–6节提供声音机制，第7节起处理材质化过渡。用户明确要求无声时按该要求调整。显式`flat`路线也可以复用这些机制。
按主题选择声音密度和材料层次，为关键动作留出静区与停顿。

声音能力与界面控件分别决定。用户已要求的声景、动作音与音画同步，应在精简界面时保留；鼠标探索作品不会因为需要声音而自动改为定时影片。

## 1. 先写素材账本，再造素材

为关键场景或过渡记录一行完整生成链：

`画面事件 → 原始输入 → 几何/场 → 材质数据 → 光照/遮挡 → 合成 → 声音 → 控制参数 → 验收`

| 字段 | 最少记录 |
|---|---|
| 输入来源 | 用户实拍、授权素材、工具生成、程序生成或本地字体 |
| 生成方法 | 函数/脚本、随机种子、尺寸、格式、工具实际返回结果 |
| 中间材料 | 高度、法线、覆盖、深度、mipmap、阴影或音频缓冲 |
| 动作事件 | 发生时刻、时长、峰值时刻、持续参数、用户接管规则 |
| 成品边界 | 可替换资源、预热成本、内嵌方式、释放方式 |

程序纹理和PCM缓冲都是正式素材。运行时合成应能重建，工具生成应能追溯实际调用与输出。
资源被内嵌只说明打包方式；不能据此推断它原先由AI、摄影或设计软件制作。

## 2. 声音从事件开始设计

为动作写出“准备、接触、受力、释放、余韵”中实际存在的阶段，再选择声音层。
定义视觉事件的准确时刻，例如折痕合拢、落地、断裂、选中、越过刻度或露出新空间。
记录音源内部的接触峰值偏移；调速后按`start = eventTime - peakOffset / rate`安排播放。
连续运动输出速度、张力、湿润度、距离等平滑参数；瞬态用越过阈值事件触发一次。
不要把每次切场统一映射为同一种提示音；声音应说明材料、尺度与状态变化。
先确定事件时间，再决定需要多精确的音频调度与视觉补偿。

交互作品以`scene / beat / local / environmentTime / transition / input`驱动音频。环境循环在停留时持续，进入新场才切换声景；动作音使用阈值越过或明确事件，转场音读取同一过渡的时长、进度与正反方向。快速推进或改向时取消尚未发生的旧事件并淡出旧过渡，不把固定总时长的整段音轨按节拍位置硬接。

## 3. 用PCM工厂生成有结构的短音

短音可以由JavaScript逐采样写入Float32Array，再交给AudioBufferSource播放。
将几种材料分开控制：短噪声瞬态表示接触；带包络的分音表示共振；滤波噪声表示摩擦；滑低频表示重量。
采样率按用途选择，起尾加短窗，滤除直流；保留一定峰值余量。

```js
for (let i = 0; i < samples.length; i++) {
  const t = i / sampleRate;
  phase += 2 * Math.PI * frequencyAt(t) / sampleRate;
  const resonance = Math.sin(phase) * resonanceEnvelope(t);
  const friction = filter.process(randomSigned()) * frictionEnvelope(t);
  samples[i] = resonance + friction;
}
```

频率、包络和噪声不能共用一个无差别衰减：纸摩擦有颗粒过程，木头接触有瞬态与共振，金属受力有不规则激励。
每类生成少量带种子差异的变体，连续播放时避免重复同一变体；关键节奏保持可复现。
需要长录音、配音或特定乐器时，选择合适来源，并继续保留相同的事件与混音接口。

## 4. 频谱声垫用于持续空间与情绪

需要循环环境或音色时，可先建立幅度频谱，再分配随机相位，通过逆变换形成PCM循环。
分音附近使用窄带或宽带峰控制稳定度；共振峰加权可形成元音感，不成整数倍的分音可形成金属感。
粉噪的幅度谱可按`1/sqrt(f)`衰减，棕噪可按`1/f`衰减，并控制过低频和高频范围。
低频左右相位保持相关，上方频带适当分开，得到稳定中心与空间宽度。
循环波形按RMS整理，运行时改变播放速率、滤波、电平和声像；检查接缝，必要时交叉循环。
长缓冲生成分成小时间片，优先准备首场和马上需要的音源，避免阻塞首屏。

## 5. 混响也是可生成的素材

用双声道衰减噪声生成脉冲响应：给出前置延迟、早期反射、高频衰减和尾部长度，再送入ConvolverNode。
分别准备短空间与长空间，保留干声定位；大混响用于距离或空间表达，而不是给所有声音统一加长尾。
IR、原始波形、随机种子及发送量都写入账本。控制卷积数量并复用空间发送。
切场时可让反射尾部延续，前景瞬态先退场，使空间衔接有余韵。

## 6. 三类总线与连续参数

建立环境/音乐声床、动作短音、过渡声三类总线，再汇入主音量。
组内保留dry与适当的混响发送；主链根据实际峰值使用压缩、增益和温和饱和。
普通画布真实`pointerdown`或有效`keydown`解锁AudioContext，提供静音，后台暂停和恢复时处理时钟差。滚轮本身未必授予音频权限，需用全新浏览器上下文验证；自动化`evaluate`可能携带用户激活，不能据此声称冷启动滚轮可起声。极简作品用M键与内部状态控制静音；圆形音频控件等可见UI按用户明确要求添加。
运行时用AudioParam斜坡或`setTargetAtTime`平滑更新，避免突然写值造成爆音。

默认起点包含[可配置音频适配器](../assets/interactive-audio.js)，接入示例与协议见[交互接口](interactive-api.md)。其中持续振荡器、循环噪声、PCM短音和程序IR均为音频素材；IR按实际AudioContext采样率转换，避免设备48kHz与生成24kHz不一致造成图创建失败。末端主音量在静音/后台时用短斜坡到精确零，便于核实真实输出。

```js
const attack = state.justEntered ? 0.3 : 0.08;
gain.gain.setTargetAtTime(levelFromSpeed(state.speed), now, attack);
filter.frequency.setTargetAtTime(cutoffFromTension(state.tension), now, 0.12);
if (crossedImpact && state.forward && !state.seeking) {
  scheduleSample(impactTime - sample.peakOffset / rate, sample, rate);
}
```

节拍改变声床目标，持续运动调整密度与滤波，事件音只在实际发生时触发。
返回、跳转、快速推进时清理旧调度；预览定位一般保持静音，避免一次触发途经的所有事件。
左右声像和少量失谐能建立宽度，低频中心与主事件位置仍需稳定。

## 7. 过渡先把画面变成材料

先把前后场景渲染成A/B纹理。一次Shader混合提供基本接缝，复杂动作还需要中间材料的状态。
按这次过渡选择几何、覆盖场或高度场，明确它如何移动、受光、遮挡、透射并退出。

```text
A/B场景 → 线性颜色纹理与mipmap
进度与输入 → 网格姿态 / 厚度场 / 开裂前沿
材料状态 → 法线 / 纤维 / 覆盖 / 反射或折射
材料层 → 近远软阴影 / 碎屑 / 景深或光晕
合成 → 对齐接收对象 → 保留B的准确终态
```

共享对象复用几何和坐标定义；纸面接入三维平面时按投影四角匹配，减少缩放、旋转和画幅跳变。
缩放与模糊使用mipmap或受控采样，颜色混合在线性空间完成，再转回显示颜色。

## 8. 纸张：形变、纸芯与投影一起工作

折叠用可分片网格与折痕轴变换，卷曲用参数曲面；纸正面采样旧画面，背面提供独立纸材质。
纸纤维可由Canvas细曲线加噪声生成，存为高度及梯度；近景裂边另算细纤维覆盖。
根据变化后的法线受光，加入折痕压暗、压缩处裂白、纸芯露出和薄边透光中需要的部分。
从透明覆盖层派生近/远软阴影，或用变形网格单独渲染阴影，建立与背景的距离。
末段把中心、角度、尺度匹配接收场景对象；纸响内部峰值对齐折痕合拢或接触。

## 9. 水洗：先高度，再光学

先在较低分辨率目标中存水膜厚度、水珠高度、浪沿和排水线。
相邻采样求梯度与法线，驱动折射偏移；厚度决定吸收、散射和柔化程度。
水珠的亮下缘、暗上缘、高光和局部反射提供体积感；泡沫可用多尺度Worley距离差与噪声组合。
浪沿先遮住旧画面，再在水体内部交接新画面，留下流痕与珠滴后干净退出。
声音分为低频水体、中频冲洗、高频飞沫和零散水滴，随同一浪沿与排水进度安排。

## 10. 散景与撕裂按表达选择

失焦过渡可对A/B做亮部加权的圆盘采样，再由实例光斑承接高亮区域，逐渐恢复新画面清晰度。
这是画面空间的散景合成；真正景深需要深度、焦平面与弥散圈，按需求选择并记录。
撕裂使用左右网格、移动裂口和圆弧卷曲，片元层处理毛边、纸芯与细阴影，少量实例碎屑表现释放。
持续摩擦声在断口完成时转为短瞬态，再让纸片声和环境尾部结束。
每种过渡先明确关键发现点，只保留有贡献的材料和后处理层。

## 11. 分配复杂度预算

每个关键段落明确像素、采样、实例、阴影、纹理和音频声部预算；先完成一个代表段落再扩展。
高度场、阴影、卷积光晕优先降低分辨率；文字、操作手柄和关键轮廓保持清晰。
昂贵Shader预热，离屏目标复用；退出时回收几何、材质、缓冲、监听与音频节点。
降级优先减少采样、实例、声部与阴影质量，保留对象状态、事件时间与交接关系。
记录实际帧耗和峰值负载；不能用“能够打开”代替运行预算验收。

## 12. 画面、同步、听感分别验收

- 画面：检查中间材料、形变轮廓、法线、高光、遮挡和最终接缝；再连续播放核对速度与停顿。
- 同步：标记接触/断裂等画面时刻，对照音源内部峰值；快速推进与返回后仍只触发有效事件。
- 离线音频：用同一音源与调度渲染，检查非静音、RMS、峰值、削波、声道与事件时刻。
- 实际输出：分析器连接在主音量及最终混音之后、扬声器输出之前；解锁后取多段真实输出，确认RMS非零、静音后近零、恢复后重新非零。检查可闻音量与场景间响度，避免源缓冲有数据但总线未连出、主音量为零或上下文仍挂起。
- 主观听审：实际听完整段落，检查触感、层次、刺耳频段、低频重量、空间、突然响度和尾部。
- 输入：首次操作解锁、静音、恢复、拖动接管与释放，都在真实浏览器中操作。

在同一场停留、进入另一场、返回、快速改向和拖动内容的几种路径下分别检查声景归属与事件同步，确认没有声音自行按固定配乐时间表走到别场。离线检查复用实际合成/混音路径，不另造一段测试音来证明输出。

离线统计证明信号性质与调度情况；通过RMS和峰值检查不等于听感合格。未实际听审时明确记录。
