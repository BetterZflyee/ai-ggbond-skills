# 程序素材：从输入到有光照的世界

与 [主技能](../SKILL.md)、[声音与连续转场](sound-and-transitions.md) 配合使用。
默认交付有空间、材质、光影和镜头关系的电影感演示；主画面用可计算的三维世界或全屏着色器组织。
Canvas 2D 可生成字形、纤维、图集和数据纹理，再把产物送入场景渲染。

## 1. 每份素材都要走通这条链

`原始输入 → 几何/场 → 法线 → 光照与遮挡 → 材质响应 → 分层合成`

1. 写出素材承担的观点、观众先看哪里、镜头会靠多近。
2. 决定基础表示：网格、实例、字形场、高度场或体密度；选择能服务镜头的最小复杂度。
3. 用同源数据推导表面位置、法线、遮挡和动画；物体变形时同步更新它们。
4. 先用一盏明确主光和环境填充测试材质，再增加局部光、雾、反射与特效。
5. 把重计算预烘焙为纹理、图集或查找表；动态阶段只更新必须变化的参数。
6. 保留深度、法线、高亮或透过率等中间数据，再做景深、体积层和光学合成。
7. 将材质变化接到统一时间与拍进度，保存可重放的种子和采样帧。

实现前先回答：输入是什么；哪个函数能查询表面；法线从哪里来；光怎样被遮住；哪些结果可以缓存。

## 2. 选择生成途径

| 途径 | 适合的输入与任务 | 必须保留的产物 |
|---|---|---|
| 代码生成几何 | 重复结构、数据空间、可描述的纸面/地形/机械隐喻 | 参数、单位、种子、顶点/场、动画函数 |
| 代码生成纹理 | 字形、纸纤维、噪声体、图表、光照分布与图集 | 通道定义、色彩空间、分辨率、平铺规则 |
| 图像模型 | 需要特定构图、美术表面、写实背景或手工难以描述的图像 | 原始提示、来源、版本、用途、可动区域 |
| 3D生成或既有模型 | 需要具体造型、可识别产品和多视角细节 | 模型来源、比例、朝向、法线、材质和许可 |

按题选择可用工具。原作的大量视觉由代码生成；外部图像/3D模型不是复现这种表达的必经步骤。
模型产物进入场景后仍需匹配镜头、光向、比例和接触关系；选型依据是最终画面需要什么。
真实场地、产品或作业关系以用户素材和明确业务口径为依据，再决定哪些部分可艺术化。

### 主题素材的组合方法

把复杂场面拆成可复用的基础资产与本场结构。例如物流实例中，纸板/胶带/面单纹理、金属/橡胶/玻璃材质、立面图集和雾精灵由少量固定种子工厂生成；城市道路、分拣结构、货机、节点网络、温控容器和门前空间再用各自的几何与运动组织。资产复用统一材质气质，场景结构和镜头重新建立解释任务。其他主题重新决定资产族，保留这条生产方法。

近景优先补厚度、倒角、接缝、接触阴影与正确比例，远景优先轮廓、层次、重复密度与方向。物理文字或面单可从Canvas图集进入材质，透明层设置合理的depthWrite与偏移，检查重叠文字、玻璃排序和背面。把颜色图、粗糙度与高度数据各自的颜色空间说明白，避免把同一噪声无差别放大到全部通道。

## 3. 海水配方

**何时选：** 需要尺度、浮力隐喻、入水镜头、船体接触，或以反射连接前后场景。

1. 定义水位、长度单位、风向、主波与细波参数；每组保存波向、波数、振幅、相位和频率。
2. 用解析波生成低频起伏，较细噪声只补小波；共享同一高度查询给船体和水面。
3. 预生成高度、双向斜率和必要的压缩量；将时间相位更新与静态波参数分开。
4. 从斜率生成 `N=normalize(-dh/dx,1,-dh/dz)`；距离变远时降低细波频率和振幅。
5. 用视线与法线求Fresnel；反射读同源天空或镜像场景，模糊程度随粗糙度变化。
6. 用折射方向查询水底/物件；以水深和光程计算不同颜色的吸收，再合成水体与反射。
7. 泡沫读取岸边水深、波峰压缩、船体距离和尾迹；噪声只打碎边缘和纹理。
8. 若镜头入水，增加水面下的折射/全反射、光程雾化和镜头水线；按深度比较遮挡。
9. 焦散可把波斜率作用到聚焦网格，再以变形前后面积比生成亮度，投到水底与物件。

可先实现平面反射与深度水色，镜头确有需要再加入射线求交、焦散和水下积分。
预算优先给近景水线与物体接触；远处波纹用mipmap和环境反射，飞溅用实例精灵。
程序波是视觉模型；若要说明真实流速、液位或受力，运动必须读取对应数据或明确的仿真结果。

**检验：** 船会随同源波高变化；反射方向正确；近岸与深水可区分；泡沫有成因；镜头过水线连续。

## 4. SDF文字与液态字配方

**何时选：** 文字本身要变成可进入的物体、浮雕、金属、粒子形状或转场锚点。

1. 确认中文字形可用；Canvas画字，读取透明度，保存二值mask。
2. 对字形内外分别做距离变换，相减得到有符号距离纹理；记录采样比例与边界余量。
3. 浮雕把二维距离与厚度场合并成圆角挤出体；液态字把内部距离映射成柔和高度。
4. 距离场用中央差分或四面体采样求法线；高度场用双向高度差求法线。
5. 浮雕沿相机射线求交，并沿光线查询遮挡；加入字根接触AO与正侧面材质差异。
6. 金属用法线反射程序环境：至少包含大色块、亮条和暗区，才能读出表面起伏。
7. 液态感由有限的坐标扰动、隆起和反射变化产生；保持主要字形可读。
8. 若聚字成群体，从同一个mask采目标点，驱动实例位置、朝向和出现延迟。

预烘焙字形距离和mask；时间只进入形变、环境及镜头。不同样式尽量共用一份字形输入。
远处文字减少射线步数；高频起伏按像素足迹消退；轮廓抗锯齿使用导数或覆盖率。
视觉上的液态高度并非流体仿真；不要据它推导黏度、流量或其他物理结论。

**检验：** 字形正确；侧面有厚度；转光后高光移动；阴影与字边一致；最关键结论始终可读。

## 5. 纸张纤维与折叠配方

**何时选：** 日历、报告、纸船、印刷、撕裂、翻页，或把旧场景变为一个可操作的实体。

1. 在灰底Canvas上用固定种子画数千条低透明度细曲线，黑白交错，跨边缘补画以平铺。
2. 将纤维图与多尺度周期噪声混成微高度；有限差分输出双向梯度。
3. 数据纹理可按 `R=高度/G=dx/B=dy/A=斑驳` 打包；梯度按有符号数据编码。
4. 另用网格函数生成宏观卷曲、悬垂和隆起；由变形后相邻点求切线与宏观法线。
5. 把微梯度沿切线加到法线；纸色、油墨浓淡、粗糙度共用纤维输入。
6. 将文字/图表放在纸面UV中；折痕用边界距离或重心坐标定位，增加亮折边和旁侧暗部。
7. 用主光阴影和环境填充建立厚度；需要透纸时补背面透光与多层遮挡。
8. 撕裂先有宏观裂口与卷边，再加多尺度伸出纤维、纸芯分层、背面与细阴影。
9. 旧场景纹理贴纸面，新场景放其后；转场按同一网格与裂口揭示空间。

预烘焙纤维、印刷图集和静态阴影；运行时只更新形变、湿润/破裂量与光照。
远处降低纤维幅度并选合适LOD；细丝不足一像素时以覆盖率表达，避免闪烁。
纸纹噪声描述表面不均匀；折叠位置、受力方向与撕裂推进必须另有明确几何规则。

**检验：** 印刷跟纸走；法线跟折叠走；裂口露出真实后层；纤维不过度放大；背面有合理受光。

## 6. 程序地形与云配方

**何时选：** 需要连续探索、尺度升级、远近重复结构、日夜变化或两种未来的同地比较。

先选一条地形主路线：

- **高度网格：** 控制点/山脊/路径数据 → 平滑高度函数 → 按距离布网格 → 邻高差求法线。
- **距离场：** 基础体/拱门/岩壁 → 坐标变换与平滑并集 → 有限侵蚀 → 射线求交 → 场梯度法线。

高度路线适合固定场地和明确接地关系；SDF适合自相似洞穴、巨大尺度与程序空间。
把侵蚀分为大裂隙、中层理、微颗粒；随像素足迹减少高频，避免所有表面同样粗糙。
颜色读取高度、坡度、材质区与噪声；雪/植被读取法线与业务地表规则。
静态地形可从光向预烘焙遮阳高度及AO；动态物体用实时阴影，减少每帧重复重算。

云的生成顺序：

1. 用大体块或覆盖场规定云在哪里、顶部有多高；体噪声再塑形和侵蚀边缘。
2. 将低频密度与高频侵蚀预存到周期3D纹理，风只移动采样坐标。
3. 从视线穿过云的区间逐段采样；有效密度处再沿光向取少量点，计算自遮挡。
4. 按 `T*=exp(-density*ds)` 累积透过率，以 `T*(1-attenuation)*light` 累积散射。
5. 低分辨率渲染，使用抖动、重投影与历史夹紧保持稳定，再与天空及场景深度合成。

地面雾也应读取高度、距离和灯分布；屏幕径向模糊适合部分太阳光束，二者按镜头分别选用。
噪声只能提供变化；真实地形高程、建筑位置、天气数据和物理散射口径要由相应输入决定。

**检验：** 地面接触无穿插；坡向和受光一致；阴影方向正确；雾有深度；云运动与镜头变化无明显拖影。

## 7. 实例群体配方

**何时选：** 大量智能体、纸面、草、灯、骨牌或设备，需要从个体讲到群体尺度。

1. 建立一个语义对象描述：位置、尺度、朝向、激活顺序、随机种子、状态和内容索引。
2. 共享少量几何；每实例只上传差异属性，顶点着色器按统一时间计算位置与法线。
3. Canvas程序生成图表/文档/数字图集；以图集索引和局部时间让个体有不同工作状态。
4. 近处用详细几何，中处用平面实例，远处用点精灵；几档读取同一语义位置和状态。
5. 按投影像素大小平滑切换LOD，做亮度/面积补偿，避免群体远近转换时亮度跳变。
6. 共用光照与雾；灯群的亮点、地面光池和体积散射读取同一位置及强度数据。
7. 阴影只保留观众看得到的关键尺度；远群体可预烘焙或使用整体遮挡表达。

种子随机应制造个体差异；业务数量、容量、速度与效率必须单独输入，不从随机动画反推。
用于真实作业时，设备姿态、通行路径和操作顺序跟随已确认场景，重复实例也遵守同样关系。

分流、汇聚或循环的实例群体先定义连续路径及朝向，再分配入口相位、间距和支路法向偏移。主物体与批量实例分开编号，防止同位置重复渲染。近景拥挤场景可用包围盒或OBB沿全周期采样间距与碰撞，再看真实材质画面，避免重叠面单闪烁和穿插只在运动中暴露。性能预算不能以牺牲空间关系为代价。

**检验：** 近看有个体，远看读出密度；没有同步机械抖动；LOD无跳亮；图集不串页；业务量与示意量标识清楚。

## 8. 素材账本与验收

每份主要素材登记以下字段；放入项目资产清单，保持可追溯：

| 字段 | 要记录什么 |
|---|---|
| `id / scene / role` | 素材标识、场景与承担的观点 |
| `source / rights` | 用户原件、代码生成或模型生成；来源与可用范围 |
| `generator / version / seed` | 生成函数或工具、版本与固定种子 |
| `inputs / units / evidence` | 输入数据、单位、业务依据与示意范围 |
| `representation / channels` | 网格/场/纹理；每个通道的含义 |
| `resolution / colorSpace` | 图集/体纹理尺寸、颜色或线性数据约定 |
| `bake / dependencies` | 预烘焙产物、依赖的字体/图像/地形/灯数据 |
| `motion / lighting` | 动画参数、主光、阴影与反射关系 |
| `lod / budget` | 各距离表示、采样步数和性能预算 |
| `checks / frames` | 指定时刻、光照测试、交互与合成证据 |

交付前检查：固定种子重复定位结果一致；改变光向能读出法线；关闭Bloom仍能识别材质。
再检查接触阴影、透明遮挡、反射方向、细节闪烁、相机交接和不同视口的空间比例。
主画面优先用明确的光源、前中远层次、克制的高亮与有目的的镜头，最后统一曝光、色调和颗粒。
若主要内容仍是固定平面卡片与文字切换，继续补齐空间、材料生成与光照链，再提交电影感演示验收。

## 9. 交付资产与首屏

正式HTML将已选用的脚本、Logo、字体与必要纹理打包或内联，并在最终路径打开验证；内部模板保留清楚入口。Logo检查实际解码、naturalWidth、透明边缘和CSS尺寸，按原始宽高比显示，不能只检查文件存在。中文字体在生成图集前确认可用，手机标题按语义断行、检查孤字与安全区；文字布局也检查跨场中间帧。

首场完成必要资源后即可显示，用画面渐入承接初始化；其余场景分批创建或编译shader。异步错误必须结束准备状态并给出具体失败原因，正常路径不增加永久加载文案。离线打开检查缺失请求与控制台；可编辑工程在独立目录构建并对比交付HTML，避免仅原机器的缓存与绝对路径让素材可用。
