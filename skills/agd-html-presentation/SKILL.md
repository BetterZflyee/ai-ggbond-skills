# agd｜交互动画 HTML 演示

把主题发展成一个可探索的动态世界。模型承担导演、素材生成、材质与灯光、镜头、动画、声音和程序实现，交付独立 HTML 与可编辑工程。

## 只给主题时

直接完成创作。自行判断受众、核心问题、篇幅、视觉语言、素材路线与交互；默认中文、普通专业观众。用户的受众、品牌、参考和格式优先。重要假设记入制作说明，不逐项让用户选大纲、分镜或风格。

默认完整作品包含：各有解释任务的场景、连贯的镜头与光影、内容对象的直接交互、场景声景及动作/转场音。声音与画面共用状态，首次自然点击或有效按键后启用。用户明确要求静音时再省去声音。

按 [creative-direction.md](references/creative-direction.md) 建立内容因果链，再为各场设计认知变化、主体与空间尺度。每场应推进理解，并按主题需要改变场面和观察方式。主题事实从一手资料核对，示意和推演标明口径。实拍使用真实资料；程序世界可以原创，具体模型、字体和纹理记录来源或生成方法。

按[制作与验收标准](references/production-and-acceptance.md)完成整篇：研究与导演卡 → 素材链 → 一段代表性音画交接 → 全部场景 → 真实输入验收 → 单文件及工程包。代码起点只验证接口；正式作品按主题重新设计世界与声音。

## 默认交互：用户推进，空间持续运动

以 `节拍 → 目标状态 → 平滑过渡 → 可探索停留` 组织叙事。鼠标拖动或移动控制镜头，点击、滚轮、触摸或方向键推进。环境可连续运动，讲述进度由用户掌握。相机探索应实际改变视点、遮挡或空间关系。

把直接操作设计在内容里：拉开比较分界、旋转物体、移动光源、揭开材料层、调整模型条件等。明确命中区、指针捕获、边界与释放规则；拖动时交还控制，松手保留结果或按明确规则恢复。推进与内容拖动的手势分开归属。

页面专注动画、内容与直接交互。默认移除前后箭头、显式导航、操作教学、数值HUD及额外提醒；通过画面中的对象和动作反馈承接自由探索。保留主题内容与必要的失败反馈，正常体验不出现提示层。精简控件时保留动画、交互和声音；声音默认通过自然手势解锁，M键静音/恢复，无需常驻播放器。**自动播放、暂停、时间轴和视频式播放器只在用户明确需要时加入。** 离屏纹理、HDR、景深和画面合成是渲染实现，不应自动变成观众操作的功能菜单。

## 先让素材与渲染成立

读 [procedural-materials.md](references/procedural-materials.md)。理解几何、场函数、纹理和采样如何生成材料，再安排灯光、相机、运动与过渡。关键场景记录紧凑的素材链：`观众看见什么 → 几何/高度场 → 材质/法线 → 光照/阴影 → 时间与交互参数`。

优先使用 Three.js/WebGL/GLSL 或同等实时图形管线实现空间、材质与光照；Canvas 2D/SVG 可用于字形、纹理、HUD 和图表。需要特定实物或风格时使用合适的图像/三维素材工具，记录实际输出。

先实现代表主题的一段画面和一处直接交互，检查材料、光照、镜头与过渡是否共同成立，再扩展全篇。正式作品重做符合主题的世界、物体、文字与镜头。

```bash
# 默认：鼠标镜头、直接光源操作、用户推进、材质转场与状态声景
python3 <skill-dir>/scripts/deck.py init --topic "主题" --project <工程目录>
python3 <skill-dir>/scripts/deck.py build --project <工程目录> --output <交付文件-V1.0.html>
```

默认起点的接口见 [interactive-api.md](references/interactive-api.md)，声音编排按 [sound-and-transitions.md](references/sound-and-transitions.md) 第2–6节扩展。鼠标探索与声音使用同一交互路线。明确需要平面图解时用 `--engine flat`，接口见 [runtime-api.md](references/runtime-api.md)。明确需要固定时长播放或影片式演示时用 `--engine cinematic`，再读 [film-api.md](references/film-api.md)。

## 动作与连续性

动作实现见 [motion-recipes.md](references/motion-recipes.md)。连续运镜见 [camera-and-handoff.md](references/camera-and-handoff.md)；其中同物体投影交接仅用于内容确有理由的局部片段。材质化过渡见 [sound-and-transitions.md](references/sound-and-transitions.md) 第7节起。

- 运动解释观点：尺度、遮挡、受光揭示、因果、聚散、形变和材质变化承担表达任务。
- 主线来自内容递进：上一场的动作、数据、方向或问题引出下一场的新认识。场景主体与尺度随解释任务变化；局部可共享对象或构图。同一物体换背景和全篇锁定主物体，不能代替内容衔接。
- 再按场景关系选择连续运动、切换、遮挡或投影交接，处理需要的变形、边缘、厚度、阴影与折射。
- 导演目标、环境时钟和用户输入分开管理，再由同一更新路径计算画面；快速推进、倒退与重复进入仍保持连续。
- 准备首场后尽快展示，后续内容可分批准备；用画面渐入承接初始化，正常路径不增加准备说明或操作提醒。失败给出可见原因，避免永久空白。
- 质量预算覆盖像素、采样、阴影、实例和离屏纹理，回收资源并尊重减少动态效果偏好。

## 验收

```bash
node <skill-dir>/scripts/verify-interactive.cjs <交付文件.html> --out <新验收目录> \
  --interaction-script <工程目录/interaction-check.cjs> \
  --audio-check-script <工程目录/audio-check.cjs>
# 默认起点本身的烟测可改用 --starter
```

- 运行：在最终交付位置打开完整 HTML，检查 ready、首屏、品牌素材、完整推进与返回、快速切换、真实输入和错误日志。误开源码模板时应跳转成品或明确说明，避免显示缺失占位素材与永久准备状态。
- 交互：检查正常画面没有箭头、显式导航、操作提示或冗余HUD。真实拖动镜头与内容对象，验证对象/材料状态改变；松手后检查控制权与导航归属。仅按钮跳页或截图不同不足以证明内容交互成立。
- 语义与节奏：逐场回答“观众为什么到下一场、会新理解什么”，连看多场复核主体、空间尺度、构图、运动与停顿的变化；只有物体或背景变化而解释任务不变时，重做场景关系。
- 画面：实际看关键帧和连续操作，检查空间层次、材质触感、明暗、遮挡、镜头、接缝和文字；技术断言通过不能代替视觉审看。
- 声音：实测首次手势解锁、场景/动作/转场匹配、快速返回清理与后台恢复；在主音量之后采集实际输出，验证非静音、静音近零及恢复后的RMS。只见AudioContext运行或源缓冲非零不代表已经听得到。离线使用同源合成和混音，实际听审后才能报告听感验收。

发现问题后修正受影响部分并复验，保留真实检查范围。

## 交付与本地约定

交付带版本的独立 HTML、可编辑工程、讲稿/来源、素材账本、预览、同源声音试听和验收记录。成品内联运行资源，离线打开可用；工程保留可重建的依赖与入口，独立目录重建比对交付文件。交付链接指向成品，内部模板单独命名并给清楚入口。局部更新递增次版本，重大方案更新递增主版本，保留旧版。放入主题所属项目成果与交付；无项目时放入 `20-领域/AI能力建设/projects/html-presentations/YYYY-MM-DD-主题/`。

技能源名与目录使用 `agd-`，显示名使用 `agd｜`；本机入口以符号链接指向源目录。默认本地保存、安装和打包，发布上传按用户当次指令执行。
