# 提示词方法论（内容生图通用）

## 生图前必答

1. 内容类型：信息图 / 海报 / 概念插画 / 编辑修复？
2. 平台比例：小红书 3:4 或 1:1？公众号 16:9？手机竖屏 9:16？
3. 是否有精确数据/品牌名（必须原样上图）？
4. 是否要"去AI味"（用 editorial-notes 风格 vs tech-neon）？

## 通用提示词结构（内容图）

```
类型+比例：创建一张 16:9 中文技术信息图 / 9:16 招聘海报 / 1:1 概念图
视觉：风格 + 配色 + 构图关键
内容：标题区文字 + 分区文字（逐行列出，只允许这些）
约束：严格比例、安全边距、简体中文、无Logo/水印/二维码/随机英文
```

## 反默认纪律（避免 AI 味视觉）

| AI 默认陷阱 | 打破 |
|------------|------|
| 居中深色 hero + 紫色渐变 | 用暖白/纸感/真实编辑痕迹 |
| 漂浮无意义气泡 | 用具体图标、代码窗、数据 |
| 模板化卡片堆叠 | 突出 1-2 个核心，其余弱化 |
| 左文右图懒构图 | 尝试居中覆盖、左下定位、画布式 |
| 标题正文同字号 | 标题 = 正文 2-3 倍 |
| 信息过载 | 图:文 ≥ 6:4，留白 ≥ 15-20% |

## 文案相关红线

- 这是内容图，不是写真/装饰图；看图要能猜到文章主题
- 配图元素必须来自实际内容，不塞无关角色
- 图表数字/比例必须与来源一致，不编数据
- 标签（#xxx）属于正文，不放图片

## 图生图编辑场景

`--edit --image src.png --prompt "只改X处，其余不变"`

适合：
- 修 1-2 个错字/乱码
- 改局部颜色/元素/背景
- 去某块文字换新内容
- 调整比例不裁人物

不适合（不如重生成）：
- 大面积重排
- 需要完全不同构图
- 文字系统错乱

## 交付前检查

- [ ] 图片真实存在、非空、目标尺寸
- [ ] 中文无乱码错字（vision_analyze 抄录核对）
- [ ] 比例正确、无裁切关键元素
- [ ] 无水印/Logo/随机文字
- [ ] 与文章内容一致（图文对应）
