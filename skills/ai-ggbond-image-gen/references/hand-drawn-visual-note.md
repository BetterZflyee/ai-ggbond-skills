# 手绘视觉笔记版式（hand-drawn visual note）

适用：用户反馈"太生硬"、"像 PPT 模板"、"像 Excel"时。已被验证：3840x2160，40-50 秒，中文可读。

## 立即可用的 prompt 骨架

```
生成一张 16:9 横向中文信息图，风格是手绘视觉笔记（hand-drawn sketch note / visual note），不是排版整齐的打印图表。

【整体视觉】
米白纸张背景，带轻微纸张纹理。所有线条都是手绘的、略带抖动的不规则手绘线，不要笔直的印刷线。
所有文字是中文手写字体，笔迹工整清晰，每个字的笔画结构必须完整、准确、可辨认，
接近清晰的楷体手写，千万不要潦草连笔、不要缺笔画、不要用形近字替代。
主体文字用黑色笔；重点用黄色荧光笔高亮；关键数字用红色笔；少量注释用蓝色笔。
可画手绘小图标：时钟、灯泡、心形、天平、箭头、星星、爆炸框。整体像一页内容密集的速写本笔记。

【布局】用留白和手绘波浪分割线分区，绝对不要印刷表格网格线：

顶部：手写大标题「XXX」，下方手写小字「副标题」。右上角画手绘公式框，框内「公式」，框下小字「释文」。
左上：手绘折线图（图标题 + 纵轴 + 横轴 + 两条反向曲线 + 灰区标注）。
右上：红色笔写巨大数字「1 : 5」+ 两行说明。
中部：六张手绘便签卡片（贴在纸上的方形纸条，边缘略歪斜），每张两行文字（见下方卡片铁律）。
右下：手绘小标题 + 四条要点，每条前面画手绘小方块。
底部：手绘波浪线拉出加粗判词。右下角页脚「署名 年月 版本」。

文字要求：所有汉字独立清晰、笔迹工整、字距明显；只允许出现以上列出的文字，
不得添加任何其他文字、英文说明、水印或 logo。严格 16:9 横向构图，四周留 4% 安全边距，禁止裁切。
```

## 便签卡片铁律（同 cognitive-impact-layout.md）

标签与内容必须用**冒号**连写在同一对引号内，且开头加强调句：

```
每张卡片里「你以为」那行用灰色笔写，「实际」那行用黑色粗笔写，并在关键短语下面画一道黄色荧光笔高亮。

【特别强调，这些字必须百分之百写对，不许用形近字替换】
第1张的「工单台」：第一个字是工人的工，不是正，不是止。
第4张的「闲聊」：第一个字是门里一个木的闲，不是问，不是间。
```

实测：这个"点名词组 + 拆解字形"的强调段**能修对已点名的字**，但不能阻止新的形近字错误出现。

## 错字迭代决策树（血泪经验）

```
发现错字
  ├─ 错字 ≥ 3 处 → 整张重跑，并在 prompt 里点名所有易错词
  ├─ 错字 = 2 处 → 整张重跑（比 edit 快且安全）
  ├─ 错字 = 1 处 → 评估语义是否被误读
  │     ├─ 不被误读（如 填空→填实）→ 止损交付，如实告知用户
  │     └─ 会被误读（关键结论错）→ 再重跑一次，仍错则换成印刷体
  └─ 全程禁止用 --edit 修中文文字（实测：无效或破坏其他区域）
```

## 为什么 --edit 修中文不可靠

`--edit` 是整图重绘（masked diffusion），模型会重新解释整个画面。
对英文/公式通常可控，但对密集中文便签区，模型容易：
1. 不改目标处（无效）
2. 顺手把邻近便签的文字也重写（破坏）

**结论：修中文正文一律整张重跑，`--edit` 只用于改图形元素（曲线方向、色块、布局）。**

## 成本基线

| 操作 | 耗时 | 备注 |
|------|------|------|
| 整张生成 | 40-110 秒 | 内容越少越快（手绘版约 40-50s） |
| --edit 局部 | 50-65 秒 | 成功率低，慎用 |

## 收敛预期

手写体中文的错字数通常按 2 → 2 → 1 → 1 收敛，很难降到 0。
**第 3 轮后若只剩 1 处非关键错字，应止损。**
