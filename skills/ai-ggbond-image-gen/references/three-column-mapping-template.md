# 三栏映射信息图模板（问题 → 根因 → 装置）

适用：认知拆解、个人系统诊断、方法论推导图。已被验证——3840x2160 一次成图、中文零乱码。

## 为什么用三栏而不是上下堆叠

- 左右都是窄格，每格只需 2-12 字 → 命中 gpt-image-2 的"短标签稳"区间
- 横向箭头天然表达"映射/推导"关系，不需要长句解释
- 同一行左中右并置，读者视线横向移动，不需要跳读

## Prompt 骨架（可直接改写）

```
生成一张 16:9 横向中文信息图，学术论文 Figure 风格：纯白背景 #FFFFFF，全图墨黑文字，唯一强调色为学术蓝 #1F4E9C。

版式：顶部标题带 + 主体严格三栏网格（细黑线分隔，中间栏到右侧栏之间有横向箭头表示映射）+ 底部证据带 + 收束条 + 页脚。

顶部标题带：左侧大字标题「主标题」；下方一行小字「副标题」；右侧一行公式「R(t) = R0 x (1 + r)^t」。

主体三栏，共 6 行，每行三格：
左栏表头「你问的问题」（窄栏）
中栏表头「根因 · 层层剖析」（最宽栏，每格内部自上而下三个小标签：现象 / 机制 / 深层）
右栏表头「干预装置 + 出处」（次宽栏，每格上半是装置名，下半是出处小字）

第1行：左格「短问题」；中格：现象「短词」，机制「短词」，深层「短词」；右格：装置「短句」，出处「书名 作者」
……（逐行列出，6-7 行）

底部证据带：两个并排小折线图。左图标题「A vs B（待实测）」，横轴 0 到 30，曲线先扬后落。右图标题「C vs 周数」，两条曲线一升一降。

底部收束条：一行加粗居中「一句话判词」。
页脚右下小字「署名 · 年月 · 版本」。

文字要求：所有中文标签都是短句，每个汉字独立清晰、字间距明显、字体为黑体加粗；网格化布局，每个单元格有细黑边框；只允许出现以上列出的文字，不得添加任何其他文字、英文说明、水印或 logo。严格 16:9 横向构图，四周留 4% 安全边距，禁止裁切。
```

## 硬约束清单

| 项目 | 约束 |
|------|------|
| 单格字数 | ≤12 字；格内三行的标签（现象/机制/深层）各 ≤10 字 |
| 行数 | 6 行最佳；超过 7 行单格就要再短 |
| 尺寸 | 3840x2160（16:9）；竖版用 2160x3840 |
| 图表标注 | 未实测的曲线必须写「待实测」，不要伪装成数据 |
| 公式 | 避免下角标（R₀ 会渲染成 R0），直接写 R0 x (1 + r)^t |
| 引文出处 | 放在方案格下半部分的小字里，不要混入正文 |

## 验证方式（必做）

用 `vision_analyze` 读本地文件，让它**逐字抄录**每个区块的文字，再与定稿逐条比对。
错字只重绘那一格：`image_gen.py --edit --image out.png --prompt "只把第N行X格的『错字』改成『正字』"`。
