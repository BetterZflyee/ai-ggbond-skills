# 中文信息图提示词策略（gpt-image-2 实测）

## 核心结论

gpt-image-2 渲染**短中文标签**很稳，渲染**长中文段落/自由排版**容易乱码。所以要"让模型按格子写字"，而不是让它自由发挥。

## 策略优先级

| 策略 | 适用 | 成功率 |
|------|------|--------|
| 结构化网格 + 短标签（2-4字） | 高密度信息图 | ⭐⭐⭐⭐ |
| 低密度大字 + 留白 | 封面/概念图 | ⭐⭐⭐ |
| 分区卡片（每卡一个标题+几行） | 多模块内容 | ⭐⭐⭐ |
| 极简中文 + 英文节点标签 | 流程图/架构 | ⭐⭐⭐ |
| 全英文 + 中文图注 | 兜底 | ⭐⭐ |

## 失败模式（不要用）

- ❌ 叙述性段落："画面展示一个关于……的场景" → 模型自由发挥，文字全乱
- ❌ 连续 5+ 个汉字的长句密集堆叠 → 粘连、缺字
- ❌ 纯英文标注：用户要中文内容，全英文 = 违反需求
- ❌ PIL/HTML 拼字再贴图 → "像贴膏药"，用户明确拒绝

## 成功模板（raw 模式建议写法）

```
生成一张 {比例} 中文信息图，2160×3840 构图。

视觉：{风格描述}。

顶部标题区：大字「{标题}」居中，白色粗体，字间距明显。

画面主体分 {N} 个区域，严格网格布局：
[区域1]（上 1/3）：
- 标签：「2-4字短词」
- 图标/描述
[区域2]（左下 1/2）：
- 标签：「短词」
- 三行小字：「短词」「短词」「短词」

所有中文文字每个字独立清晰，字间距大，字体粗。
标签用 2-4 字短词，不要长句。
网格化布局，每个模块有明确边框分隔。
严格 {比例}，四周 8% 安全边距，禁止裁切。
```

## 长文/数据文案怎么传

- 精确数据必须原文直传（品牌名、百分比、金额一字不改）
- 长句交给模型会碎，先把长句拆成：短标签 + 一行说明
- 若内容必须长（标题/金句），单条控制在 12-20 字内
- 全部要上图的文字在 prompt 中逐行列出，并加一句"只允许出现以下文字"

## 质检与修复

1. vision_analyze 逐字抄录图上文字，与目标文案对照
2. 若局部错字（1-2 处）：用 `--edit` 图生图修复该区域，**不要整张重来**
3. 若大面积乱码：按上面策略改写 prompt 重新生成
4. 连续 3 次失败 → 停止，提供 prompt 给用户手动生成

## 输出尺寸管理

- 目标 9:16 高分辨率（2160×3840）：直接请求 2160x3840（OpenLux 支持），不要先 1024x1536 再拉伸
- 若 API 拒大尺寸：生成 1024x1536，再用 PIL/工具等比放大到目标
