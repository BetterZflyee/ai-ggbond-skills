# 认知冲击型信息图（分区图形版式）

适用：需要「Aha moment / 颅内高潮」而非「查得到」的信息图。已被验证：3840x2160 一次成图、中文零乱码（v3）。

## 为什么不用三栏网格

三栏网格 = 白底 + 细黑线 + 单元格 + 行号 → **用户第一眼评价「这是一张 Excel 表」**。
即使信息完备，也只会被当成「分类归档」，不会产生认知冲击。

## 冲击力从哪来（内容层，比排版更重要）

三条可复用的「冲击配方」：

1. **公式里藏一个反直觉的项**
   例：`R(t) = R0 x (1+r)^t x e^(-λt)`——多出的 `e^(-λt)` 衰减项，把「不经营＝持平」的错觉打破。
   配方：乐观公式 + 一个被忽略的负向项。

2. **给一个不对称的兑换率**
   例：`1 : 5`（1 次负面 = 需 5 次正面抵消）。
   配方：把模糊感受换算成具体倍数，倍数越大越震。

3. **「你以为 vs 实际」的自我识别对**
   例：「你以为：她不会走 / 实际：她在积累离开资本」。
   配方：第一行写读者心里的原话（越自洽越好），第二行揭机制。

## 版式骨架（五区，禁止网格线）

```
┌─────────────────────────────────────────┐
│ 标题 + 副标题          │  公式 + 一行释义 │
├─────────────────────────────────────────┤
│ 主视觉：大折线对比图    │  巨大数字 1 : 5  │
│ （两条反向曲线+灰区）   │  + 两行说明      │
├─────────────────────────────────────────┤
│ 三列 × 两行 对比卡片（浅灰底、细边框）      │
├─────────────────────────────────────────┤
│ 收束判词（加粗居中）        页脚（小字）    │
└─────────────────────────────────────────┘
```

要点：
- **左上放主视觉折线图**：蓝实线向上 + 黑虚线向下 + 中间灰区标「差额 = 你的损失」+ 一条水平灰点线标「你以为的一直线」。这个对比图本身就是冲击源。
- **右上放大数字**：警示红、超大字号，配一行解释。
- **卡片区**：浅灰底圆角卡 + 细边框，**不是网格线**。
- 明确写 **「绝对不要画表格网格线，不要行号，不要 Excel 感」**。

## ⚠️ 卡片文字渲染铁律（v2 失败教训）

**错误写法**（v2 实测：模型只渲染出「你以为」三个字，后面的短句全丢）：
```
每张卡片上半是灰色小字「你以为」，下半是黑色粗体「实际」：
卡片1：你以为「只响应需求」实际「关系变成工单台」
```

**正确写法**（v3 实测：六张卡片全部完整渲染）：
```
极其重要：每张卡片内必须完整渲染两行文字。第一行格式固定为「你以为」加冒号加短句，
冒号后面的短句必须渲染出来，不许省略；第二行格式固定为「实际」加冒号加短句。
第1张卡片，第一行「你以为：只响应需求」，第二行「实际：关系变成工单台」
……（逐张写全）
```

关键差异：
- 标签与内容之间用**冒号**连接，写在同一对引号内；不要用「标签」+「引号内容」的分离写法
- 开头加**强调句**（「极其重要」「不许省略」），并逐张卡片完整写全

## 硬约束

| 项目 | 约束 |
|------|------|
| 尺寸 | 3840x2160（16:9）；竖版 2160x3840 |
| 单条短句 | ≤12 字；卡片两行合计 ≤20 字 |
| 卡片数 | 6 张（3×2）最佳 |
| 曲线标注 | 未实测的曲线必须写「待实测」 |
| 公式 | 避开下角标，用 e^(-λt) 而非上标写法 |
| 页脚 | 标注版本号（v2/v3），便于迭代比对 |

## 验证方式

1. 先全图 `vision_analyze` 逐字抄录
2. **卡片区必须再用 `region=[x1,y1,x2,y2]` 放大复核一次**——全图扫描容易漏掉「标签下内容为空」这类缺字
3. 发现缺字：`image_gen.py --edit --image out.png --prompt "把第N张卡片补全为……"`；改动超过一区时直接重跑（v3 即重跑成功，比 edit 更稳）
