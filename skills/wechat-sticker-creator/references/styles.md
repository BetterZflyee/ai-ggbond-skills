# Styles

## 风格映射

| 风格代码 | 风格名称 | 适合内容 |
|---|---|---|
| `high-density` | 高密度信息大图 | 干货清单、数据报告 |
| `retro-pop` | 复古波普网格 | 工具对比、清单拆解 |
| `folder` | 文件夹/档案风格 | 方法论、流程说明 |
| `receipt` | 打印热敏纸风格 | 步骤指南、入门教程 |
| `vintage-journal` | 复古手帐风格 | 经验分享、个人表达 |
| `vector-illustration` | 矢量插图风格 | 概念解释、教育内容 |

## 比例建议

- `16:9`：默认，适合信息密度高的内容
- `1:1`：适合朋友圈/小红书方图场景
- `3:4`：适合纵向叙事与长内容

## 选择策略

1. 先看内容类型（干货/故事/教程/报告）
2. 再看传播场景（横版信息图或平台方图）
3. 最后确认比例并在提示词中重复强调
