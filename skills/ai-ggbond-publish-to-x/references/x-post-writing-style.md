# X 发帖写作风格（飞哥偏好，2026-05-27 确认）

多次迭代后明确的飞哥 X 发帖风格铁律。

## 核心原则

**不劝、不邀、不推销——让人自己点进来。**

## 禁止项

| 禁止 | 示例 | 原因 |
|------|------|------|
| 强引导/推销 | "你怎么看""来聊聊""推荐你看看" | 操控感，像营销号 |
| AI 味大词 | "深入探讨""赋能""值得注意的是""此外" | 塑料感，不像人话 |
| 一句话推荐 | "这篇写得特别好，强烈推荐" | 自卖自夸，反效果 |
| 平行罗列 | "第一...第二...第三..." | 像说明书，不是分享 |

## 应该做

- **信息差钩子**：翻完内部信、发现一个细节、推出来的结论——这些制造好奇心
- **名人洞见钩子**：引用宝玉等人的关键一句话
- **真实脆弱感**："写到一半想删""发怵""自己都有点接不住"
- **具体判断**：不是"AI很重要"，是"替代的不是基层，是传话+翻译+审批那一整层"
- **长短句交替**：3-5字短句穿插在20-30字长句之间
- **去掉过渡词**：不要"此外""另外""值得注意的是"，直接开始新句子

## 长短控制

- **推荐文案（朋友圈/群聊）**：50-100字，一条判断 + 一个钩子
- **X Thread**：每条 ≤ 280 字符，6-8 条拆分
- **X 长帖**：全文 ≤ 1000 字，保持节奏

## 去 AI 味检查清单

来自 `ai-ggbond-article-writer` 的"去AI味五步法"，适用于 X 发帖：
- □ 是否有"在快速发展的背景下"类开头？
- □ 是否有"深入探讨""赋能""优化""总而言之""此外"？
- □ 句子长度是否太均匀？（需要长短交替）
- □ 是否缺乏个人观点/情感？
- □ 读起来像真人说话吗？
