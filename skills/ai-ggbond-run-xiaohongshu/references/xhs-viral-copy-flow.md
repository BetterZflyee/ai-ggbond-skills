# XHS Viral Copy 链路（Memory 增强版）

目标：输入一条爆款 URL，输出"高贴合主题"的可发布新笔记。
**增强：复刻前检查与用户 Persona 的兼容性，确保复刻结果像「你会发的内容」。**

## 标准四步流程

1. 输入爆款笔记 URL
2. **Persona 兼容性检查（NEW）** → 分析爆款因素
3. 生成新封面（参考封面图风格，不复用具体元素）
4. 发布（上传图文、填写标题正文，发布前确认）

## 1) 输入

- `source_url`：爆款笔记链接
- `copy_mode`：`style-only`（默认）| `medium` | `tight`
- `persona`：当前 active Persona（自动从 Runtime Context 获取）

## 2) Persona 兼容性检查（NEW — Memory 驱动）

在开始复刻前，先评估源笔记与用户 Persona 的兼容性：

```
Persona 兼容性检查：
- 主题相关性：源笔记主题是否在用户内容支柱范围内？
- 语气兼容性：源笔记的语气（如"傲娇嘴硬"）与用户的 Persona 是否兼容？
- 立场一致性：源笔记的立场/观点与用户的定位是否一致？
```

处理策略：
- ✅ 高度兼容：直接复刻结构，替换细节
- ⚠️ 部分兼容：保留互动机制和结构，**更换语气和案例**以适配 Persona
- ❌ 不兼容：告知用户"这篇笔记的内容调性不适合你的定位"，建议是否更换参考笔记

## 3) 源笔记拆解（同原版）

提取：标题模板、封面模板、正文模板、互动模板、标签模板

## 4) Viral Copy 改写规则

保留原版的 tight/medium/style-only 三级规则，新增：

**Persona 改写层（所有模式必过）**：
- 替换为 active Persona 的口头禅/固定句式
- 调整语气符合 Persona 的「发帖风格」
- 确保结尾 CTA 是用户 Persona 会用的方式

## 5) 输出格式

1. 标题：3 个备选（标注 Persona 契合度）
2. 正文：1 版可发布（通过 Persona 自检）
3. 封面 prompt：1 条
4. 话题：5-8 个
5. **Persona 自检结果**：✅/⚠️ + 调整说明

## 6) 发布衔接

调用 `references/xhs-publish-flows.md`（Hermes 适配版）
