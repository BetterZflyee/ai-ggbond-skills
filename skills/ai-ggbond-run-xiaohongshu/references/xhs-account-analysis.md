# XHS 账号分析（Memory 增强版）

目标：快速判断一个小红书账号"现在处在什么位置、为什么涨或不涨、下一步该优先改什么"。**在此基础上，增加「与你自己的相关性」分析。**

## 0. 与原版的核心差异

原版只分析目标账号，本版额外回答：
- 这个账号的成功/失败模式与你有什么关系？
- 你能从中学到什么、不能学什么？
- 放在你的定位下，哪些动作值得复制？

---

## 1. 输入

建议用户至少提供以下之一：
- `account_url`：账号主页链接
- `account_name`：账号名称或截图
- `analysis_goal`：诊断目标

**Memory 自动注入**：
- `user_identity`：用户核心身份
- `user_xhs_account`：用户自己的小红书账号（如有）
- `user_goals`：当前小红书运营目标

---

## 3. 分析维度（5+1）

原版 5 维度 + 新增第 6 维度：

### 3.1-3.5 原版五维度（保持不变）
- 定位清晰度
- 内容结构力
- 互动转化力
- 账号辨识度
- 增长可持续性

### 3.6 对你的参考价值（NEW — Memory 驱动）

评分逻辑：对比目标账号与用户的定位/目标，判断参考价值。

```
对你的参考价值: x/5

判断依据（从 Memory 提取的用户上下文）:
- 定位相近度：目标账号的内容领域与你的领域重叠程度
- 策略可迁移性：对方的成功策略能否直接套用
- 差异化启发：对方做得好但你不适合做的 → 知道边界
- 风险提前感知：对方踩的坑你是否也可能踩
```

输出：
- 「可学」：哪些动作值得直接复制
- 「不要学」：哪些看起来好但不适合你
- 「可以改」：哪些动作需要适配你的定位后才能用
