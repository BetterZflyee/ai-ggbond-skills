# XHS 首页推荐流分析（Memory 增强版）

目标：分析小红书首页推荐流里"为什么这类内容会被推给你"。
**增强：增加「与你账号的关系」和「你可复用的动作」两层。**

## 0. 适用场景

- 想理解首页推荐逻辑
- 想从推荐流里找选题灵感、标题套路
- 想判断某类内容适不适合你继续做

## 1. 输入（增强）

除通用输入外，**自动注入**：
- `user_identity`：你的核心身份
- `user_content_pillars`：你的内容支柱
- `active_persona`：当前人设风格

## 2. 浏览器抓取流程（Hermes 适配）

1. `browser_navigate(url="https://www.xiaohongshu.com")` 打开首页
2. `browser_snapshot()` 确认在推荐流页面
3. 采样首页前 10-20 条内容，记录：title, hook, cover_text, cover_type, account_type, likes/comments/collects, tags, cta, reason_to_stop
4. 如卡片信息不完整，`browser_click` 进入帖子详情补齐
5. 保留重复主题样本，帮助判断推荐流偏好

### 4.4 与你的关系（NEW — Memory 驱动）
```
- 内容重叠度：首页有多少内容与你的领域相关
- 你的优势区：哪些内容你做得比首页样本好
- 你的盲区：哪些方向你没覆盖但首页在推
- 机会窗口：基于推荐流信号，你可以立刻做的 1-2 件事
```
