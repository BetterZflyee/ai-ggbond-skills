# XHS 选题灵感（Memory 增强版）

目标：把平台信号、账号定位和用户需求合并成可发布的选题清单。
**增强：每条选题增加「用户适配分」，确保选题不仅"能火"，而且"像你会发的"。**

## 0. 核心原则（增强）

- 先看平台信号 → 再看账号定位 → **最后过用户适配筛**
- 选题必须自带互动钩子
- 选题要和 active Persona 的语气、边界、风格保持一致
- **不做和用户定位无关的热点搬运**

## 1. 输入（增强）

除通用输入外，**自动注入 Memory 上下文**：
- `user_identity`：用户核心身份
- `user_content_pillars`：用户内容支柱（从 Memory 提取）
- `user_current_goals`：用户当前优先级目标
- `active_persona`：当前激活的 Persona 风格约束

## 2. 信号来源（同原版）

- 平台侧信号
- 需求侧信号
- 账号侧信号（由 Memory 填充）

## 3. 选题生成 + 用户适配筛（NEW）

### 3.5 用户适配筛选（Memory 驱动）

候选选题全部通过后，额外过「用户适配筛」：

```
每条选题的打分（0-8分）:
  热度信号: 0-2
  账号匹配: 0-2
  互动潜力: 0-2
  可写性:   0-2
  用户适配: 0-2 ← NEW（基于 Memory）
```

用户适配分评估逻辑：
- `2分`: 选题直接服务于用户当前P0目标，且契合用户身份/经验
- `1分`: 选题与用户领域相关但非核心，或需较大改编
- `0分`: 选题与用户定位完全无关，不建议发布

输出时按总分排序，用户适配分 0 的选题直接建议跳过。

## 5. 输出格式（增强版）

每条选题新增 `用户适配说明` 字段：

```
1. 选题标题：___
   选题角度：___
   目标人群：___
   互动钩子：___
   内容结构：___
   风险提示：___
   用户适配：x/2 — 为什么适合/不适合你：___
   Persona自检：这段话像不像{活跃人格}会说的？✅/⚠️
```
