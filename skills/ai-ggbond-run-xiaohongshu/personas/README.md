# Persona 管理系统

本目录存放小红书运营可用的预设 Persona。每个 Persona 是一个独立的人格配置文件，决定内容生成的语气、风格、边界。

---

## 可用 Persona

| Persona | 文件 | 描述 | 适用场景 |
|---------|------|------|---------|
| 飞哥 AI Native | `feige-ai-native.md` | 专业严谨、结果导向、AI战略视角 | 行业分析、深度内容、专业知识分享 |
| 默认动态 | `../persona.md` | 从 Memory 动态填充 | 未指定时的默认回退 |
| 虾薯傲娇 | `xia-shu-tsundere.md` | 傲娇嘴硬、短句口语、电子宠物感 | 轻快话题、互动型内容 |
| （自定义） | 新建 `.md` | 按需创建 | 按需使用 |

---

## 使用方式

### 激活 Persona
在操作前指定即可：
```
用飞哥AI Native人格，帮我写一篇小红书笔记
用虾薯傲娇人格，帮我回复这条评论
```

### 创建新 Persona
1. 复制 `_default.md` → `personas/<name>.md`
2. 填入以下字段：
   - 身份描述
   - 气质/性格关键词
   - 发帖语气规则
   - 评论回复风格
   - 内容支柱（3个）
   - 口头禅/固定句式
   - 禁忌（红线）
   - 视觉偏好
3. 使用时指定 `@<name>` 或描述激活

### Persona 继承规则
- 如果 Persona 文件中某个字段未定义，回退到 `persona.md` 默认值
- 如果 `persona.md` 中也未定义，回退到 Memory 中的用户风格偏好
- Memory 中的偏好优先级 > Persona 预设 > 系统默认

---

## Persona 设计原则

1. **Memory > Preset**：用户的真实偏好优先于预设模板
2. **可组合**：不同 Persona 可在不同场景切换，不要求全账号统一
3. **可演化**：根据实际使用效果持续微调
4. **不硬编码**：不绑定特定 Agent，任何 Agent 都可以切换 Persona
