# 风格管理

**重要先说：你的核心身份、定位、内容支柱来自你的 Hermes Memory——本目录只做「语气微调」。**

---

## 怎么工作

1. Skill 启动时，从你的 Memory 自动构建 Persona（身份/定位/风格偏好/红线）
2. 如果你对自动推断的语气不满意，可以说「用XXX风格」微调
3. 微调只改表达方式，不改你的核心定位

---

## 内置风格模板

| 风格 | 文件 | 怎么激活 | 适合 |
|------|------|---------|------|
| 专业深度 | `professional.md` | 「用专业风格」 | 行业分析、深度内容、知识分享 |
| 温暖治愈 | `warm.md` | 「用温暖风格」 | 生活感悟、情感话题、成长分享 |
| 犀利直接 | `sharp.md` | 「用犀利风格」 | 观点输出、反常识、行业批评 |
| 傲娇毒舌 | `tsundere.md` | 「用傲娇风格」 | 轻快话题、互动型内容 |

---

## 创建你自己的风格

1. 复制 `_default.md` → `personas/<name>.md`
2. 只填语气和表达方式（身份来自 Memory）
3. 说「用<name>风格」激活

---

## 风格叠加

可以说「用专业风格，但加一点幽默」——两种风格会叠加以 Memory 为基底。
