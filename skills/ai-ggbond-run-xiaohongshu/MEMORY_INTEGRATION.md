# Memory Integration Guide — ai-ggbond-run-xiaohongshu

## 为什么需要 Memory 集成？

普通小红书运营技能做的是「通用分析」——告诉你这篇笔记为什么会火、这个账号为什么涨粉。
但它们不会告诉你：**这对你意味着什么，你应该怎么做。**

Memory 集成让分析从「What happened」升级到「What this means for YOU」。

---

## Memory 集成的三层架构

### Layer 1: Identity（身份层）
从 Hermes User Profile 提取：
- 你是谁（核心身份/角色）
- 你在做什么（当前主线目标）
- 你的风格偏好（内容风格、排版偏好）

→ **用途**：决定内容生成时的 voice 和 angle

### Layer 2: Context（上下文层）
从 Hermes Memory 提取：
- 近期重点优先级（求职/副业/IP/学习...）
- 已有的经验/案例/成绩
- 当前的避坑和红线

→ **用途**：选题筛选时评估「用户适配分」，过滤无关内容

### Layer 3: Learning（学习层）
从 Knowledge Base + Session History 提取：
- 已验证有效的内容模式
- 失败过的操作路径
- 沉淀的标题模板/互动钩子

→ **用途**：复用已验证的模式，避免重复试错

## 在每个操作中如何应用

### 账号分析时
```
通用版：这个账号定位清晰度 4/5，因为...
增强版：这个账号定位清晰度 4/5。对比你的定位（AI Native 超级个体），
       它在「个人IP人格化」上比你强，建议你学习它的___做法。
       但它缺乏你的「技术深度+战略视野」优势。
```

### 选题灵感时
```
通用版：给你5条选题...
增强版：给你5条选题，按与你的定位匹配度排序：
       1. ★★★★★ AI Agent创业的3个坑（高度契合你的AI战略定位）
       2. ★★★★☆ 从求职到副业的时间管理（契合你的当前P0目标）
       3. ★☆☆☆☆ 美妆测评（与你的定位无关，建议跳过）
```

### 评论回复时
```
通用版：回复"已收到，会考虑"
增强版：根据你的「专业严谨、结果导向」风格，
       回复："收到。这个方向我们验证过，核心卡点是___。
              建议先从___入手，一周内能看到结果。"
```

### 爆款复刻时
```
通用版：复制这篇爆款的结构，替换内容
增强版：这篇爆款的核心钩子是「身份认同+争议立场」。
       按你的AI Native定位，可以替换为「程序员 vs AI产品经理的思维差异」，
       保留同样的争议结构，但内容换成你的领域。
```

## Memory 写入规则

以下情况应写入 Hermes Memory：

| 触发条件 | 写入内容 | 格式 |
|---------|---------|------|
| 发现新的有效内容模式 | [XHS-Pattern] 模式描述 | `[XHS-Pattern] 标题「为什么___」句式在你的AI领域互动率高 — 来源: url` |
| 账号定位更新 | [XHS-Positioning] 新定位要素 | `[XHS-Positioning] 小红书账号定位更新为: ___` |
| 已验证的避坑经验 | [XHS-Pitfall] 避坑记录 | `[XHS-Pitfall] 发布时段避开周一上午，你的受众活跃在___` |
| Persona 风格微调 | [XHS-Persona] 风格偏好 | `[XHS-Persona] 评论回复偏好: 专业但有温度，不超过3句话` |

---

## 隐私与安全

- 绝不将 Memory 中的敏感信息（密钥、路径、私人对话）写入任何公开发布的内容
- 内容发布前强制过一遍红线检查
- Persona 中的「傲娇嘴硬」等风格设定参照原版，但不照搬具体措辞
