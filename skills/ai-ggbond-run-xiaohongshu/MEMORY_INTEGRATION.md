# Memory Integration Guide — ai-ggbond-run-xiaohongshu

## 为什么需要 Memory 集成？

普通小红书运营技能做「通用分析」——告诉你这篇笔记为什么会火、这个账号为什么涨粉。
但它们不知道**你是谁**。

Memory 集成让每次分析都变成**关于你的分析**：

| 没有 Memory | 有 Memory |
|------------|----------|
| "这个账号做对了这3件事" | "这个账号做对了这3件事。其中第2件你也能做，因为你有___经验。第3件不适合你，因为你的定位是___" |
| "给你5条热门选题" | "给你5条选题。按与你的适配度排序：第1条高度契合你的领域，第5条与你的定位无关建议跳过" |
| "已回复评论" | "已用你的风格回复：___（像你说的话吗？）" |

---

## 三层 Memory 架构

### Layer 1: Identity（你是谁）
从 Hermes User Profile 自动提取：
- 核心身份：AI从业者 / 设计师 / 投资人 / 创业者 / ...
- 当前目标：求职 / 副业 / IP / 学习 / 创业 / ...
- 风格偏好：专业严谨 / 温暖治愈 / 犀利直接 / 幽默风趣 / ...
- 已有平台：公众号 / 小红书 / 其他社交媒体的现有定位

→ **决定：内容生成时的身份视角和话语体系**

### Layer 2: Context（你有什么）
从 Hermes Memory 自动提取：
- 专业领域：你最擅长什么？
- 已积累的经验/案例/成绩
- 当前的避坑和红线
- 近期优先级

→ **决定：选题筛选时的适配度、内容深度的边界**

### Layer 3: Learning（你验证过什么）
从 Knowledge Base + Session History 提取：
- 已验证有效的内容模式
- 失败过的操作路径
- 沉淀的话术模板

→ **决定：复用已验证模式，避免重复试错**

## Memory 写入规则

以下情况应写入 Hermes Memory（供跨会话检索）：

| 触发条件 | 写入格式 |
|---------|---------|
| 发现有效内容模式 | `[XHS-Pattern] <模式描述> — 来源: <URL>` |
| 更新账号定位 | `[XHS-Positioning] <定位要素>` |
| 验证避坑经验 | `[XHS-Pitfall] <避坑描述>` |
| 调整风格偏好 | `[XHS-Persona] <风格偏好变更>` |

---

## 隐私与安全

- 绝不将 Memory 中的敏感信息写入公开发布内容
- 内容发布前强制过红线检查
- 任何涉及密钥/路径/私人对话的信息不进入对外文案
