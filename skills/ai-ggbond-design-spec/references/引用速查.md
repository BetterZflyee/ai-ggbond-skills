# 引用速查（design-kb 数据字段）

> 本文件是 `ai-ggbond-design-spec` 的字段速查表。**它不存风格数据**——风格内容一律现查 `design-kb/data/*.json`。
> 这里只说明「哪个字段是什么意思、输出时放哪一段」。

## 数据文件与字段

### `data/route.json` — 场景路由（13 条）

| 字段 | 类型 | 含义 | 输出位置 |
|---|---|---|---|
| `trigger` | string[] | 命中关键词 | 判断依据，可在「来源」行标注 |
| `primary` | string | 首选风格 key | 输出「✅ 首选」 |
| `alt` | string[] | 1-2 个备选 key | 输出「◻ 备选」 |
| `question` | string | **必须先问的反问** | 输出「❓ 反问」原文 |
| `note` | string | 补充说明/飞哥偏好 | 输出在反问下方 |

**匹配规则**：取命中 `trigger` 词最多的那条；一条都不中就走风格族反查。

### `data/styles.json` — 风格库（16 种）

| 字段 | 用途 |
|---|---|
| `key` | 程序内标识，route/top10/combos 都用它引用 |
| `name` | 中文名 + 英文名，输出用 |
| `family` | 风格族（克制型/秩序型/氛围型/叙事型/亲和型/反叛型/复古型），反查用 |
| `visual` | 核心视觉特征，**必输出** |
| `palette` | 配色，**必输出**（含具体色值） |
| `typo` | 字体与字号层级，**必输出** |
| `mood` | 情绪传达 |
| `audience` | 目标受众，用于「为什么选它」 |
| `age` / `occupation` | 受众画像 |
| `scenes` | 适用场景 |
| `industries` | 适用行业 |
| `caution` | **已知雷区，必须原样呈现**，不许省略 |
| `sites` | 参考站名数组，取前 2-4 个 |
| `tags` | 风格标签 |

### `data/top10.json` — 现成提示词（10 条）

| 字段 | 用途 |
|---|---|
| `rank` | 1-10 排名 |
| `key` | 对应 styles 的 key |
| `why` | 为什么排这个位置 |
| `core` | 核心要点（一句话） |
| `scene` | 适用场景 |
| `aud` | 受众 |
| `ref` | 参考标准/站点 |
| `pro` / `con` | 优势 / 劣势 |
| `prompt` | **可直接用的完整提示词**，含 `{占位符}` 需替换 |

**重要**：只有 10 种风格有 prompt。另外 6 种（`minimal` / `glass` / `y2k` / `motion3d` / `collage` / `retro-print`）必须用 styles.json 的 `visual`+`palette`+`typo` 现场拼装。

### `data/combos.json` — 混搭方案（6 组）

| 字段 | 用途 |
|---|---|
| `name` | 组合名（A × B） |
| `logic` | 为什么能搭（底层逻辑同源在哪） |
| `visual` | 视觉描述 |
| `scene` | 适用场景 |
| `why_use` | 对飞哥的具体价值 |
| `prompt_extra` | **追加到提示词末尾的补充段** |

### `data/audience.json` — 受众依据（列表）

| 字段 | 用途 |
|---|---|
| `style` | 风格中文名 |
| `seg` | 受众细分 |
| `evidence` | 依据来源 |
| `note` | **可信度标注**：标「推测」的引用时要说明是推测 |

### `data/sites.json` — 参考站（100 个）

| 字段 | 用途 |
|---|---|
| `name` / `url` | 站名与地址 |
| `category` | 分类（大赛与奖项/图库/规范/工具…） |
| `content` | 这个站到底有什么 |
| `resource_type` | 资源形态 |
| `position` | 定位 |
| `verify` | **核验说明**，含「失效/已修正」必须一并告知用户 |
| `verify_level` | **A/B/C 核验等级**，C 级必须标注 |
| `url_note` | 地址补充说明 |

### `data/site-style-map.json` — 站↔风格映射

`{ "站名": ["风格中文名", ...] }`，用于「这个风格去哪看」的反向查询。

## 输出四段与字段的对应

```
✅ 首选：{styles.name}（{styles.family}）
   配色：{styles.palette}
   字体：{styles.typo}
   视觉：{styles.visual}
   ⚠️ 已知风险：{styles.caution}          ← 必须原样
   参考站：{styles.sites 前 2-4 个}

◻ 备选：{每个 alt 的 name + family + caution 摘要}

❓ 反问：{route.question}                  ← 必须原样，不许改写
   补充：{route.note}

🎯 提示词：{top10.prompt 或按 styles 拼装}
{+ combos.prompt_extra（若用组合）}
{+ 万能负向清单}
```

## 万能负向清单（原文，附加到任何 prompt 末尾）

```text
【禁止】米白底 #F5EFE6 + 陶土色 #C67B5C 的组合；深色底 + 发光边框 + 光束特效；
卡片内再套卡片；「01 / 02 / 03」式编号小标题；斜体衬线大标题配细字重；
提示框左侧一根彩色竖条；无来源的环境光与发光；过度圆角（>16px）配大阴影；
彩虹式多色数据图；居中对称却无层级的标题堆叠；纯装饰性图标（不带信息量）。
```

## 飞哥历史偏好（已固化，优先于通用规则）

| 偏好 | 内容 |
|---|---|
| PPT 风格 | 白底 + 苹果发布会风，大留白大字号，关键数字居中，极简装饰 |
| 点缀色 | 品牌红 `#E41E2C` 仅作点缀，非主色 |
| 明确不要 | 深色主题（PPT）、米白+陶土、行业报告腔 |
| 配图风格 | 学术风高密度信息图（像论文 Figure），拒绝科普风 PPT 图 |
| 文章配图 | 白底黑字高留白 + 少量技术蓝 |

## 脚本用法速查

```bash
S=~/.agents/skills/ai-ggbond-design-spec/scripts/advise.py

python3 $S "做一张电商主图"          # 文本推荐（四段）
python3 $S --json "做一张电商主图"    # JSON，给程序调用
python3 $S --style clean-app         # 直接查某风格完整规格
python3 $S --list                    # 列出 16 风格/13 路由/6 组合
python3 $S --doctor                  # 知识库体检（文件/引用/覆盖缺口/核验状态）

# 退出码：0=命中或成功  1=未命中路由（需人工判断）  2=知识库缺失或损坏
```

## 维护

知识库更新后**不需要改本技能**——技能每次现读。只有两种情况要改：

1. `design-kb` 路径变了 → 改 `SKILL.md` 和 `scripts/advise.py` 里的 `KB` 常量
2. 新增了数据文件 → 在 `SKILL.md` 的表格和本文件补一行字段说明
