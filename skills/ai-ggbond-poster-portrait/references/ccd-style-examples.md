## 场景模板库

### 室内居家
```

光线：午后窗光 + 暖色台灯 / 阴天柔光 / 黄昏侧光
服装：oversized毛衣 + 短裤 / 棉质睡裙 / 针织开衫 + 居家裤
```

### 城市街拍
```

```

## 姿态动作库

### 坐姿
```
靠近窗边坐姿，身体轻微侧向镜头，一只手自然搭在腿边
盘腿坐在沙发上，双手环抱靠枕
侧身坐在椅子上，下巴轻靠椅背
```

### 站姿
```
靠墙站立，一脚微微弯曲，重心偏移
背对镜头微微转头，头发被风吹起
双手插兜站立，肩膀微耸
```

### 特写
```
低头微笑，刘海遮住一只眼睛
仰头闭眼感受阳光，颈部线条舒展
双手捧杯贴近脸庞，眼神看向镜头
```
