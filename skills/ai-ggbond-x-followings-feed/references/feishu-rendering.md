# Feishu/Lark 平台渲染行为

## 链接渲染规则

### 裸URL → 自动识别为超链接 ✅
```
https://x.com/username/status/1234567890
```
飞书会自动将裸URL渲染为可点击的蓝色超链接。

### 反引号包裹 → 渲染为代码块 ❌
```
`https://x.com/username/status/1234567890`
```
反引号包裹的URL会被渲染为代码块（灰色背景、等宽字体），**不可点击**。

### Markdown链接语法 → 渲染为超链接 ✅
```
[链接文字](https://x.com/username/status/1234567890)
```
标准Markdown链接语法在飞书中可正常渲染为超链接。

## 最佳实践

**输出日报/摘要时**：使用裸URL格式，飞书自动识别为超链接。

```markdown
- **标题** (@来源)
  - 描述内容
  - 🔗 https://x.com/username/status/1234567890
```

**不要使用**：
```markdown
- **标题** (@来源)
  - 描述内容
  - 🔗 `https://x.com/username/status/1234567890`  ← 不可点击！
```

## 其他飞书Markdown支持

| 语法 | 支持情况 |
|------|----------|
| **粗体** | ✅ 支持 |
| *斜体* | ✅ 支持 |
| `行内代码` | ✅ 支持 |
| ```代码块``` | ✅ 支持 |
| [链接](url) | ✅ 支持 |
| 裸URL | ✅ 自动识别为超链接 |
| # 标题 | ✅ 支持 |
| - 列表 | ✅ 支持 |
| 1. 有序列表 | ✅ 支持 |
| > 引用 | ✅ 支持 |
| | 表格 | ⚠️ 部分支持 |

## 注意事项

1. **飞书IM消息**和**飞书文档**的渲染行为可能略有差异
2. 飞书IM消息中，裸URL会自动识别并显示为卡片预览（如Twitter链接会显示推文预览）
3. 长链接在飞书IM中会被截断显示，但点击仍可跳转
