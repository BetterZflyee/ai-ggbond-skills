# 上游来源与吸收范围

项目：[wechat-layout-copilot](https://github.com/frederick-kk/wechat-layout-copilot)。
本模块固定复用 2026-11-17 调研过的 v0.7.0 提交：`96fd55564b0e44e50530a0d0504083d59f3eaee9`；本次不声称它仍是最新版本。

吸收的方法：个人版式规则持久化、按阅读场景选组件、参数化生成、样稿复查、保存重开以及区分平台验收层级。基础排版编译器为本次独立实现，加入 Markdown 导入、15 类静态组件、文件保真检查、图片归档和现有发布器交接。

本地 v2 在保留既有白底黑字风格的基础上，增加内容分组间距、按任务拆分比较表、图片角色与缩小字号检查、数字层级、真实宽度预览、文字放大测试和独立的设计报告。代码空白纳入精确保真。上游两个 SVG 文件未改动，这些改进不归为上游已提供的功能，也不声称 v2 是上游版本号。

内置的上游文件只有：

- `vendor/wechat-svg-click-reveal/render.py`
- `vendor/wechat-svg-data-chart/render.py`

文件保持原样，哈希见 `vendor/provenance.json`；MIT 原文与版权署名保存在 `vendor/LICENSE.upstream`。原作者头像、纸纹、品牌配图、动图与视频未纳入交付素材。目录中其余 48 项是带固定版本链接的参考，不是本地完成品。

上游的浏览器/秀米记录是作者报告。此前仅离线抽测，未在此机器验证微信端。本次新增的浏览器与脚本检查记录保存在实际交付报告中，不据此推导目标账号或手机兼容性。Ego lite/Hermes 支持路径此前查到官方文档，本模块不强制安装或重新配置浏览器。

项目源码许可不自动赋予文章图片、第三方字体或秀米模板的使用权。实际使用外部素材时保留来源与对应许可。
