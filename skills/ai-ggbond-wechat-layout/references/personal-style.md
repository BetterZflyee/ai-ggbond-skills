# 个人版式依据

2026-11-19 读取现有写作技能的 `wechat-semantic-rhythm-typesetting.md`、`wechat-html-precision-typesetting.md` 和设计知识库长期要求后构建。本文件记录模块依据，不修改长期记忆。

执行优先级：用户本次要求 → 稿件品牌规范 → 用户确认过的文章习惯 → 本模块 profile → 上游示例。新要求可调整默认值，不把历史记录变成额外批准关卡。

- 默认 15px 正文、1.9 行高、18px 章节标题、白底 #FFFFFF、文字 #2B2B2B、少量蓝 #2563EB。这些是个人风格起点，不是平台硬规定。
- 连续语义讲完再分段。脚本保留原稿段落，只报告过长段落，不机械切句或合并。
- 主标题仅在 `meta.title`，摘要仅在 `meta.summary`，封面单独处理。Markdown 导入时明确记录移动。
- 保留作者已有强调，排版不新增论点。引文与解释分开，出处来自输入，不编造作者。
- 图片尽量利用正文宽度、保比例、不放大低分辨率小图。仅照片默认 8px 圆角；截图、图解保留完整边缘。检查图内文字在手机上的实际字号，无阴影，alt 不变图注。数据出处或授权署名确需显示时，使用来源段或 `show_caption:true`，不因“干净”删出处。
- 不自动添加阅读时长、听阅提示、订阅口号、公众号名片或 CTA。
- 重组件靠得太近时提示复核密度，不自动丢弃或挪动内容。
- 默认不加纹理、装饰分隔线、大块暖色、每段卡片。上游头像与示例品牌不代表用户品牌。

`felix-clean` 采用 S1 的层级秩序和 S14 的字阶思路。`felix-editorial` 为可选候选，字号更大、左对齐、标题更明显，代价是相同内容占更多屏幕；未获用户确认，不能改成长期默认。字体使用系统字体，不分发字体文件。本地知识库的风格归纳不构成外部素材授权。

旧指南的段长、卡片数量不是每篇必须达到的配额；密度由文本决定。复制 profile JSON 后调整，使用 `--profile /path/to/profile.json`，并记录变更理由与实际反馈。

## v2 的间距与数字层级

保留已确认的字号与正文风格，细化内容归属。`felix-clean` 的章节前距 34px、标题后距 10px；`felix-editorial` 分别为 36px / 12px。普通组件间距 24px，连续段落按各 profile 的段距；首块前距 18px。用块内上间距避免相邻外边距折叠导致实际距离失真。

指标组件使用 22px 的主数值、13px 的说明；表格默认 14px，数字列右对齐且使用等宽数字。原输入的小数位、单位和正负号不因美化而修改。表格、图片、注释的字号都应按实际内容调整；不能仅为了挤进屏幕继续缩字。

这些参数说明本模块的默认选择，不是所有公众号的设计标准。字体放大后应允许换行和增高，避免固定高度裁字；审查意见保留测量环境和人工判断。
