## 一、风格选择指南

### 1.1 如何选择合适的信息图风格？

根据文章主题、调性和目标受众，从以下维度选择风格：

| 维度 | 考虑因素 | 推荐风格 |
|------|---------|---------|
| **文章主题** | 技术/专业/商业 | 高密度信息大图、文件夹风格 |
| | 生活/美学/文艺 | 复古手帐、打印热敏纸 |
| | 对比/分析/评测 | 复古波普网格、矢量插图 |
| **目标受众** | 专业人士/产品经理 | 高密度信息大图、档案风 |
| | 普通用户/小白 | 复古手帐、打印热敏纸 |
| | 年轻群体/创意人群 | 复古波普网格、矢量插图 |
| **内容密度** | 高密度数据/参数 | 高密度信息大图、波普网格 |
| | 中等密度/概念解释 | 文件夹风格、矢量插图 |
| | 低密度/温馨分享 | 复古手帐、打印热敏纸 |

### 1.2 风格选择流程

```
分析文章特征
    ↓
提取关键要素（主题、受众、调性、密度）
    ↓
匹配推荐风格（3-5款）
    ↓
用户确认或重新推荐
    ↓
生成对应风格的信息图
```

### 1.3 风格推荐规则

系统将根据以下规则自动推荐3-5款合适风格：

1. **技术产品拆解** → 高密度信息大图、文件夹风格、矢量插图
2. **效率工具评测** → 复古波普网格、高密度信息大图
3. **行业趋势分析** → 档案风、高密度信息大图
4. **方法论分享** → 复古手帐、文件夹风格
5. **入门教程** → 打印热敏纸、复古手帐、矢量插图

## 二、高密度信息大图风格

### 2.1 风格概述

**适用场景**：技术产品拆解、专业数据分析、复杂概念可视化
**视觉特点**：实验室精密手册感 + 波普实验风格
**核心优势**：信息密度极高、专业感强、数据可视化效果好

### 2.2 视觉规范

#### 色彩系统（蓝图·波普实验室）

| 用途 | 颜色 | 色值 | 说明 |
|------|------|------|------|
| 背景 | 专业灰白/蓝图网格 | #F2F2F2 | 精密感 |
| 系统基色 | 柔和青绿/鼠尾草绿 | #B8D8BE | 功能区块 |
| 高亮强调 | 荧光粉 | #E91E63 | 关键警告/赢家数据 |
| 标记高亮 | 柠檬黄 | #FFF200 | 半透明高亮效果 |
| 线条艺术 | 炭黑棕 | #2D2926 | 技术网格、坐标线 |

#### 布局规范

- **信息坐标化**：每个模块必须有坐标标签（如R-20, G-02, SEC-08）
- **实验室手册美学**：微观细节（技术图纸）+ 宏观数据（大标题）
- **高密度**：每图6-7个模块，最小化边距
- **视觉对比**：大粗体标题 vs 超精细技术注释（8pt）

### 2.3 模块结构（6-7个必含模块）

```
[MOD 1: 品牌阵列] - 4x4或3x3矩阵，荧光粉高亮"最佳选择"
[MOD 2: 参数刻度] - 技术标尺，显示"标准"vs"高级"数值增量
[MOD 3: 深度拆解] - 产品技术草图，带"放大"标注圈
[MOD 4: 场景网格] - 对比卡片，0.5pt细线分隔
[MOD 5: 警告区域] - 高对比粉/黑区域，"避坑提醒"
[MOD 6: 快速检查] - 实验室数据表风格小摘要
[MOD 7: 状态栏] - 垂直/水平信息块堆叠
```

### 2.5 质量检查清单

- [ ] 色彩过滤：是否只用了系统性的粉、绿、黄、黑？

- [ ] 张力检查：标题是否有足够大的视觉冲击力？

## 三、复古波普网格风格

### 3.1 风格概述

**适用场景**：产品评测、对比分析、清单类内容
**视觉特点**：70年代复古波普艺术 + 瑞士网格系统
**核心优势**：对比鲜明、视觉冲击力强、信息模块化清晰

### 3.2 视觉规范

#### 色彩系统（复古波普）

| 用途 | 颜色 | 色值 | 说明 |
|------|------|------|------|
| 画布背景 | 暖复古奶油/米色 | #F5F0E6 | 复古感 |
| 平涂强调色 | 鲑鱼粉、天蓝、芥末黄、薄荷绿 | - | 波普艺术 |
| 视觉锚点 | 纯黑 | #000000 | 极端对比 |
| 视觉锚点 | 纯白 | #FFFFFF | 极端对比 |
| 线条艺术 | 粗黑线 | - | 统一描边 |

#### 布局规范

- **严格网格布局**：方形和矩形单元格，粗黑线分隔
- **每图6-7个模块**：每个模块占据独立单元格或单元格组
- **反转对比**：关键警告或主类别必须使用白底黑字或黑底白字
- **模块化模式**：文本和图形分离，部分单元格纯文本，部分纯插图

### 3.3 模块结构（6-7个网格模块）

```
[Grid 1: 品牌选择] - 子网格含简单品牌图标和名称
[Grid 2: 参数标准] - 平涂波普色粗描边标尺/条形图
[Grid 3: 选择对比] - 并排列，颜色对比（如粉vs蓝单元格）
[Grid 4: 型号类型] - 抽象平涂剖面图或侧视图
[Grid 5: 识别技巧] - 浅色单元格列表格式，粗黑勾选标记
[Grid 6: 避坑区域] ⚠️ - 纯黑底白字，红/粉叉标记
[Grid 7: 速查总结] - 高度结构化迷你网格表（可选）
```
