# 女性角色信息图设计规范（2026-06-08 实战）

## 核心要求

飞哥要求科技/AI主题贴图加入**女性化角色**，让信息图更有吸引力。

### 角色设计原则

| 维度 | 要求 |
|------|------|
| 比例 | 角色占画面 25-30%，不要太大抢信息图主体 |
| 风格 | 动漫 × 奢华杂志感，成熟有魅力 + 可爱细腻 |
| 表情 | 自信微笑，微微带笑，锐利但温暖 |
| 服装 | 与项目气质匹配的优雅连衣裙/制服 |
| 发型 | 长发微卷或精致短发，有光泽感 |

### 配色方案（奢华杂志感）

| 项目类型 | 主色 | 辅色 | 质感 |
|---------|------|------|------|
| 压缩/效率 | 深梅子 #2D1B2E | 玫瑰金 #B76E79 | 丝绒 |
| 文档/转换 | 深海军蓝 #0A1628 | 香槟金 #C9B06B | 皮革 |
| Agent/进化 | 深祖母绿 #1A3A2A | 玫瑰金 #B76E79 | 锦缎 |

### Prompt 关键规则

1. **角色描述要具体**：服装颜色、发型、表情、手中道具、周围元素
2. **角色比例明确**："small character in bottom-right corner, 25% of image"
3. **信息密度高**：6+ 功能模块，含数据、对比、命令
4. **文字用英文**：gpt-image-2 中文渲染不可靠，prompt 用英文，文字内容英文
5. **风格关键词**：luxury magazine, feminine illustration, anime style, elegant, mature

### 飞哥反馈记录

- v1-v2：角色太大（50%+），信息图太简单 → 要求缩小角色、增加信息密度
- v3：角色大小OK但信息图仍是英文 → 要求中文（但gpt-image-2中文乱码）
- v4：角色更小(25-30%)，信息更多 → 飞哥确认方向OK
- 关键教训：**信息密度 > 角色大小**，角色是点缀不是主体

### 抽象概念的角色化设计（2026-06-09 新增）

当贴图主题是抽象概念（如"系统提示词""记忆""效率"）而非具体项目时，需要创造一个**代表该概念的精灵/女神角色**：

| 概念 | 角色定位 | 视觉特征 |
|------|---------|---------|
| SOUL.md / 系统提示词 | SOUL精灵 / 配置女神 | 银白长发+尖精灵耳+深蓝科技战甲+霓虹电路纹理+手持全息配置文件 |
| 记忆/知识管理 | 知识女神 | 祖母绿长裙+发尾渐变绿+衔尾蛇手镯 |
| 压缩/效率 | 断舍离女王 | 深梅子长裙+手握水晶+数据粒子流过手中 |
| Agent / 自动化 | Agent指挥官 | 深紫战甲+发光符文+魔杖+全息控制面板 |

**角色与写真的区别（关键）**：
- ❌ poster-portrait风格 = 摄影写真，真实相机感，CCD/胶片质感，适合人物特写
- ✅ 贴图角色风格 = 科幻插画，动漫×奢华杂志感，适合信息图配角
- 贴图角色是**视觉锚点**（25-40%），不是主体。信息图才是主体。
