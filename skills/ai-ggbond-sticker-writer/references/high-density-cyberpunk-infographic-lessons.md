# 高密度赛博朋克信息图实战经验（2026-06-10）

## 背景
飞哥要求生成Claude Fable 5贴图配图，要求：赛博朋克风、科技风、高密度信息大图。

## 失败教训

### 第一版：中文prompt太简单 → 被否
- 只描述了"分为N个区域"，没有足够的视觉细节
- 生成结果不是"高密度信息大图"，只是普通信息图
- 飞哥原话："这张图片不属于高密度信息大图"

### 第二版：英文prompt → 被否
- 用英文写了详细的赛博朋克prompt，视觉效果达标
- 但飞哥要求：**除专有名词外必须全中文**
- 飞哥写死了这条规则到记忆

## 成功策略

### 高密度信息大图prompt必须包含的元素：
1. **背景描述**：深色背景#0A1628 + 霓虹蓝#00D4FF细线网格 + 扫描线效果 + 电路板纹理
2. **面板描述**：多个半透明面板叠加发光边框
3. **坐标标签**：每个模块标注坐标（行1列1、R1-C1等）
4. **模块密度**：6-8个模块，每个有标题+图标+数据+对比
5. **发光效果**：霓虹发光边框、光晕、数据流线条
6. **底部标注**：品牌/日期/级别小字

### prompt结构模板：
```
创建一张16:9横版赛博朋克风超高密度信息图。[背景描述]。
顶部：[标题+副标题+分隔线]。
主体：[N]个模块[M]行[N]列网格布局，霓虹边框，半透明面板，坐标标签：
模块1：标题「XX」，图标XX，数据「XX」，对比「XX」，[颜色]边框。
...
底部：[品牌标注]。
风格：超高密度[类型]感，每个像素都有信息，坐标标签，精细技术注释，发光边框，深色背景加高对比霓虹元素，赛博朋克数据可视化，无水印。所有文字必须是简体中文，每个字独立清晰，字间距大，字体粗。
```

### 关键约束：
- **prompt必须全中文**（专有名词除外）
- **不要用脚本**（ContentAnalyzer会覆盖自定义prompt），直接调API
- **批量生图前检查API余额**（每张约$0.004）
- **gpt-image-2** 默认模型，尺寸1792x1024（16:9）
- **图片间等待20秒**，避免429

## 生成结果
3张赛博朋克高密度信息图成功生成（1.7-2MB），包含6-8个模块，霓虹发光效果，坐标标签。API余额耗尽后停止。
