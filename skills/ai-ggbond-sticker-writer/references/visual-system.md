# 贴图视觉与组件

先按长期设计要求确认交付形态和信息密度。用户 2026-11-16 已把默认改为商业杂志编辑风，多张分图、短 prompt、清晰中文等偏好继续保留。默认候选可用“杂志封面”和“编辑批注”两种变体；用户已指定成功稿、风格或 prompt 则直接执行，不新增批准关卡。科技风、高密度、深色霓虹仅在用户选择时使用。

## 保留的视觉资产与角色

- AI朱朱侠：亚洲面孔、短发、深蓝科技夹克、半透明 AR 眼镜，卡通科技形象。用户要求角色时使用，结合系列参考图保持一致，不自动把角色加到每张贴图。
- 主题精灵、女神或女性化角色：代表系统提示词、记忆、压缩等主题，风格偏科幻插画。角色与信息建立关系，不能变成无关人物写真；占比由具体内容调整，不固定每页 25% 或 40%。
- 原有波普、档案、票据、手帐、矢量风格可作为内容适配方案。深色贴图可以插入白底文章，长文正文的字号和背景规则不直接覆盖图片内部设计。

## 信息密度与手机尺寸

每张图承担清楚的任务，但不强制固定模块数。一页信息过多时，先拆分任务、减少冗余或改连续多图；保留数据和出处，不靠缩字让它勉强塞下。

先看 320/375px 下的真实呈现。已知原图最小字号时，用“原图字号 × 显示宽度 / 原图宽度”估计；12px 是当前复核起点，不是统一标准。未知字号需视觉或 OCR 辅助检查，不能填一个猜测值让检查通过。

**1792×1024 是 7:4，不是精确 16:9。** 真正 16:9 的例子包括 1600×900、1920×1080；3:4 可用 1200×1600。尺寸请求受工具实际参数约束，生成后检查原文件，不以提示词写了比例就认定正确。不得静默拉伸；需要裁图时先看重点内容和留白，并按当前编辑工具规则处理。

封面检查原图及目标账号实际使用的方形/横向缩略图裁切，避免标题、角色面部或关键数字被截掉。当前预览器显示原图，没有自动裁切模拟；需要裁切时另行检查，不能把原图预览算作裁切验收。

## 提示词

简短描述主题、主构图、配色和角色关系，再列精确上图文字；不要堆十五个风格参数段。默认中文描述，专有名词、官方产品名与用户要求的双语保留。标签只在正文。用户已有 prompt 时保留它，必要差异单列，不擅自重写整份提示词。

品牌、水印和许可分别处理。只用本次允许的素材与署名，不移除他人权利标识。个人水印是否添加由品牌要求或当前指令决定；不要自动画到每一张图上。

## 既有系列图中可复用的方法

2026-11-18 的本地双语系列稿展示了深色编辑网格、醒目数字、双语主次、原帖证据截图、时间线、观点页与问题收束。这些可以作为“事件解释＋证据卡”的结构参考，不能据此认定原稿事实已核实或该视觉已成为长期默认。

证据卡需保留来源和必要上下文；手机上截图小字难读时，在图外提供准确摘录或改成可编辑引用，不将截图本身作为事实已核验的证明。复用旧图时保持原页码与顺序；抽取部分页必须说明是节选，不能让图内页码与交付顺序造成误解。
