# Taste-Skill 方法论吸收记录

**来源**：[Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill)
**作者**：Leonxlnx
**吸收日期**：2026-05-29
**用途**：提升贴图和配图的视觉品味，打破AI图片的默认模式

## 核心理念

AI生成的界面/图片会塌缩成重复的默认模式。Taste-Skill通过"旋钮系统"和"反默认纪律"主动打破这些模式。

## 吸收的精华

### 1. Brief推断（先读懂再动手）

在生成任何东西之前，先输出一行"设计解读"：

```
"Reading this as: [页面类型] for [目标受众], with a [视觉语言] language, leaning toward [具体方案]."
```

**中文版**：
```
"解读为：为[目标受众]做的[内容类型]，采用[视觉语言]风格，倾向[具体方案]。"
```

**示例**：
- "解读为：为AI开发者做的技术贴图，采用科技风视觉语言，倾向深蓝霓虹+细线网格。"
- "解读为：为普通用户做的效率工具分享，采用复古波普风格，倾向高对比+手绘感。"

### 2. 三旋钮系统（Taste-Skill 核心）

| 旋钮 | 含义 | 范围 | 默认值 |
|------|------|------|--------|
| DESIGN_VARIANCE | 设计变化度 | 1=完美对称, 10=艺术混乱 | 8 |
| MOTION_INTENSITY | 动效强度 | 1=静态, 10=电影级 | 6 |
| VISUAL_DENSITY | 视觉密度 | 1=美术馆/透气, 10=驾驶舱/密集 | 4 |

**推断规则**：
| 用户说 | VARIANCE | MOTION | DENSITY |
|--------|----------|--------|---------|
| "极简/干净/冷静/编辑感" | 5-6 | 3-4 | 2-3 |
| "高端消费者/苹果风/奢华" | 7-8 | 5-7 | 3-4 |
| "活泼/狂野/Dribbble/实验性" | 9-10 | 8-10 | 3-4 |
| "落地页/作品集/营销站" | 7-9 | 6-8 | 3-5 |
| "信任优先/公共部门/无障碍" | 3-4 | 2-3 | 4-5 |

**贴图应用**：
| 贴图类型 | VARIANCE | DENSITY |
|----------|----------|---------|
| 数据冲击/价格对比 | 6-7 | 5-6 |
| 工具介绍/效率分享 | 7-8 | 4-5 |
| 经验分享/个人故事 | 8-9 | 3-4 |
| 技术拆解/架构图 | 5-6 | 6-7 |

### 3. 反默认纪律（Anti-Default Discipline）

**AI图片的10大默认陷阱**：

| 默认陷阱 | 为什么是陷阱 | 打破方式 |
|----------|-------------|----------|
| 居中深色hero | 所有AI图都长这样 | 改用左下角、右上角、全出血背景 |
| 紫色/蓝色AI辉光 | 千篇一律 | 根据内容选配色 |
| 漂浮的无意义气泡 | 没有信息量 | 用具体图标、数据替代 |
| 通用仪表盘卡片堆叠 | 无层次 | 突出1-2个核心 |
| 弱字体层级 | 标题正文差不多大 | 标题2-3倍于正文 |
| 克隆式章节 | 每个模块一样 | 每个模块独特构图 |
| "奢华"=米色衬线体 | 假高级 | 真奢华靠留白和克制 |
| "创意"=乱 | 不可读 | 创意必须可读 |
| 文字太多图太少 | 信息过载 | 图:文 ≥ 6:4 |
| 太密没有呼吸 | 压迫感 | 留白 ≥ 20% |

### 4. 构图多样性（Composition Variety）

**左文右图是AI最懒的构图**——必须主动选择：

| 构图 | 适用 | 说明 |
|------|------|------|
| 居中覆盖背景图 | 品牌感、冲击力 | 文字叠在大图上 |
| 左下角定位 | 编辑感、不对称 | 文字在左下，视觉在右上 |
| 右下角定位 | 高端感、留白 | 文字在右下，左侧大面积视觉 |
| 堆叠居中 | 简洁、聚焦 | 标题在上，图在下 |
| 画布式 | 艺术感、沉浸 | 整张图就是视觉 |
| 网格编辑 | 信息密度、对比 | 多模块网格布局 |
| 右文左图 | 打破惯性 | 反转经典 |
| 极简迷你 | 克制、高端 | 小焦点+大面积留白 |

### 5. Hero构图偏见打破

**默认左文右图是最过时的AI模式**。在选择构图前，先考虑：

- 居中覆盖背景图
- 左下角覆盖图
- 右下角覆盖图
- 顶部左侧引导
- 堆叠居中
- 画布式图片
- 网格编辑感
- 右文左图（反转经典）
- 极简迷你

只有在左文右图确实是最强选择时才用——不是默认。

## 与现有技能的融合

### 贴图生成技能

1. **反默认纪律**：在风格选择步骤后增加"AI默认陷阱检查"
2. **构图多样性**：在配图提示词生成时，不要默认左文右图
3. **三旋钮系统**：用于量化视觉参数，帮助用户做选择
4. **Brief推断**：在开始生成前，先输出一行"设计解读"

### 文章写作技能

1. **配图部分**：构图多样性规则应用于文章配图
2. **信息图**：反默认纪律应用于信息图生成

## 实际应用示例

### 贴图生成前的设计解读

```
【设计解读】
解读为：为AI爱好者做的技术工具分享贴图，采用科技风视觉语言，倾向深蓝霓虹+高对比构图。

旋钮设置：
- 设计变化度：7/10（科技风但不呆板）
- 视觉密度：5/10（中等密度，有呼吸感）

构图选择：居中覆盖背景图（品牌感+冲击力）
避免陷阱：不用紫色AI辉光、不用漂浮气泡、不用弱字体层级
```

### 配图提示词中的构图指令

```
【构图指令】（不要默认左文右图）
- 采用"居中覆盖背景图"构图
- 主视觉占60%面积，文字叠在上面
- 标题字号是正文的2.5倍
- 留白 ≥ 20%
- 不要漂浮的无意义装饰元素
```
