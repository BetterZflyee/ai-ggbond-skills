# 贴图配图生成实战教训（2026-06-09）

## 背景

飞哥要求生成"一份让 Agent 翻身的系统提示词"微信贴图的配图。经历了6轮迭代才成功。

## 失败路径记录

### 第1轮：poster-portrait 女性写真风格 ❌
- 错误：参考了 ai-ggbond-poster-portrait 技能，生成了女性写真照
- 飞哥反馈："我不是让你给我生成女性的写真照，我要围绕这个贴图的内容来生成"
- **教训：贴图配图必须围绕内容主题，不是生成与内容无关的美女图。poster-portrait 技能只用于肖像海报场景，不应用于内容贴图。**

### 第2轮：纯科技风信息图（无角色） ❌
- 错误：去掉了所有角色，只留图标和文字卡片
- 飞哥反馈："完全不行，太简单了"
- **教训：纯图标+卡片的信息图缺乏视觉吸引力，需要有角色/视觉锚点**

### 第3轮：精灵女性角色 + 高密度信息 ❌
- 错误：生成了精灵耳朵的女性角色写真
- 飞哥反馈："不要构建女性角色了"
- **教训：用户要的是与内容相关的IP角色，不是任意的女性角色**

### 第4轮：低密度大字封面 ❌
- 飞哥反馈："内容还是太简单了，还是得高密度信息大图"
- **教训：飞哥默认要高密度信息大图，低密度方案除非用户明确要求**

### 第5轮：高密度中文信息图 → 中文乱码 ❌
- 问题：gpt-image-2 中文渲染乱码
- 飞哥反馈："中文字体都乱码了"
- **教训：gpt-image-2 中文乱码是硬伤，必须用结构化网格+短标签策略**

### 第6轮：极简英文封面 ❌
- 错误：为避免乱码全部改用英文
- 飞哥反馈："不行，你不能全用英文"
- **教训：中文内容贴图不能全用英文，必须解决中文渲染问题而非回避**

### 最终方案：用户自行生成 ✅
- 飞哥要求提供提示词，自己通过 Codex 生成
- 提示词策略：结构化网格 + 短中文标签（2-4字） + AI朱朱侠卡通IP角色

## 成功模式总结

### 贴图配图的正确思路

1. **先理解内容主题** → 配图必须围绕内容，不是装饰
2. **确认是否有IP角色需求** → 飞哥有"AI朱朱侠"卡通科技感男性IP
3. **选择信息密度** → 默认高密度，除非用户明确要低密度
4. **处理中文渲染** → 结构化网格 > 自由排版，短标签 > 长句

### gpt-image-2 中文渲染最佳策略

**策略一：结构化网格 + 短标签（推荐）**
- 用显式网格/表格/单元格描述布局
- 每个模块的中文标签 2-4 个字
- 强调字间距和清晰度
- 英文做辅助标签
- 示例：「自动发现」「并行安全」「知识文件」

**策略二：极简中文 + 英文标签（流程图/架构图专用）**
- 中文只留 1 个标题（3-5 字）
- 节点标签全用英文
- 强调 "Minimal text, maximum visual"

**策略三：用户自行生成（最终兜底）**
- 当 gpt-image-2 无法满足中文需求时
- 提供详细中文提示词，让用户用其他工具生成
- 不要反复尝试各种绕行方案浪费时间

### AI朱朱侠 IP 角色设定（贴图用）

卡通风格科技感男性角色：
- 亚洲面孔，短发，自信微笑
- 穿深蓝色科技夹克
- 戴半透明AR眼镜
- 风格介于扁平插画和3D渲染之间
- 线条干净，色彩鲜明

## 2026-06-10 补充：vision_analyze 502 验证降级

vision_analyze 会返回502错误（连续3次）。降级方案：
1. PaddleOCR：`pip install paddleocr paddlepaddle`，然后OCR提取图片文字对照原文

3. 不要因为验证失败就重生成——先确认图片有没有问题

## 关键规则

1. **贴图配图围绕内容，不是装饰** — 不要生成与内容无关的美女/风景图
2. **poster-portrait 技能不用于内容贴图** — 只用于肖像海报场景
3. **默认高密度信息大图** — 除非用户明确要求低密度
4. **中文用结构化网格策略** — 短标签（2-4字）+ 字间距 + 网格布局
5. **不要全用英文回避中文乱码** — 用户要的是中文内容
6. **gpt-image-2 无法满足时让用户自行生成** — 提供提示词，不浪费时间
