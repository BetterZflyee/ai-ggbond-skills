# 商业杂志编辑风：当前默认

来自旧合集 v2.7 中 2026-11-16 的用户确认。它优先于早期“AI 题材默认科技风”规则；用户本次指定风格时直接遵从。

纸色 `#F4F0E8` 或 `#FAF8F2`，墨色 `#111111` 或 `#1A1A1A`。只选一个强调色：墨绿 `#1F4D3A`、深红 `#8C2F2F`、暖棕 `#8A5A2B`。辅助灰 `#6B6B6B` 用于次要信息，仍需在实际背景上检查可读性。

一页先让读者看懂一个主判断或大数字，再看少量支撑信息。原规范的“约 40% 留白、最多 3 个支撑点”作为初始排布目标，遇到截图、来源或比较表时按内容调整，不为达到比例删掉必要证据。信息太多优先拆图，不缩成细小文字。

可选版式：

- 杂志封面：左侧大标题/数字，右侧低饱和主视觉，底部来源；根据标题长度调整占比。
- 跨页数据：左栏主判断，右栏共同指标的细线表格；保持可比较结构。
- 编辑批注：中央简单线稿/流程，外围少量准确批注，不用装饰冒充信息。

中文宋体或粗黑体建立标题性格，正文用清晰无衬线；短标签优先，品牌英文与指定双语保留。不用深蓝霓虹、发光边框、圆角卡片堆叠制造默认视觉。角色只在用户要求时加入。

提示词起点：

> 一张商业杂志编辑风信息图，比例按计划。米白纸色、黑字、单一墨绿强调，轻微纸张质感。以一个大标题和一个主视觉建立重心，少量准确支撑信息用细线组织，留出明显空白。不要霓虹光和卡片堆叠。精确上图文字与来源另列，不能自增数据。

实际检查：第一眼主次是否明确、320/375px 中文是否可读、来源能否辨识、封面裁切是否伤到标题、同组图片是否连贯。截图小字另附可读摘录；不能靠“杂志感”掩盖事实或阅读缺陷。
