# gpt-image-2 中文渲染网格策略（2026-06-09 实战）

## 背景

飞哥要求生成 Loop Engineering 公众号文章的科技风高密度中文信息图封面。经历 5 轮迭代：

| 版本 | 策略 | 结果 |
|------|------|------|
| v1 | 叙述性段落 prompt，中英混排 | 中文乱码严重 |
| v2 | 叙述性段落 prompt，纯中文 | 中文乱码 |
| v3 | 极简低密度，4个大字 | 中文OK但太简单，飞哥说"内容太少了" |
| v4 | 低密度+大字+光环 | 太简单 |
| v5 | **结构化网格+短标签+边框分隔** | 中文基本可读 ✅ |

## 成功策略：结构化网格布局

### 核心原则

1. **显式网格描述**：用"左侧30%上下两个卡片，霓虹蓝边框，半透明底板"这种精确的布局描述，不用"画面展示一个关于...的场景"这种叙述。

2. **短标签**：每个中文标签 **2-4个字**。字越短越不容易乱码。
   - ✅ 「发现」「分配」「执行」「手动提示」「人工瓶颈」
   - ❌ 「自动化任务发现与分诊机制」

3. **字间距强调**：prompt 中必须包含"每个字独立清晰，字与字之间有明显间距，字体粗"。

4. **模块边框**：每个信息模块用明确的边框/卡片分隔，让模型按格子渲染文字。

5. **英文辅助**：主要标签用中文，节点英文名做辅助（如 DISCOVER/ASSIGN/EXECUTE）。

### prompt 模板

```
创建一张16:9横版科技风高密度信息图。深色背景#0A1628，霓虹蓝#00D4FF细线网格。

顶部标题区：大字「[标题]」居中，白色粗体，每个字之间有明显间距。

画面主体分为[N]个区域，严格网格布局：

左侧区域（30%宽）：上下排列两个卡片，霓虹蓝边框，半透明底板。
上卡片「[模块名]」：
- [图标]
- 三行标签：「[2字]」「[2字]」「[2字]」
下卡片「[模块名]」：
- [图标]
- 三行标签：「[2字]」「[2字]」「[2字]」

中间区域（40%宽）：[视觉主体]
右侧区域（30%宽）：[数据/对比卡片]

底部横条：[来源信息]

所有中文文字每个字独立清晰，字间距大，字体粗。标签用短词（2-4个字），不要长句。网格化布局，每个模块有明确边框分隔。无水印。
```

### 关键参数

- 模型：gpt-image-2
- 尺寸：1792x1024（16:9横版）
- 中文标签长度：2-4个字
- 信息密度：6-10个模块
- 配色：深蓝#0A1628 + 霓虹蓝#00D4FF + 玫瑰金#b76e79

## 已验证的失败方案

| 方案 | 为什么不行 |
|------|-----------|
| 叙述性段落 prompt | 模型自由发挥，文字与要求不符 |
| 密集长句中文（>5字） | 粘连、缺字 |
| 纯英文标注 | 用户明确拒绝"除了专业词语其他不能用英文" |
| 极简低密度 | 用户嫌太简单 |
| Python 代码绘图 | 飞哥明确禁止 |
| Pillow 叠加文字 | "文字和图分离，像贴膏药" |
