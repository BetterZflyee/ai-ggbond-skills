# 多事件贴图叙事线程规则

## 核心铁律

**多个新闻事件合并成一张贴图时，必须用因果链/递进链串联，严禁平行罗列。**

用户原话："你要把这三件事情串起来，而不是单独作为三个故事讲。"

## 错误 vs 正确

### ❌ 平行案例陷阱

```
事件A：OpenAI造芯片了...
事件B：Anthropic告阿里了...
事件C：三大模型跳票了...
```

每个事件独立成节，像新闻摘要汇编。读者看完没有"原来如此"的感觉。

### ✅ 因果链/递进链

```
钩子：GPT-5.6需要政府审批
  ↓ 为什么？
OpenAI造芯片 → 政府看到全栈整合 → 开始介入
  ↓ 不只美国在动
阿里偷Claude数据 → 第一起AI知识产权诉讼
  ↓ 所以
三大模型集体跳票 → 技术准备好了，但发布节奏在政府手里
```

每件事是前一件事的"所以"或"不只是"，读者跟着一条线走到底。

## 叙事结构模板

### 模板1：因果链（A导致B导致C）

```
钩子（最震撼的结果）
  ↓ 为什么会出现这个结果？
原因1（最早的动作）
  ↓ 这引发了什么？
原因2（连锁反应）
  ↓ 所以
结果（所有事件指向同一个结论）
```

### 模板2：递进链（从小到大）

```
钩子（具体事件）
  ↓ 这不只是个案
同类事件1（扩大范围）
  ↓ 还有更大的
同类事件2（再扩大）
  ↓ 这说明
结论（趋势判断）
```

### 模板3：反转链（表象vs真相）

```
钩子（表面现象）
  ↓ 但真相是
深层原因1
  ↓ 而且
深层原因2
  ↓ 所以
结论（颠覆初始认知）
```

## 写作检查清单

- [ ] 每个事件之间是否有"所以"、"不只是"、"这引发"等连接？
- [ ] 读者看完是否有"原来这几件事是连着的"感觉？
- [ ] 是否存在独立成节、互不关联的事件？
- [ ] 结论是否由前面所有事件共同推导出来？

## 实战案例

**输入**：OpenAI造芯片 + Anthropic告阿里 + 三大模型跳票

**平行写法（❌）**：
- OpenAI：自己造芯片Jalapeño...
- Anthropic：发现阿里用2.5万假账号...
- 跳票：Claude Fable 5被禁...

**因果链写法（✅）**：
- 钩子：GPT-5.6需要政府审批
- OpenAI造芯片 → 政府看到全栈整合 → 开始介入
- 阿里偷数据 → AI知识产权战争升级
- 三大模型跳票 → 技术准备好了，但发布节奏在政府手里
- 结论：AI正在变成国家基础设施
