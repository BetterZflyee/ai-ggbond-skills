# 热点资讯调研→贴图工作流

当贴图主题是外部热点（新产品发布、行业事件、人物动态），需要先调研再写内容时，使用本流程。

## 调研阶段

### 搜索策略（3轮）

1. **第一轮：核心事实** — `web_search` 搜产品/事件名 + 年份
   - 目标：发布时间、发布方、核心定位、关键数据
   - 示例：`Claude Fable 5 Anthropic 2026`

2. **第二轮：深度细节** — `web_extract` 提取2-3篇权威源（TechCrunch/WSJ/Mashable等）
   - 目标：定价、性能数据、用户反馈、竞品对比、安全/争议点
   - 优先选带数据的文章（benchmark、价格、时间线）

3. **第三轮：社区反应** — `web_search` 搜 HN/Reddit 讨论
   - 目标：真实用户评价、争议点、冷思考素材
   - 示例：`Claude Fable 5 Hacker News` 或 `site:reddit.com`

### 信息提炼模板

调研完成后，按以下结构整理核心信息（用于写文案）：

```
- 一句话定位：[是什么，为什么重要]
- 关键数据1：[最有冲击力的数字/事实]
- 关键数据2：[对比数据/竞品数据]
- 痛点/争议：[用户关心什么，什么有争议]
- 时间节点：[免费期/上市/截止日等]
- 冷思考：[别人都在吹，但真正值得关注的是什么]
```

## 内容阶段

### 结构选择

热点贴图推荐「递进叙事」结构（非平行罗列）：

```
钩子/反常识 → 核心数据 → 机制/背景 → 价格/策略 → 冷思考/金句
```

- 钩子：用反差抓注意力（"太危险不敢发布"→ "今天你能用了"）
- 核心数据：给1-2个最有冲击力的数字，不要堆砌
- 机制：用一句话解释"为什么这么强"或"怎么做到的"
- 价格/策略：读者最关心的实际问题
- 冷思考：别人没说的角度，或者"你应该怎么看"

### 字数控制

- 飞哥要求500字以内（含标题、标点、emoji）
- 热点贴图信息密度高，初稿通常会超（800-1200字）
- **压缩策略**：
  1. 砍掉"解释性文字"——读者不需要你科普基础概念
  2. 合并同类段落——不要每个数据点单独成段
  3. 用竖线 `｜` 代替换行做并列数据（如 `Fable 5：29.3%｜Opus 4.8：13.4%`）
  4. 每个 section 控制在3-4行以内
  5. 结尾金句单独一行，不要加解释

### 配图策略

热点贴图的配图必须包含**调研数据**，不能是通用装饰图：

- 封面图：产品定位 + 最有冲击力的1个数据
- 数据图：benchmark对比、用户实测结果
- 策略图：定价、时间线、安全机制

科技/AI类热点默认用**科技风**（深色背景+霓虹蓝/紫）。

## 典型翻车点

| 问题 | 原因 | 解法 |
|------|------|------|
| 初稿严重超字数 | 信息量大，不舍得砍 | 用上述压缩策略，逐段砍到500以内 |
| 数据堆砌 | 调研收集太多数据 | 只留最有冲击力的1-2个，其余砍掉 |
| 科普腔 | 想解释清楚原理 | 热点贴图不需要解释原理，给结论就行 |
| 缺少冷思考 | 赶时间没做第三轮调研 | 第三轮搜HN/Reddit，找争议点 |
| 配图与内容脱节 | 用了通用科技风模板 | 配图prompt必须引用文章中的具体数据 |

## 实战案例

- 2026-06-10 Claude Fable 5 贴图：TechCrunch+Mashable+HN 三源调研，529字，3张科技风信息图
