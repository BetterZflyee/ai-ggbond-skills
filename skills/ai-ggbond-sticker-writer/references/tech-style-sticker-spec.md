# 科技风贴图风格规范（2026-05-29 确认）

飞哥偏好科技风作为贴图配图的默认风格。

## 视觉规范

- **背景色**：深蓝 #0A1628（深色背景）
- **主色调**：霓虹蓝 #00D4FF
- **辅助色**：霓虹紫 #A855F7
- **线条**：细线网格、发光边框、半透明层
- **布局**：中心聚焦式或严格网格
- **字体**：大标题粗体发光，正文清晰现代
- **卡片**：霓虹蓝边框 + 半透明背景 + 发光效果
- **箭头/连接线**：发光渐变

## 提示词模板

```
创建一张[比例]的信息图，使用科技风格。
深色背景（深蓝#0A1628），霓虹蓝(#00D4FF)和霓虹紫(#A855F7)点缀
细线网格、发光边框、半透明层

[具体内容...]

所有文字必须是简体中文，确保清晰无乱码，不要出现英文。严格[比例]比例。
```

## 适用场景

- 工具介绍、效率提升、技术科普
- AI产品/技能推广
- 数据对比、流程展示
- 不适合：温馨故事、生活方式、情感共鸣类（用复古手帐）
