# 贴图写作迭代实战：从新闻播报员到"我"的视角（2026-06-22）

## 背景

飞哥要求用Agent Reach调研"微信AI"后写贴图。调研数据非常丰富（微信小微灰度上线、iLink协议、380万小程序等），但连续三版文案被飞哥退回。

## 迭代过程

### V1：新闻播报员模式（飞哥："太AI化了"）

```markdown
昨天刷到一条新闻，愣了好几秒。

微信悄悄上线了一个AI助手，叫**小微**。

不是那种你问它答的聊天机器人。

你跟它说"帮我点一杯楼下咖啡店的拿铁"，它直接调用小程序帮你下单了。
你跟它说"明天早上8点帮我抢xx医院的专家号"，它到点自动挂号。
你跟它说"帮我做一个记录心情的小程序"——它真的能**凭空生成一个**。

为什么微信能做到这些？

因为微信里有**380万个小程序**。
```

**问题诊断**：
- 虽然去掉了"首先/其次/最后"等AI句式，但**整体结构仍是功能介绍**
- "为什么微信能做到这些？"是设问句
- 没有"我"的感受和判断
- 读起来像产品说明书

### V2：去AI味但仍是旁观者（飞哥："还是太AI味，不是从自我的角度"）

```markdown
昨天在群里看到有人说微信悄悄上线了个AI，我一开始没当回事。

又是什么套壳聊天机器人吧。

结果仔细一看，有点猛。

你跟它说"帮我点楼下那家拿铁"，它直接调小程序帮你下单了。不是给你个链接让你自己点，是**它帮你点**。

医院挂号、打车、查快递、交停车费——全都动嘴就行。

最离谱的是，你说"帮我做一个记录心情的小程序"，它能**凭空给你生成一个**。

我第一反应是：扯呢吧？
```

**问题诊断**：
- 加了"我一开始没当回事""我第一反应是：扯呢吧？"——有了"我"
- 但**中段仍然是功能罗列**（"医院挂号、打车、查快递、交停车费"）
- 本质还是在**介绍产品功能**，只是换了个口吻
- 飞哥说"你完全不是从自我的一个角度来去分享这个事情"

### 核心教训

**去AI味不是语言技巧问题，是视角问题。**

| 维度 | 新闻播报员（AI味） | "我"的视角（对味） |
|------|-------------------|-------------------|
| 开头 | "微信上线了AI助手" | "我昨天试了一下/我看到一个东西" |
| 中段 | 罗列功能（能做A、B、C） | 讲一个具体场景（我跟它说了一句话，它干了什么） |
| 判断 | "这很强大"/"这颠覆了" | "我第一反应是：扯呢吧？" |
| 结尾 | "一句话总结：..." | 不总结，让读者自己感受 |

### 正确写法的特征

1. **开头有"我"的触发点**：不是"XX发布了XX"，而是"我昨天刷到/试了一下/朋友跟我说"
2. **中段讲一个具体场景**：不是罗列功能清单，而是描述一个完整体验（我做了什么→它回应了什么→我的感受）
3. **判断是"我的"判断**：不是"这说明AI正在颠覆XX"，而是"我第一反应是：扯呢吧？"
4. **结尾不总结**：不写"一句话总结"，不说教，不替读者下结论

## 深层问题：去AI味的核心不是语言，是研究深度

飞哥说"AI味道太浓"时，表面问题是语言风格，**根本问题是内容空洞**。

没有具体事实支撑的贴图，再怎么去AI味也是空洞的。

### 写贴图前必须做的研究清单

1. 这个产品的**具体数据**是什么？（用户数、上线时间、灰度范围）
2. 它**怎么做到的**？（技术路径、底层架构）
3. 有没有**具体案例**？（谁在用、用了什么效果）
4. 跟**读者有什么关系**？（对谁有用、怎么用、要付费吗）

不做研究直接写 → 必然写出AI味十足的空洞内容。

## 关键学习

1. **去AI味不是删几个词**，是改变整个叙述视角（从分析师/播报员→普通人）
2. **"我"的视角 ≠ 加"我觉得"**，是要有自己的体验、判断、感受
3. **功能罗列是最大的AI味来源**——不管用什么口吻，罗列功能清单 = 产品说明书
4. **一个具体场景 > 十个功能描述**——选一个最有冲击力的场景展开，比列出所有功能更有效
5. **研究深度决定了去AI味的上限**——没有具体事实，再好的写作技巧也是空中楼阁
6. **多轮迭代是正常的**——飞哥可能纠正3-4轮才找到正确的风格，不要急着定稿
