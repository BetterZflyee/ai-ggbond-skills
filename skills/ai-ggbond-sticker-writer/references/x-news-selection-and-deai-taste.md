# X日报素材选题评估与去AI味实战（2026-06-22）

## X日报素材选题评估

从X日报中挑选素材做贴图/公众号时，先评估**传播性**，不要看到信号就直接写。

### 传播性强的素材特征

| 特征 | 为什么有效 | 示例 |
|------|-----------|------|
| **跟钱有关** | 所有人都关心 | "800倍成本差异"、"2周赚12万" |
| **跟时间有关** | 打工人痛点 | "省下2小时"、"一个人顶三个人" |
| **反直觉** | 引发讨论和转发 | "越AI越需要SaaS"、"AI抢的不是工作是生意" |
| **有具体故事** | 让读者"看到" | "13岁卖游戏机器人"、"月入4万美金" |
| **跟具体人群相关** | 读者觉得"这说的是我" | "制造业数据安全"、"自由职业者" |

### 传播性弱的素材（不建议做贴图/公众号）

- **产品更新**（GLM 5.2发布、Claude新功能）→ 读者反应："哦知道了"
- **行业趋势分析**（AI行业将增长10倍）→ 太空泛，跟读者没关系
- **政策/宏观叙事**（Trump说了什么）→ 波动大，容易过时
- **纯技术突破**（破解3500年古文字）→ 故事性强但跟读者没关系

### 判断标准

拿到一条X新闻，问自己三个问题：
1. **读者看到标题会想点进去吗？** → 跟我有关吗？
2. **读者看完会转发吗？** → 能引发讨论吗？
3. **读者能从中获得什么？** → 能赚钱/省钱/避坑/涨见识？

三个都答"是"→ 值得做。两个"否"→ 不做。

## 故事必须补充真实背景（2026-06-22 血泪教训）

贴图写故事时，**不能只写表面现象，必须搜索补充背后的真实背景**。

### 反面案例

```markdown
YC投了个AI叫Thomas，两周赚了12万。
没员工没办公室，连人都不是。
```

**问题**：信息量太薄，像新闻搬运。读者会想"这跟我有什么关系？"

### 正面案例

```markdown
YC投了个AI叫Thomas，两周赚了12万。

但它背后那个人挺猛的。
13岁开始做游戏机器人卖钱。18岁在NeurIPS发论文，给OpenAI做过贡献。
法国顶级工程学校退学创业，公司被收购了。
后来他做自由职业，月入4万美金。
然后他干了一件事：把自己克隆了。
```

**为什么更好**：
- 有具体人物背景 → 故事有厚度
- "月入4万美金" → 说明他本来就赚钱，AI是放大器
- "把自己克隆了" → 比"AI自己创业"更准确，更有冲击力

### 搜索补充背景的策略

```
"{创始人名} background"
"{公司名} YC batch"
"{创始人名} previous startup"
"{创始人名} NeurIPS / paper / contribution"
```

**搜索目标**：
- 创始人年龄、教育背景
- 之前的创业经历（被收购？失败？）
- 收入数据（月入多少？融资多少？）
- 技术背景（论文？开源贡献？）

**提炼原则**：不是堆砌简历，是找**让故事更有冲击力的具体数字和转折点**。

## 去AI味实战清单（2026-06-22 补充）

飞哥说"AI味道太浓"时，按以下清单逐项检查并替换：

### 必须删除的AI句式

| AI味句式 | 为什么是AI | 替换方案 |
|----------|-----------|----------|
| "以前创业最难的是什么？" | 设问句，AI最爱用 | 直接说"以前一个人创业，根本不可能" |
| "你可能会说" | AI过渡句 | 删除，直接说下一句 |
| "但你想想" | AI说服句 | 删除，用"对吧"代替 |
| "你卖的不是时间，是能力" | 金句感对比结构 | 改成更口语的表达 |
| "那你还在卖什么？" | 反问句结尾 | 改成"等哪天你发现...你就明白了" |
| "这不是威胁，就是个现实" | 说教感 | 删除，让读者自己感受 |
| "早点想明白，没坏处" | 说教结尾 | 改成具体场景或事实收束 |

### 去AI味五步法

1. **删设问句**：所有"X是什么？""X为什么？"改成直接陈述
2. **删过渡句**："你可能会说""但你想想""说实话"全部删除
3. **删金句对比**："不是X，是Y"改成只说Y
4. **删说教结尾**："所以你应该""早点想明白"改成具体事实
5. **加口语确认**："对吧""吧""呢"拉近距离

### 检查方法

写完后大声读一遍。如果听起来像"老师在讲课"或"分析师在评论"→ AI味。如果听起来像"朋友在分享一个有意思的事"→ 对了。

## 本次实战记录（2026-06-22）

### 背景
飞哥从X日报中看到YC虚拟人Thomas的新闻，要求转成贴图。

### 迭代过程

**第1版（飞哥说"传播性不够强"）**：
- 问题：角度太空泛（"AI正在抢你的生意"），跟读者没关系
- 教训：不是所有X新闻都适合做贴图，要先评估传播性

**第2版（飞哥说"可以，但AI味道太浓"）**：
- 问题：设问句、金句对比、说教结尾
- 教训：用humanizer技能的29个AI写作模式逐项检查

**第3版（飞哥说"可以讲一下具体怎么操作的"）**：
- 问题：只写了表面现象，没有补充背后的真实背景
- 教训：搜索创始人背景，找具体数字和转折点

### 最终版本要点

1. **开头**：直接说事件（"YC投了个AI叫Thomas，两周赚了12万"）
2. **背景**：搜索补充创始人真实经历（13岁、NeurIPS、月入4万美金）
3. **核心洞察**：不是"AI自己创业"，是"他把自己克隆了"
4. **结尾**：不替读者下判断，用具体问题引导（"你手里的活，哪些是重复的？"）

### 关键学习

- X日报素材 ≠ 公众号/贴图选题，要先评估传播性
- 故事必须有真实背景支撑，不能只写表面现象
- "把自己克隆了"比"AI自己创业"更准确、更有冲击力
- 去AI味不是删几个词，是改变整个叙述视角（从分析师→普通人）
