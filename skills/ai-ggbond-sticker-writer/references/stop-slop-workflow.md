# 贴图 x stop-slop 去AI味配合流程

## 什么时候用

飞哥说"去一下AI味道"或贴图文案初稿完成后，用 stop-slop 技能做二次审核。
贴图技能自带的"去AI味七步法"是第一遍粗洗，stop-slop 是精修。

## 工作流

```
步骤2（贴图技能）：去AI味七步法 → 粗洗
    ↓
stop-slop 逐条审查 → 精修
    ↓
五维评分（≥35/50 才可发布）
```

## stop-slop 在贴图场景的高频问题

### 必须砍的

| 模式 | 贴图中的表现 | 替代 |
|------|-------------|------|
| pull-quote 感金句 | "先让你离不开，再说钱" | 直接陈述事实 |
| 模糊声明 | "Anthropic 在赌：用户愿为…买单" | 说具体动作 |
| 安全没有满分 | "安全没有满分" | 删除或用事实替代 |
| 套路/清嗓子 | "套路清晰""翻译一下" | 直接说 |
| "Not X, it's Y" 对比 | "不是快一点，是快三到五倍" | "快三到五倍"直接说 |

### 贴图特有的节奏问题

- 贴图因为字数限制（500字），容易出现连续短句堆叠
- 解法：合并短句，用逗号连接，减少断句数量
- 安全段/数据段最容易犯这个毛病

## stop-slop 五维评分 vs 贴图评分

stop-slop 的五维评分和贴图技能自带的评分维度完全一致：
- Directness = 直接性
- Rhythm = 节奏感
- Trust = 信任感
- Authenticity = 真实感
- Density = 密度

**贴图发布门槛：35/50。低于这个分数必须回炉。**

## 压缩字数的注意事项

飞哥说的"500字以内"包括：标题、emoji、标点、#标签。
实际正文内容（不含标题行和标签行）控制在 400 字左右才安全。

- 标题行：~10字
- emoji/分隔线：~20字
- #标签：~30字
- 正文安全区：~440字

压缩时优先砍：引言/过渡句、重复信息、pull-quote 感金句。
不能砍：核心数据、具体案例、行动建议。
