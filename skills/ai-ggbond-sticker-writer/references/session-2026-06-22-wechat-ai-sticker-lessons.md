# 微信AI贴图写作迭代记录（2026-06-22）

## 背景

飞哥要求用Agent Reach调研"微信AI"后写贴图。调研数据非常丰富（微信小微灰度上线、iLink协议、GitHub开源项目），但写贴图时连续被纠正3轮。

## 迭代过程

### 第1版（飞哥说"太AI化了"）

**文案特征**：
- 开头："昨天刷到一条新闻，愣了好几秒。"
- 有设问句："为什么微信能做到这些？"
- 有总结段："一句话总结：别的AI在练嘴，微信AI在练手。"
- 信息结构像产品说明书：功能1→功能2→功能3→开发者信息

**失败原因**：虽然用了口语化表达，但整体是"新闻播报员"视角——在客观介绍微信AI的功能，没有注入"我"的感受和判断。

### 第2版（飞哥说"AI味道太重，完全不是从自我的角度"）

**改动**：删了设问句，删了总结段，压缩了开发者信息。

**仍然失败的原因**：只是在语言层面去AI味（删句式、改措辞），没有解决根本问题——**叙述视角还是第三人称旁观者**。全文找不到"我"的感受。

### 第3版（飞哥确认OK）

**关键改动**：
1. 加了"我"的视角："我一开始没当回事""我第一反应是：扯呢吧？"
2. 用自然触发点开头："昨天在群里看到有人说"
3. 保留判断但去掉说教："我觉得这才是AI真正的用法"→删除，改为事实收束
4. 结尾不再总结，保留开发者信息但压缩

**为什么这版通过了**：
- 有"我"→不再是新闻播报
- 有真实反应（"愣了好几秒""没当回事""扯呢吧？"）→像人在说话
- 信息结构是"我发现→我惊讶→我理解→你知道吗"，不是"功能1→功能2→功能3"

## 核心学习

### 去AI味的三层检查（2026-06-22 新增）

之前只有"语言层"检查（删设问句、删过渡句、删金句对比）。这次发现还缺两层：

**第1层：语言层**（之前已有）
- 删设问句、过渡句、金句对比、说教结尾
- 加口语确认（"对吧""吧""呢"）

**第2层：视角层**（本次新增）
- 全文有没有"我"？找不到"我"→必然是AI味
- 开头是"新闻事件"还是"我的经历/发现/反应"？
- 信息结构是"产品说明书"（功能罗列）还是"个人叙事"（我发现→我惊讶→我理解）？

**第3层：判断层**（本次新增）
- 有没有替读者下判断？（"一句话总结：..."→说教）
- 结尾是观点还是事实？（观点=说教，事实=分享）
- 有没有"总结性金句"？（"别的AI在练嘴，微信AI在练手"→AI最爱的对比结构）

### 反模式：新闻播报员视角

```
❌ "微信悄悄上线了一个AI助手，叫小微。它能做X、Y、Z。"
→ 你在播报新闻，不是在分享

✅ "昨天在群里看到有人说微信悄悄上线了个AI，我一开始没当回事。又是什么套壳聊天机器人吧。结果仔细一看，有点猛。"
→ 你在分享你的经历和反应
```

**判断标准**：如果把文案里的"微信"换成"某公司"，内容还能成立→说明你在写新闻稿，不是在写贴图。

### 自然触发点 vs 新闻式开头

| 新闻式开头（❌） | 自然触发点（✅） |
|----------------|----------------|
| "微信上线了AI助手" | "昨天在群里看到有人说" |
| "XX公司发布了新产品" | "我昨天试了一下XX" |
| "据报道..." | "刚刷到一条新闻，愣了好几秒" |
| "最近有个热门话题" | "我朋友昨天跟我说了个事" |

**原理**：新闻式开头把读者放在"接收信息"的位置。自然触发点把读者放在"听朋友分享"的位置。

### "一句话总结"是毒药

- ❌ "一句话总结：别的AI在练嘴，微信AI在练手"
- ❌ "总结一下：这个趋势值得关注"
- ❌ "所以你应该..."

**为什么毒**：这是AI最典型的说教模式。读者不需要你帮他总结，他自己会感受。

**替代方案**：用具体事实收束。比如最后说"6月20号已经灰度了，部分人左上角能看到一对绿色小眼睛"——这是信息，不是判断。

## 对后续贴图写作的启示

1. **写之前先问自己**：这篇贴图里有"我"吗？"我"的感受、反应、判断在哪里？
2. **信息结构用叙事链**：我发现→我反应→我理解→你知道吗，不要用"功能1→功能2→功能3"
3. **去AI味不是语言技巧**：是改变叙述视角。视角对了，语言自然对；视角不对，怎么删都是AI味
4. **最后一个读者问的问题**：这更值得作为结尾——不是你替读者总结，而是读者看完后自己会想的问题
